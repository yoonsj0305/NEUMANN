# 1단계 후보 C1 설계서 — Discrete Register Fold with Tape (DRF)

**상태:** 초안. 기준선 작업(Phase A‴)이 끝나면 설계 채팅에서 동결한다. 동결 전에는 구현하지 않는다.
**작성:** 2026-11-17, 설계 채팅

---

## 1. 이 후보가 답하려는 질문
같은 학습 FLOPs에서, 위치와 무관한 공유 갱신과 이산 상태를 가진 학습 모델이, 강한 기준선 4종(abacus, rope, looped_rr, gru)이 실패하는 **분포 밖 길이**에서 일반화하는가?

## 2. 근거 (지금까지의 관측)
| 관측 | 출처 | 설계에 주는 의미 |
|---|---|---|
| GRU는 패리티 분포 밖 전 구간 1.000, 트랜스포머는 찍기 수준 | Phase A | 위치와 무관한 공유 갱신이 길이 일반화의 핵심 |
| 덧셈 분포 밖은 네 기준선 모두 거의 실패 (최고 looped_rr 11–20: 0.278) | Phase A, A′ | 받아올림 상태 + 길이에 비례하는 기억이 동시에 필요한 빈자리 |
| GRU 덧셈 분포 안 0.896 | Phase A | 고정 크기 연속 상태로는 피연산자 전체를 담기 어렵다 |
| §44 K: 숨은 상태를 이산 레지스터로 구성해 70개 중 60개 | Q3 §44 | 이산 상태는 길이가 늘어도 표류하지 않는다 |

**가설:** 길이 일반화 실패의 두 원인은 (1) 위치에 묶인 계산과 (2) 연속 상태의 누적 표류다. DRF는 (1)을 공유 갱신으로, (2)를 이산 상태로 막고, 길이에 비례하는 기억은 상대 이동 테이프로 준다.

## 3. 구조
입력을 왼쪽부터 한 토큰씩 읽는다. 모든 위치에서 같은 셀을 쓴다.

**상태**
- 레지스터 R개, 각각 K개 기호 중 하나 (이산). 초기값 0.
- 테이프: 슬롯 열, 각 슬롯은 S개 기호 중 하나 (초기 공백). 헤드 위치 h (초기 0).

**한 step의 계산** (입력 토큰 x_t)
1. 읽기: m = tape[h]
2. 제어기: 작은 MLP f(embed(x_t), onehot(registers), onehot(m)) 가 다음을 출력한다.
   - 새 레지스터 값 (레지스터마다 K-범주)
   - 쓰기 기호 (S-범주, 공백 유지 포함) 
   - 헤드 이동 {왼쪽, 정지, 오른쪽, 처음으로}
   - 출력 토큰 로짓
3. 적용: 레지스터 갱신, tape[h] 쓰기, 헤드 이동.

**이산화:** 학습 중에는 straight-through Gumbel-softmax(정방향은 hard, 역전파는 soft). 평가 중에는 argmax. 평가 시 모델은 정확히 유한 상태 + 테이프 기계로 동작한다.

**내부 상태에 대한 지도 없음:** 레지스터·테이프 내용·헤드 이동에 정답을 주지 않는다. 손실은 기준선과 같이 답 토큰에만 건다. (§44 원칙: 정답 복사 없이 상태를 스스로 구성)

**초기 크기 (사전 선언):** R=4, K=16, S=16, 제어기 은닉 256, 2층. 파라미터는 기준선(약 0.85M)보다 훨씬 작을 수 있다. 파라미터 수를 맞추지 않고, 비교는 **학습 FLOPs**로 한다.

## 4. 과제별로 기대하는 동작 (가능성 논증, 결과 예측 아님)
- **패리티:** 레지스터 하나로 충분. GRU와 동등해야 한다.
- **덧셈** (`a 뒤집음 + b 뒤집음 =`): a를 읽으며 테이프에 기록 → `+`에서 헤드를 처음으로 → b를 읽으며 a의 자리값과 받아올림으로 합을 테이프에 기록 → `=` 이후 헤드를 처음으로 돌려 합을 출력. 길이와 무관한 규칙이라 학습되면 분포 밖에서도 그대로 동작한다.
- **MQAR:** 상대 이동 테이프로는 한 질의에 테이프 전체를 훑어야 해서, 입력 토큰당 한 step 구조로는 원리적으로 어렵다. **이 과제는 트랜스포머 우위 대조군이며, DRF가 지는 것을 숨기지 않는다.**
- **HRT (§44 과제):** 레지스터만으로 표현 가능한 계열. K(§44)를 기준선으로 함께 보고한다.

## 5. 선행 연구와 차별점 (신규성 주장 범위)
- **Neural Turing Machine / DNC:** 연속(soft) 주소 지정 때문에 학습이 불안정하고 길이에 따라 주소가 흐려졌다. DRF는 상대 이동 + 이산 헤드라 주소가 흐려지지 않는다.
- **Neural GPU (Kaiser & Sutskever, 2016):** 이진 덧셈·곱셈에서 이미 큰 길이 일반화를 보였다. 따라서 **"덧셈 길이 일반화 최초"는 주장하지 않는다.**
- **스택·테이프 보강 RNN, VQ 이산 병목:** 각 요소는 알려져 있다.
- **주장할 수 있는 범위:** 하나의 작은 구조가, 같은 학습 FLOPs에서 현대 기준선 4종보다 분포 밖 일반화가 크게 낫다는 **계산 효율 결과**. C1이 통과하면 Neural GPU를 추가 비교 대상으로 넣어 신규성을 다시 점검한다.

## 6. 실험 계획 C1
- 과제: 덧셈, 패리티, MQAR (+ HRT는 C1 통과 후)
- 학습 규약: 기준선과 같다 (N=100,000, 최대 20,000 step, batch 64, 같은 옵티마이저 설정, 분포 안 최고 시점 판정). 옵티마이저 조정 없음.
- 후보 고유 설정(사전 선언, 조정 없음): Gumbel 온도 1.0 → 0.1 지수 감소(학습 전체 구간).
- 1차: 1M 이하 × 시드 0. 2차(1차가 분포 안 기준을 넘으면): 시드 3개.

**어블레이션 (원인 귀속용, 2차에서 함께)**
- C1-cont: 이산화 없음 (연속 상태) → 표류 가설 검증
- C1-notape: 테이프 없음 → 기억 가설 검증

## 7. 판정 기준 (기준선 표 확정 후 숫자 동결)
- **유효성:** 덧셈·패리티 분포 안 ≥95%. 못 넘으면 구현 버그 점검 1회만 허용, 그래도 실패하면 C1 실패.
- **1단계 신호:** 시드 3개 모두에서
  - 덧셈 분포 밖 11–20, 21–30 구간에서 기준선 최고값보다 **절대 0.5 이상** 높음
  - 패리티 분포 밖 전 구간 ≥0.99 (GRU와 동등)
  - 위 정확도에 도달할 때까지의 학습 FLOPs ≤ 기준선 최고 모델의 학습 FLOPs
  - MQAR은 기준 없음, 숫자만 보고
- **중단:** C1이 실패하면 C2를 설계 채팅에서 정한다. C2까지 실패하면 1단계를 닫고 방향을 재판단한다(사전 결정 지점).

## 8. 위험
- straight-through 이산 학습은 수렴이 어려울 수 있다. 구조 자체가 아니라 최적화 실패일 수 있으므로, 유효성 실패 시 C1-cont 결과와 비교해 원인을 나눈다.
- 테이프 "처음으로" 동작은 사람이 준 기본 연산이다. 이는 구조적 사전 지식이며, 결과 해석 때 명시한다.
