# NEUMANN Q3: 27-weight trained source-to-invariant pilot, corrected holdout preregistration

Date: 2026-10-17 KST. This is a *small, restricted supervised learning pilot*, not an external industry benchmark or proof of global Q3. The previous raw Qwen source→SMT attempts both failed; an explicit typed semantic IR and 27 learned bilinear coefficients are now implemented.

## Frozen before SECOND, stricter hidden-goal holdout
- Architecture `torch.nn.Linear(9,3,bias=False,dtype=float64)`, **27 TRAINED scalar weights**. Inputs are nine products of two source-extracted constant affine transition deltas; output is three proposed coefficients for one homogeneous linear invariant `a*x+b*y+c*z=0`. **The coefficients themselves are learned** from 2,048 synthetic training programs (seed 2026101701). The source parser reads the two affine transition clauses only and does not read error goals. The compiler merely rounds, GCD-reduces and produces a typed SMT formula; it does NOT invent the candidate coefficients.
- Training: Adam lr=0.07, max steps 1500, early stopping only via an independent 256-case validation partition (seed 2026101702). Actual frozen training used 273 steps and 27 parameters. Frozen weights torch file SHA256 **`49d89436443e92e3594aca4e094769d40c90138b838a89d5a8681b27cccc7d5d`**.
- FIRST development test already run (seed 2026101703): 64 generated affine Horn programs with B-style renamed variables + explicit assignment guards, out of training A syntax, predictions with complete 4/4 original Horn verification **64/64**. Strong analytical source nullspace cross-product baseline **64/64**, faster median 16.164us vs NN 86.3685us forward. **Zero additional capability** and no efficiency win. **Important defect**: that first test's goal clause explicitly displayed the target linear expression, even though the neural input extractor never read the goal. This makes it a weak structural discovery validation. This earlier receipt and weights should not be relabeled or overwritten.
- Corrected SECOND holdout here preregistered *before any new task samples are generated*: **64 unseen cases seed `2026101704`**, transition integer components uniformly sampled between -7 and +7 (reject parallel, zero vectors), syntactic source family B (alpha-renamed vars and equality-guarded assignments, with commuted integer addition).
- Corrected safety clause **DOES NOT CONTAIN coefficients or the hidden invariant**. It forbids one concrete integer point `e_k` where `k` is the first nonzero index in the generating nullspace normal (only 0 or 1 constants appear in the goal). Strong equal-information classical baseline reads the exact same source and can find source transition cross product. This is still one intentionally easy class, with hidden semantic oracle in data generation. Explicit goal coordinate may reveal a weak hint, but it does not state the full invariant.
- Model weights are loaded from the above frozen SHA and **not trained/tuned after heldout creation**. Source parser must reject unsupported grammars. No source/goal text may be passed directly to the model; only the nine products of transition deltas.
- Evaluator independently substitutes the full candidate into **all four original generated Horn clauses** using a native SMT solver for each case, demands all 4 negated clauses UNSAT. Refuse zero relation, malformed source and invalid counterexamples. No post-proposal repairing or classical fallback to claim neural success.
