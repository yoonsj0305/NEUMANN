### Constructive mathematical Q3 theorem: sufficient answers without complete rule ID

Known structure: deterministic reversible local 2×2 block map `p` is an UNKNOWN permutation of 16 four-bit symbols, (p\in S_{16}). For each FULL source demonstration pair `(grid_before,grid_after)`, exact nonoverlapping 2×2 blocks reveal mapping entries `input nibble -> output nibble`; any inconsistent identical-source mapping or duplicated-target mapping is rejected. Let `K` be the partial bijective mapping from ALL source demonstrations. Let `U` be the unobserved input nibbles and `V` unobserved output nibbles. Necessarily `|U|=|V|=m`; the complete set of model-class-consistent rules is exactly

```text
P(K) = { p ∈ S_16 : p[x] = K[x] for every observed nibble x }
     = all m! bijections U -> V.
```

This is an exhaustive set, not an LLM's calibrated probability estimate. When `m<=5` we enumerate it all; when `m>5` we say UNKNOWN rather than pretending incomplete search is a proof.

For every full candidate rule `p ∈ P(K)`, perform complete 16-bit initial-state enumeration of the real partially observed 4×4 test inverse CA to obtain the set `S_p` of compatible original initial grids. The source-compatible answer set is

```text
S = union of S_p over all p in P(K).
```

If `|S|=1`, the initial state is uniquely identifiable **even if `|P(K)|>1` and the rule itself is not identifiable**. If `|S|>1`, the observed source does not entail a unique initial grid and this system MUST abstain. If any unknown family/class is possible, `P(K)` enumeration is not complete; thus no global claim of free-form physics discovery follows. On the present source, the complete 4×4 known-class solver's positive candidate answer is separately rechecked against every source observation by the native unoptimized simulator. The official independent grader later restores the actually hidden original rule and test truth. This is sound *conditional model-class* deductive program inference, not neural-exclusive primitive invention.
