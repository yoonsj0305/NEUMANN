## 3. Mathematical first principles

For sets of input pairs A,B,Y on which their Boolean predicates are true:

If A AND B = Y, then Y is a subset of A and Y is a subset of B.

If A OR B = Y, then A is a subset of Y and B is a subset of Y.

These are provably necessary conditions: candidates violating them may be discarded without eliminating a true solution in the same program language. This is a logical necessity result, not a physical causal-intervention identification.

The later meta-closure compiler used a source-certified OR and the original Boolean NOT to automatically generate ALL SIXTEEN two-input Boolean functions as executable programs. It enumerated possible operand/set inclusion relationships and exhaustively proved THIRTY-TWO safe rule instances on the four possible two-input Boolean assignments. No individual law content was entered by hand; the compiler, law-shape universe, semantics, typed VM and search budgets remain human-written.

## 6. Explanation of method failures and their repairs

1. AST-shape ranking failed on earlier official formal inverse tasks; therefore this work targets semantic constraints instead of repeated syntax ranking.
2. Naively generating every binary predicate combination wasted candidate checks; mathematically necessary inclusion laws safely prune impossible candidates.
3. Source-only composition of two predicates failed on particular new originals. Source residual analysis repaired four source tasks, causing DNF to be enabled before new target access and improving target solve counts by 2 in each of two untouched cohorts.
4. The first DNF implementation repeatedly re-sorted large candidate pools and took 25.9 seconds on one set. A separately verified bounded sufficient-set beam removed this avoidable overhead, tested on a fresh different cohort.
5. The human-coded inclusion rules were generalized by finite Boolean semantic closure, which automatically generated 16 executable binary functions and 32 proven pruning-law instances. New external task candidate checks fell 2.58-fold without changing the set of solved tasks.
6. Any unsupported law, malformed target, unavailable witness, budget exhaustion or interpreter uncertainty must fail closed to unpruned classical search or ABSTAIN, never to a fabricated pass.

## 7. Cost, risks and safeguards

The relevant cost is total source program discovery + meta-learning + formal original parsing and existential projection + typed grammar compilation + candidate search + independent proof + fallback. Because it is software, an Idiot Index of complete price divided by raw material price is not a useful metric; account for verification and marginal compute instead.

Risks: the original problem families share the same task generator, 4-bit exhaustiveness does not imply correctness at arbitrary widths, positive source and target examples may be correlated, source-only activation can overfit, the search grammar may be underexpressive, and candidate-check counts can hide large preprocessing. Preserve immutable FIRST, timestamps, source SHA, original hashes, and Z3 failures.

## 8. Quantum-jump options

1. Infer richer semantic invariants such as symmetry, monotonicity, signedness, extrema and injectivity with independent SMT proofs, rather than stopping at Boolean set inclusion.
2. Discover NEW typed constructor operators and search-control policies from verified source counterexamples, not just new expressions inside a human-provided closure grammar.
3. Route source-learned methods only when expected utility exceeds all discovery, compilation, verification and fallback costs; classical degraded mode should be default.
4. Freeze a genuinely separately authored non-BV target theory, e.g. integer arithmetic, strings or graph constraints, then demand additional independently proved target solutions under a matched expressive language.
