# NEUMANN 1 | 근본 목적 직접 검증: 공식 ARC-AGI-2 첫 전면 실패와 구조 합성의 제한적 복구

기준일 2026-10-22. 결론은 **전체 근본 목적(프런티어급 문제 해결, 최소 필요 계산) 미입증**이다. 두 개의 연구 관문에서 각각 무엇이 가능한지와 불가능한지를 실험으로 좁혔다. 모든 실험은 공개 소스 ARC-AGI-2 커밋 `f3283f727488ad98fe575ea6a5ac981e4a188e49`에 고정한다.

## 1. 공식 공개 ARC-AGI-2 평가 120개: 첫 실험에서 실패

PR [#459](https://github.com/yoonsj0305/NEUMANN/pull/459), 전용 GitHub Actions [#39733043117](https://github.com/yoonsj0305/NEUMANN/actions/runs/39733043117), **실행 SUCCESS, 연구 성능 FAIL**. 소스 SHA 고정: training tree `dac7259367cc5099ef6a7b604a50a93affbbee33`, evaluation tree `8d04288aac3146b7c47d0b799c18bc9c0217d838`. 데이터 1,000/120 전수, 파일명 목록 SHA-256 `3014a6bf8feabbf650a27fd8b77eee7badbdeec6b63035d001ba0cad7cd884dd`.

모델에는 설계자가 제공한 **기하 8종 × 후처리 12종 = 96개 프로그램**만 허용됐다. PyTorch CPU 37→48→1 점수 모델(1,873 파라미터)을 실제로 65 epoch 학습했으며 1,000개 학습 프로그램에서 시범 예제 완전 일치 후보가 있는 문제는 단 15개, 학습용 후보 표본 37개(그중 테스트 정답도 맞는 후보 36개)였다.

모든 120개 공개 평가 문제에서 **완전히 동일한 시범 입력·출력 관계를 보이는 96개 후보가 하나도 없었음**. 따라서 학습 신경망 0/120, 빈도 기반 비신경망 0/120, 가장 짧은 MDL 순위 0/120, 혼합 0/120이고, 평가 정답을 사후에만 이용하는 **96개 DSL 표현 상한 oracle도 0/120**. 이는 학습한 선택기 품질보다는 **문제 표현 문법의 근본 부족**을 지적한다. 96개 중 어떤 고정 순위 모델도 해당 공개 평가집에서 성공 수를 높일 수 없다. 문법의 확장이 필요하다.

실행 파이프라인 세 작업: 최초 소스 공개 SHA 고정과 120 테스트 출력의 제거, 정답 필드가 존재하지 않는 별도 CI 작업에서 추론하고 예측 영수증을 업로드, 그 뒤 **다른 독립 CI 작업**에서 실제 평가 정답을 내려받아 채점했다. 최초 평가 예측 SHA-256 `3f51a7f221f58696b11fda6ab89b67524f3d6cc700e7624b0e5f7d97bea3068e`. 공식 훈련+후처리 5.059초, 전체 평가 추론 3.126초가 측정됐다. 최적화 epoch 실제 gradient 부분 약 0.017초에 불과하지만 학습의 전처리 비용을 제거하지 않는다. GPU/전력/프런티어 모델 직접 비교는 하지 않았다.

## 2. 새로운 표현 구성과 별도 TRAIN ONLY 200개 검증

PR [#460](https://github.com/yoonsj0305/NEUMANN/pull/460), 전용 GitHub Actions [#39734910237](https://github.com/yoonsj0305/NEUMANN/actions/runs/39734910237), **실행·제한적 성능 PASS**. 공식 평가 120문제의 정답으로는 **절대로 추가 튜닝하지 않았다**. 공식 학습 1,000개의 ID를 `SHA256(task_id)` 정렬로 나눠 800개 개발, 200개 검증을 미리 동결했다. 개발 IDs SHA `b781269e0c7deaf49a212b666ddc94cff4915ebe5c8d5251c0134901f2f56281`, 홀드아웃 IDs SHA `9f9f9f80d9c51dd31e0ad999e7d2cf7289fcd2791f785ba41fd74d1b86c8dc9b`.

추가 구조: 96개 원래 프로그램 또는 64개의 범용 객체·기하 프로그램을 먼저 적용한 후, 정답 시범 예제만에서 **문제별 정확한 색 대응표를 합성**한다. 이는 **신경망이 아닌 프로그램 합성**이며, 개별 검증 답은 프로그램 입력에 들어가지 않는다. 모든 200개를 대상으로 코드/홀드아웃 ID가 GitHub에 고정된 후 첫 로컬 예측을 작성하고 별도 채점했다. CI에서도 200개 정답을 제거한 독립 추론 작업이 먼저 예측물을 업로드하고, 별도 채점 작업이 실제 정답을 처음 취급했다. 로컬 사전 시험과 독립 CI가 일치했다.

**정확 해결**: 원래 96개 고정 문법 7/200, 확장된 구성 문법 10/200, 새로 해결된 문제 **3개**. 시범 예제 완전 설명 가능 문제: 7→11/200. 신경망 순위로 해결 가능한 여지 확인을 위해 **모든 11개 정확 시범 적합 프로그램 후보를 정답과 사후 전수 비교**했다. 후보 집합 중 정답을 생성할 수 있는 프로그램 존재 문제는 **10개**였고, 이미 정확히 10개가 선택됐으므로 **동일 문법 안에서 완벽한 학습 순위기조차 이 검증집의 10개를 넘지 못한다.** 유일하게 시범 예제는 설명하지만 정답을 못 만드는 한 문제는 `aabf363d`이다.

동일 CI 파이프라인 새 구성기 200문제 추론 시간 약 3.869초; 이는 본인 기준 내부 프로세스 구간에 한정된다. 전체 10배 계산 효율, 의미 있는 대규모 일반화, 새로운 원자 연산 발명은 입증되지 않았다.

## 3. 최종 연구 판정 및 강제 피벗

- **Q0/근본 목표:** 공식 ARC-AGI-2 평가에 대한 0/120 확인. 현재 고정 96연산 모델은 프런티어급과 엄청난 격차다. FAIL (해당 모델·문법·공개 평가 범위).
- **Q3 표현 원리:** 고정 구조가 없으면 학습이 성능을 개선할 수 없다는 실험적 상한을 얻었다. 조건부·객체·색 대응의 구성으로 TRAIN 홀드아웃 3문제를 추가 해결한 실제 시연이 있다. 제한적 PASS.
- **Q3 학습만의 고유 신구조 발명:** 전혀 증명되지 않음. 실험의 새 프로그램 생성기는 정확한 비학습 절차다. OPEN.
- **Q4 완전비용 10배·프런티어:** 미입증. 일회성 PyTorch 학습은 비교 대상보다 더 많은 비용이 들 수 있다. OPEN.
- **Q6 독립 저자/새 문제군 전이:** TRAIN 홀드아웃 내 소규모 전이 3개 확인, 강한 독립 분포 일반화 OPEN.

**의사결정:** 더 높은 학습률, 반복 epoch 또는 동일 후보에 대한 모델 랭킹 연구를 즉시 중단한다. 먼저 훈련 예제에서 **새로운 객체 상태·관계·조건부·반복·다중 단계 AST를 동적으로 생성**할 수 있도록 프로그램 표현을 확장해야 한다. 새 AST는 정확한 실제 입출력 검증을 통과하고, 강한 일반용 프로그램 합성/탐색 및 비용 대조군보다 추가 해결 문제를 가져와야 연구상 신경망 지능 성과로 인정한다. 학습비용과 추론비용, 실패/UNKNOWN을 함께 청구한다.

**엄격한 한계:** 원본 ARC-AGI-2 공개 평가에는 상용 프런티어 AI의 직접 추론·비용 측정이 없고, 공식 ARC-AGI-2 비공개 대회 점수를 대체하지 않는다. 자체 후보 상한은 **오직 주어진 작은 문법에 한정**되며, 모든 프로그램 언어 또는 모든 AI에 대한 불가능성 정리가 아니다. 새 200개 검증은 공식 120평가를 재사용하지 않았으며, 홀드아웃 일반화를 과대평가해서는 안 된다. 두 연구 PR 모두 현재 미병합이다.
