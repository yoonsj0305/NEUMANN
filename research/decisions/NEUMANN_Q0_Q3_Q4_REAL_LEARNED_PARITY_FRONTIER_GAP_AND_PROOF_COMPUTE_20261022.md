### Q3 | 실제 학습에 의한 구조 합성과 신규 해결

- 신규 원본 `332efdb3`: 5×5, 7×7, 9×9 훈련 예제로부터 모델이 **출력=0 iff (행이 홀수 AND 열이 홀수), 나머지=1**을 구성했다. 미관측 11×11 테스트 완전일치, 시범 예시 LOODO 3/3. 결정트리 분기 특징은 [11,10], 각각 `열 % 2`, `행 % 2`이고 0.5 임계값이다. 5×5~29×29 홀수 크기에서 *학습한 트리와 닫힌 형식 식*이 같음도 별도 검사했다. **정답 패턴이 이 모든 크기에서 옳다는 일반화 보증이 아니라, 모델 생성 코드의 동치 검사다.** 기존 제한 유한 문법은 이 원본에서 완전 시범 적합 후보를 만들지 못했다.

**기여 경계:** 고정 목록으로 정의된 프로그램보다 유용한 **조건부 논리조합을 실제 모델이 학습하고 원본 새 크기로 일반화**한 하위 가설은 입증했다. 하지만 홀짝성 특징과 결정트리 문법은 설계자가 지정했다. 인간과 고전적 알고리즘이 발명할 수 없는 새로운 원시 연산, 학습 모델의 유일무이함, 프런티어 성능은 입증하지 않았다.

### Q4 | 계산 자체의 원리적 필요성

**증명 가능한 사전 배제:** 고정 특징 함수 F에서 두 원본 훈련 위치 `p,q`에 대해 `F(p)=F(q)`인데 정답 `y_p ≠ y_q`이면 어떤 결정적 f(F(x))로도 이 두 위치를 모두 맞힐 수 없다. 따라서 이 경우 고정 특징을 사용하는 학습 모델을 훈련할 필요가 없다. 해당 증거는 개별 프로그램의 훈련 시범 데이터에서 형성하며 원본 테스트 답은 필요 없다.

- 개발 800: **218개** 불가능 모델 학습 삭제. 검증 200: **54개** 삭제, 합계 **272개**.
- 여전히 학습이 가능하고 훈련 시범을 정확히 맞히는 기존 **52개 (43+9) 모델의 모든 예측과 교차검증 결과는 동일**하다.
- 단발 로컬 CPU 실행 기록: DEV 800 **8.64s→6.31s**, 검증 200 **2.82s→1.78s**. 이는 측정 환경의 편차를 포함하고 전체 모델 파이프라인 비용 10배 개선을 뜻하지 않는다. 공식 CI 여러 교차 실행·272개 독립 원본 증거와 비교할 것.

**역비용을 숨기지 않음:** 학습 전의 기존 합성기 코호트 추론 약 3.82s에 학습형 보완 실행 약 2.82s가 추가돼, **10→11정답을 얻기 위한 추론 계산시간은 약 3.82→6.64s로 늘어났다.** 상호 다른 GitHub 작업의 기록을 합친 근사이며 같은 실험기기에서 여러 차례 반복 측정한 엔드투엔드 벤치마크가 아니다. 오히려 현재 NEUMANN의 북극성 목표에는 충분하지 않다는 점을 명시한다.
