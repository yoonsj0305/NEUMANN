# NEUMANN 1 | Q0·Q3·Q6: 언어 표현력 한계와 데이터 중복 감사

**실제 검증일:** 2026-10-22  
**연구 판정:** 외부 원본 평가 실행/정확도/표현 상한/출처 중복 감사 모두 검증. **프런티어급 문제 해결, 학습 모델 고유 구조 발견, OOD 일반화, 전체 10배 계산효율은 미입증(OPEN)**.

## 연구의 근본 목적

NEUMANN 1 North Star는 *최소 필요 계산으로 프런티어급 문제 해결 능력*을 실현하는 것이다. 실제 능력 검증이 아닌 비슷한 SyGuS 증명 반복과 Q4의 일부 연산 축소만으로는 North Star를 입증할 수 없다. 이 연구는 원본 ARC 문제의 정답 전부를 확인하기 전 동결된 모델을 사용해, 후보 문법과 탐색 정책을 구분하고 데이터셋 독립성까지 직접 감사했다.

## D. 결정적 출처 독립성 감사: ARC1이 ARC2에서 사실상 겹친다

원본 두 저장소의 Git SHA를 고정하고 **400개 원본의 전체 train/test 격자를 재파싱**해 비교. 시범 예제의 제시 순서만 다른 동일 문제를 놓치지 않도록 (train 시범 쌍 순서 무시, test 쌍 순서 유지) 정규화한 내용의 SHA256으로 평가. [독립 데이터셋 충돌 CI #39738996423](https://github.com/yoonsj0305/NEUMANN/actions/runs/39738996423) PASS.

| ARC1 EVAL400과 ARC2의 겹침 | 원본 문제 수 |
|---|---:|
| ARC2 TRAIN1000과 동일한 파일명(문제 ID) | **376** |
| 이 가운데 내용까지 완전히 동일(시범 순서 제외) | **356** |
| ARC2 EVAL120과 ID 및 내용 동일 | **6** |
| 두 쪽 모두와 문제 ID가 겹치지 않음 | **18** |
| 위 ID 비중복 18문제의 정확 해결 | 기존 **0/18**, 신형 **0/18** |
| ID 비중복 18문제에서 예시 완전일치 후보 | **0/18** |

즉 400개 중 최소 **362개가 내용까지 동일**하고, **382개에 ID 중복**이 있다. 파일 SHA나 순서가 달라 보였던 문제들도 많은 경우 같은 내용이다. ID 비중복 18개도 유사/파생 계열 독립까지 검증한 것은 아니며 샘플 크기가 작다. 이전 ARC1 5/400을 **완전 독립적인 교차 벤치마크 전이 성공**이라고 부를 수 없다. 5개 정답은 모두 이름이 겹치는 집단에서 발생했다.

## E. Q0·Q3·Q4·Q6 핵심 가설 판정

1. **PASS, 제한적:** 시범 예제에서 색/객체 연산을 합성하여 기존 문법 밖의 유효한 프로그램을 구성할 수 있다. ARC2 DEV800에서 6개 추가 실제 정답.
2. **FAIL/NOT SUPPORTED:** 같은 확장을 ARC2 별도 200문제 및 ARC1 공개 400문제에 변경 없이 전이해 정확도를 높인다는 가설. 두 실험 모두 추가 정확 해결 0개.
3. **PASS, 제한적 불가능성:** 고정 후보 문법에서 사후 oracle이 10/200 및 5/400이므로 **그 후보들만 재정렬하는 학습**으로는 이 상한을 넘을 수 없다. 이는 표현 한계이지 범용 추론 불가능성 정리가 아니다.
4. **PASS, 평가 체계:** 원본 SHA만 다르다고 독립성이 보장되지 않으며, 정규화한 문제 내용과 ID 중복을 모두 확인해야 한다는 검사 방식을 실제 데이터에 적용했다.
5. **OPEN:** 신경망의 새로운 원시 연산자 발견/Q3 고유 우위, 저자 독립 문제의 Q6 이전, 프런티어 문제 해결 동등성, 학습/추론/검증/물리 자원 합산 **10배 이상 Q4 총효율**. 이번 ARC 구조 합성에는 학습 호출이 0이므로 이를 NEUMANN 학습지능 자체의 성공으로 전환할 수 없다.

## F. 다음 연구를 위한 STOP / GO

**STOP:** 새 색 선택자 몇 개씩 더 추가해 이미 열람한 200/400에서 점수만 올리기, 같은 후보 공간의 학습 순위 모델 재훈련, 모든 2/3단계 변환 무작정 열거, 내용 중복이 있는 공개셋 간 전이를 독립 성능으로 표시하는 것.

**GO:** (i) 객체의 개수·위치·관계·역할을 포함하는 **중간 상태 그래프**를 생성하고, (ii) 예시 쌍에 의해 제약되는 **typed/compositional 프로그램 AST**를 합성하며, (iii) 증거가 부족하면 불확실성을 유지하고, (iv) 문제 내용 및 계열까지 최대한 중복을 제거해 미리 고정한 외부 코호트에서 강한 비학습 기준선과 전체 물리/계산 예산을 공정하게 비교한다. 어떤 가설도 실제 새로운 원본에서 추가 정확 해결과 상대비용이 입증되기 전에는 GLOBAL PASS가 아니다.
