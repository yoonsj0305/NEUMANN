# NEUMANN 1: 근본 목표 가설 판정 (2026-10-22)

## 목표와 이번 실험의 범위

North Star: **Frontier-level problem solving with minimum necessary computation**.
성공은 (A) 실제 낯선 문제의 정확도와 (B) 같은 능력에 드는 총 계산비용이 모두 입증돼야 한다. 한 축의 성공은 다른 축을 대체하지 않는다.

### 실험 Q0: 기존 타입 기반 중간 객체 표현의 공식 ARC-AGI-2 공개 평가

* 두 기존 알고리즘은 평가 전에 Git blob SHA로 동결. 이전 합성기 `99649c3174710557e27c312a6e5af3eb8b375eb9`; 최신 타입 기반 AST `a46dc5480f0819895effc48df1e0600a23640bdf`.
* 전용 GitHub Actions: https://github.com/yoonsj0305/NEUMANN/actions/runs/39754356479 (성공). 연구 PR: https://github.com/yoonsj0305/NEUMANN/pull/467 (미병합).
* 분리된 3개 CI 작업: 120개 공개 평가 원본 SHA 확인 + 평가 test 정답 삭제 → 별도 프로세스에서 120개 모두의 예측·프로그램 수·비용 저장 → 그 후 독립 작업에서 원본 정답과 전체 격자 완전 일치 채점.
* **결과:** 이전 합성기 0/120, 신규 타입 AST 0/120, hybrid 0/120. 시범 예제를 모두 만족하는 후보 수가 있는 문제도 각각 0/120. 기존 합성기 실행 합계 6.924470552초, 새 AST 실행 합계 1.593044026초. 이 비용 비교는 두 정확도가 모두 0이고 CPU 추론 구간 측정이므로 frontier efficiency 우위의 증거가 아님.
* 첫 실행에는 원본 코드 import 경로 누락 오류가 있었음. 이를 수정하고 동일 모델 SHA를 유지한 최종 CI만 정상 평가로 사용. 실패 실행 https://github.com/yoonsj0305/NEUMANN/actions/runs/39754141155 . 이 평가 세트는 이전 모델에서 사용했으므로 오염이 없는 최초 블라인드 테스트라고 주장하지 않는다.
* **판정:** Q0 일반화와 프런티어 문제 해결 **미입증/현재 메커니즘 실패**. Q3 학습 모델 고유 연산자 발견 **미입증**. 학습 neural model을 실행한 시험이 아니라 비학습 DSL 검증.

### 실험 Q4: 동일 AST 의미를 보존하며 불필요한 컴퓨팅 작업 제거

* GitHub Actions 실측: https://github.com/yoonsj0305/NEUMANN/actions/runs/39748259485 (40문제, 7회 반복, 기존/shape/semantic). 원본 `NEUMANN_Q4_LATEST_FULL_DSL_COST40_20261022.zip` 안의 모든 결과가 동일한 프로그램 선택·격자 예측 해시와 후보 수 93을 기록.
* 40개 동일 문제에서 한 프로세스 내 **DSL 합성+최소복잡도 선택+test 입력 예측** 벤치마크의 7회 중앙값: 기존 2.271944055초, shape cache 0.306273968초, semantic memo v2 0.205164416초. 기존 대비 **11.07377배**.
* 원본 7회 쌍의 개선비는 모두 9.07~11.34배. 동일 7쌍 재표본추출(percentile bootstrap, 30,000회, 고정 시드)시 *메디안 시간비* 95% 경험 구간 약 9.58~11.30배. 반복 수가 작고 한 CI 환경이므로 이것은 기계 간 통계적 보증이 아니다.
* https://github.com/yoonsj0305/NEUMANN/actions/runs/39748259491 에서는 ARC-AGI-2 공식 1,000개 학습 원본에 대해 source-selector memo v1과 v2의 동일 후보 AST를 검사하고, 더 무거운 기존 방식과도 일부 원본을 교차 검증했다. 같은 40개 proposer-only 중앙값 기존 4.025826414초 / semantic v2 0.354447611초 = **11.358배**.
* **판정:** 검증된 **고정 DSL 작업**의 Q4 하위 가설 PASS. 중간 객체 선택과 연결 성분 결과의 안전한 재사용이 불필요한 계산을 삭제하면서 결과를 보존함. 하지만 초기화/설치/네트워크/전체 프런티어 모델의 학습·추론 비용이나 모든 문제집으로 일반화된 10배 성능은 OPEN.

## 최종 결론과 연구 채택 기준

1. **현재 병목은 프로그램의 표현·생성이며 선택/계수 최적화가 아니다.** 동결된 표현 문법이 공개 ARC2 평가 120개 중 단 하나도 시범 예제를 설명하지 못했다. 같은 문법을 더 오래 탐색하거나 더 빠르게 실행해도 정확도는 증가하지 않는다.
2. **효율 최적화 메커니즘은 재사용**한다. 의미 기반 memo, 정확한 타입·형태 제약 및 fail-closed verification은 새 구조 생성기가 등장한 뒤에도 유효하다.
3. **새 아키텍처의 첫 임무는 표현 공간 확장과 learned-only 구조 생성의 검증**이다. 기존 시범 예제에서 새 typed AST를 출현시키는 모델을 훈련한 뒤, ID·내용·문제 계열을 격리한 새 코호트에서 기존 강력한 고전적 동일 권한 제안기에 없는 올바른 출력을 실제로 맞혀야 한다. 오류·abstention 전부 분모, 테스트 정답은 예측 생성 후 독립 해시로 평가.
4. 새로운 Q0 성공률이 확인되기 전에는 컴퓨팅 최적화만 늘리는 실험을 **중단**한다. 하위 DSL 속도 11배를 글로벌 frontier parity나 10배 비용 우위로 포장하지 않는다.
