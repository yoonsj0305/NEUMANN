# NEUMANN 1 | Q0 근본 목표 검증: 실제 일반화와 표현력 상한

**날짜:** 2026-10-22  |  **판정:** 데이터셋 중복과 기존 고정 문법의 표현력 한계를 독립 검증. 프런티어급 문제 해결, 학습 모델 고유의 구조 발명, 전체 계산비용 10배 우위 **미입증(OPEN)**.

## 실험의 근본 질문

> NEUMANN 1은 새로운 문제에서 기존의 강한 비학습 기준선보다 높은 해결 능력을 더 적은 **총** 계산으로 제공하는가?

이 질문에는 긍정적 증거가 나오지 않았다. 반대로 현재 평가와 표현 언어에서 **왜 그런 증거를 만들 수 없는지**를 원본을 고정해 확정했다.

## 공개 원본 전수 감사

- ARC-AGI-1 공개 평가 **400개**, pinned Git commit `399030444e0ab0cc8b4e199870fb20b863846f34`; 평가 디렉터리 Git tree `4a19f8327d45dda5e1809ee47be08bf1484b493b`.
- ARC-AGI-2 학습 **1,000개**, 공개 평가 **120개**, pinned commit `f3283f727488ad98fe575ea6a5ac981e4a188e49`; Git trees `dac7259367cc5099ef6a7b604a50a93affbbee33`, `8d04288aac3146b7c47d0b799c18bc9c0217d838`.
- ARC1 평가의 **376개** ID가 ARC2 학습에, **6개** ID가 ARC2 평가에 등장. 합집합 **382/400**. 375개는 ARC2 학습과 시범 예제(입력+출력 격자)가 동일. **362개는 학습 예제 순서만 정규화하면 완전한 문제 내용이 동일**.
- **ID도, 정규화된 전체 문제 내용도 중복되지 않는 것은 18/400**. 비중복이 곧 규칙/문제 계열까지 독립임을 보장하지는 않음.
- 이전에 고정·저장된 최초 400개 예측/정답 점수를 **전혀 바꾸지 않고**, 비중복 18개에서 기존 및 개선된 비학습 문법 모두 **0/18 정답**. 전체 **5/400 정답**은 모두 중복 ID가 있는 집단에서 발생. 이 18개 부분집합은 사후 구분이므로 **새로운 블라인드 시험으로 재명명하지 않는다**.
- 평가 작업 자체는 소스 원본 전체 커밋/디렉터리 SHA를 확인하고 완료했으며, 원본 첫 실행의 예측 SHA `98dba8c5432f437d296df95d0db2860f6354575313bfc18d5fb2bf713dd2ea47`, 전체 독립 채점 SHA `0f72e52b1ccc504a35717135d556090f34205a635e8f4dba050a47ce5aab035f`, 고정 400개 간결 점수 SHA `11ea8eb3438914e2ab7e9b5b83d80a8f3c3bea28d2f77e7b8d135544287d5878`에 연결됨.

## 표현 언어의 구조적 상한: **후보 선택 학습만으로는 개선 불가능**

사후 독립 검사에서 ARC2 개발 자료만으로 동결한 두 비학습 프로그램 문법을 모두 열거했다. 각 ARC1 프로그램의 시범 예제를 전부 일치시키는 **후보 프로그램이 발견된 문제는 7/400**, 그 후보 수 합은 **19**. 원본 테스트 정답과 일치하는 후보가 존재한 문제는 **5/400**이며 실제 시스템 역시 이미 5/400을 맞혔다.

그러므로 같은 후보 생성 집합을 전제로 후보 **순위만** 재학습시켜도 이 400문제에서 개선 가능한 정답 수는 **0개**이다. 이것은 고정된 유한 후보 언어 내의 완전 열거 결과이지 모든 프로그램, 모든 신경망, 모든 더 강한 DSL의 불가능성 정리가 아니다. 18개 ID-비중복 문제에서는 일관된 후보 자체가 **0개**였으며 완전 열거 상한 또한 **0/18**이다.

공식 ARC2 공개 평가 120개에서 기존 96개 DSL 신경망과 고전적 기준선은 각각 0/120, 문법 표현 후보 상한도 0/120. ARC2 학습 내부 별도 200문제에서는 새 비학습 관계형 DSL 10/200 정답, 기존 DSL 7/200이었으나 이는 독립 신규 저자/외부 문제 전이에 대한 증거가 아니었다. 관계형 DSL을 보강해도 ARC2 학습 내부 200문제 정답은 10/200, ARC1 공개 평가 400문제 정답은 5/400이었다.

## 실제 입증 및 거부된 가설

1. **PASS (평가 무결성):** 다른 벤치마크 이름만으로 미관측 문제라 가정하면 안 된다. 원본 ID, 순서 정규화된 시범 예제, 전체 test를 통해 원본 중복을 확인한다.
2. **PASS (문법 상한):** 현재 동결된 후보 언어의 400개 중 표현 가능한 정답은 정확히 5개다. 현재 순위기가 이미 모두 해결했으므로 학습 선별 모델 개선 여지는 이 세트·이 문법에서는 없다.
3. **PASS (최소 필요 계산에 대한 조건부 정리):** 생성기가 예시를 만족하는 후보를 하나도 만들지 못한 문제(393/400)에는 동일한 후보 집합을 순위화하는 연산을 추가할 이유가 없다. 이는 **불필요한 재순위화 가능성**의 논리적 제거일 뿐, 신경망 실제 전력/벽시계 98% 절감을 실측했다는 뜻이 아니다.
4. **FAIL/NO EVIDENCE (문제 해결):** ARC1과 ARC2 사이에 일반화 우위 입증 없음. 비중복 18개에서 0개, ARC2 공개 평가 첫 실행 120개에서 0개.
5. **OPEN:** 학습기가 새로운 문법 연산/합성을 자율 제안해 고전적 강한 소스 알고리즘이 놓친 문제를 해결하는가? 전체 학습·추론·검증비용까지 반영한 10배, 프런티어급 동등성, 충분히 큰 독립 벤치마크 전이 여부.

## 중단할 작업 / 다음 결정적 실험

**중단:** 기존 후보 19개에서 더 오래 학습시키기, 동일 ARC2 내부 200개 재튜닝 후 `firstblind` 재명명, 중복 ARC1 400개를 독립 OOD 증거로 인용, 현재 재순위화 학습을 성능의 주 엔진으로 확대.

**다음 게이트:** SHA와 문제 내용까지 사전 인증한 *다른 출처·다른 문제 계열* 원본에서 **학습 기반 새 연산자/객체 관계를 합성**하는 경로를 만들고 (a) 정확한 비학습 알고리즘/DSL/탐색기/SPACER 수준에 맞는 강한 기준선, (b) 정답 비노출 추론, (c) 각 후보의 실제 원본 정합성, (d) 학습 포함 벽시계·GPU/CPU·검증비용, (e) 통계적으로 의미 있는 충분한 표본과 실패한 모든 사례를 동일 분모로 측정한다. **기존 표현 언어가 이미 포괄하는 문제에서 신경망을 억지로 사용하는 것을 금지**한다.
