# NEUMANN 1 | Q0 전체 목적 직접 판별: ARC-AGI-2 공개 120문제

- 본 사전 등록은 GitHub `arcprize/ARC-AGI-2@f3283f727488ad98fe575ea6a5ac981e4a188e49` 원본의 `data/training` 1,000개와 `data/evaluation` 120개 전체로 고정한다.
- 데이터 트리의 Git 객체 SHA를 각각 고정하고, 파일명 목록의 SHA-256도 고정했다. 사후에 특정 문제를 제외하거나 난이도를 바꾸지 않는다.
- 모델의 상태공간은 **설계자가 지정한 96개 변환 프로그램**으로 고정되어 있다. 모델은 그중 훈련 예제와 합치하는 연산의 순위를 정할 뿐, 새로운 연산자·원리를 발명하지 않는다.
- PyTorch 모델은 훈련 세트의 예시와 목표에 한해 훈련한다. 추론 작업에는 평가 문제의 정답 필드를 제거한 입력만 전달한다. 예측 파일과 SHA-256이 먼저 저장된 뒤, **다른 별도 작업**이 처음으로 평가 정답을 다운로드한다.
- 비학습 MDL, 훈련 경험 빈도 기반 비학습 prior, 사후 문법 내 oracle ceiling(정답은 채점에만 사용)을 같은 120문제에 적용한다. 가장 강한 실제 고전적 ARC 전용 솔버나 API 프런티어 모델을 직접 실행한 것은 아니므로 공정한 '프런티어 동등' 주장에는 사용하지 않는다.
- 관측된 **정확 일치 정답 개수**와 모델의 추가 성공 수, 표현 가능성 상한, 학습+추론 시간, 실패 이유를 저장한다. 아무리 성과가 낮아도 원본 120개 전체가 분모다.
- 성공 판정은 관측 결과에 한정한다. 글로벌 Q3 학습 고유 구조 발명, Q4 전체 계산비용 10배, 프런티어급 정확도는 추가 근거 없이는 OPEN이다.
- 실패했을 경우 이 96개 문법과 학습 방식의 한계를 보존하고, 같은 평가 세트에서 정답을 보고 튜닝한 후 첫 실행인 척하지 않는다.
