# NEUMANN 1 · Q3 원본 12개 안전성의 참값 종결과 학습 모델 고유성 판정

**날짜:** 2026-10-22  |  **판정:** 원본 12개에 대한 SAFE/UNSAFE 사후 원본 검증 완료, **학습 고유 구조 발견 미입증**.

## 가장 중요한 확정 사실

- 12개의 원래 SyGuS 프로그램을 변경하지 않고, SHA-1 Git Blob과 바이트 수를 검증한 다음 **SAFE 11건**과 **실제 도달 가능한 UNSAFE 1건**을 판정했다.
- SAFE 11건의 *전체 원본* `Init`, `Consecution`, `Goal` 세 조건 각각을 원래 소스 `pre-f/trans-f/post-f`와 제안 불변량으로 구성하고 Z3와 cvc5(체크섬 고정 버전 1.4.2)로 각각 **33/33 UNSAT**를 확인했다.
- 잘못된 불변량 TRUE/FALSE에 대한 부정 대조군 22개와 UNSAFE `fib_07.sl`의 구체적인 도달 가능성 검증 3개는 두 솔버 모두 **25/25 SAT**다. 따라서 **58/58 결과 일치 / 솔버당**, 총 116개의 판정을 확인했다. 원본 각 질의 SMT-LIB2 텍스트가 재생 가능하게 보존되었다.
- SAFE 11건의 불변량 출처: **기존 고전 Houdini 생성 8개**(기존 별도 원본 독립 검증 영수증 재사용), **사후 명시적 수작업 후보 3개**(`ex23`, `fib_13`, `fib_11`). UNSAFE 원본 `fib_07`은 실제 초기 상태 `(i,n,a,b)=(0,1,0,0)`에서 1회 진입 가능한 `(1,0,1,2)`가 원래 Post를 위반한다. 중요한 원인: 원본 Trans가 `n'`을 제한하지 않는다.
- 기존 12개 평가에서 `fib_11.sl`의 **사전 등록 원본 Git SHA 오류**가 있었다. 이번에는 올바른 원본 SHA로 *별도 사후 재검증*했다. 따라서 과거 선등록 실험이 실패한 사실을 보존해야 하며, 이번 검증을 '첫 블라인드 모델 일반화 12/12'이라고 해석해서는 안 된다.

## 추가로 입증된 유용한 구조

실제 원본을 대상으로 Z3 + cvc5 3VC를 통과한 수작업 관계식:

1. **ex23:** `0<=y<=127`, `0<=c<=36`, `z=36*y+c`. 이는 상태별 상수 `36`과 교차 변수 관계를 필요로 한다.
2. **fib_13:** `t=0 => k=0`, `t!=0 => j=2*k+2`. 조건 분기별로 서로 다른 관계식이 귀납적이다.
3. **fib_11:** `x>0`, `0<=i<=x`, `j=2*i`. 이 항목은 SHA 오류의 *사후 보정 원본*에만 귀속된다.

**주의:** 세 항목은 인간이 이번 작업에서 제안했다. 학습 모델이 이 새 구조를 발견했다고 주장하면 안 된다. 일반적 의미의 수학 정리 자체도 새로운 발견이 아니다.

## 학습 정책에 대한 실패 판정

이전 공식 고정-가중치 타 원본 실험([PR #450](https://github.com/yoonsj0305/NEUMANN/pull/450), [GitHub Action 39707890040](https://github.com/yoonsj0305/NEUMANN/actions/runs/39707890040))은 고전적 훈련 라벨을 사용한 8개 원본에서 한 번 학습한 후 12개 원본에 가중치를 고정해 적용했다. 학습 정책은 7/12, 무작위 후보 순위는 7/12, 정적 순위는 5/12, 비학습 신경망은 4/12, 전체 고전 Houdini는 8/12 증명했다. **학습 7개와 무작위 7개는 동일한 원본 집합**이다. 추가 성공 사례 0. 직접 전체 고전 Houdini보다도 해결 건수가 적고, 전체 학습 훈련 비용과 후보 실패 검증을 합한 통제된 10배 비용 우위도 없다.

**따라서 Q3를 '학습만의 구조 발명 PASS'로 닫을 수 없다.** 오히려 기존 구조 어휘 내 정책 학습이 새로운 능력에 기여하지 못했다는 제한적 부정 결과가 나온다. 해당 고정-어휘 정책 경로는 우선순위에서 제외한다.

## 새 아키텍처에서 유지해야 할 4개 조건

- `SOURCE_IDENTITY`: 원본 SHA 및 원본 의미에 대한 재확인 실패 시 자동 UNKNOWN.
- `SOURCE_TRUTH`: SAFE는 원본 전체 불변량 3VC, UNSAFE는 실제 Pre→Trans→¬Post 경로로만 인정. 단순 SMT unknown이나 깊이 제한의 '반례 미발견'은 SAFE가 아님.
- `PROPOSER≠AUTHORITY`: 학습 모델은 명시적 구조 AST를 **제안**만 하며, 정확 고전적 합성과 독립 검증을 제거해서는 안 됨.
- `LEARNED_UNIQUE_GATE`: 고정 AST 후보의 숫자 최적화나 기존 관계 어휘의 후보 순위를 개선한 것만으로 새로운 연산자 발명 PASS를 선언하지 않음. 새로운 언어·표현의 신경망 유래 후보를 사전 동결된 강한 비학습 비교군에 대해 새 원본에서 평가하고 전체 비용까지 증명해야 함.
