# NEUMANN 1 | 핵심 가설 검증: 최소 필요 계산과 외부 원본 안전성 분류

**2026-10-22 · 연구 범위 한정 · 전체 Q1–Q7 OPEN**

## Q4. 기존 증명 활용으로 불필요 계산 삭제

실제 SyGuS 4개 원본의 최소 필수 관계 지원 차수 K=(3,3,3,4)를 이전의 독립 Z3+cvc5 원본 3VC에서 검증한 후, J_(K−1)(R)의 가상 상태가 원본 도달경로·전이로 안전성을 위반함을 확인하면 그보다 낮은 j<K−1의 불가능성은 J_(K−1)(R) ⊆ J_j(R) 때문에 자동으로 따라온다. 따라서 모든 k=1..K−1를 독립 탐색할 필요가 없다. 표현 하한은 보조변수 없는 원본 상태변수 k개 이하를 참조하는 임의 조건들의 AND에만 적용한다.

GitHub 동일 실행기 네 번씩 ABBA 교차 실행: 전체 탐색 평균 1.371425초, 필요한 마지막 차수만 탐색 0.636300초 (2.1553배 탐색 속도). 각자 얻은 최소 관계 차수 정확히 4/4. 두 솔버 원본 SAT 증거 재검사 64개 → 31개 (51.5625% 감소). 자동 소스 상한 불변량 생성에 별도 0.9295초가 소요됐으며, 해당 상한은 원본 전체 12개 귀납 조건이 Z3와 cvc5에서 모두 UNSAT로 승인됐다. 이 비용을 공짜로 취급하거나 전체 AI 2.16배/10배라고 주장하지 않는다. 원본 fetch, 환경 설치, 아티팩트 저장, 모든 검증 전체시간은 별도다. 소규모 네 원본의 제한된 검색 상의 절감이다.

## Q3. SHA만 먼저 등록한 새로운 외부 원본 8개

공식 SyGuS-Org/benchmarks 기존 고정 커밋에서 2017 Inv_Track 네 개와 2019 Inv_Track From2018 네 개를 본문 읽기 전에 SHA-1 Git blob/파일 크기로 먼저 등록했다. 동일한 학습 없는 Houdini·source-guarded exact affine 알고리즘을 수정 없이 적용했다. 첫 CI 원본 전체 독립 3VC: 둘 다 7/8 SAFE 정확 입증, 미해결 matrix2_simp.sl 한 개. 모든 분모와 오류를 유지, 성공 사례만 선별하지 않았다. 저자 독립·대규모 일반화를 주장하지 않는다.

matrix2_simp.sl의 미해결 원인은 **고전적 파서가 원본 상태변수를 최대 5개로 제한**했는데 실제 프로그램이 6개 변수인 구현 제한이었다. 그 원본은 추가로 본래 Pre와 Post만 분석해도 UNSAFE: 원본 Pre ∧ ¬Post SAT를 만족하는 초기 상태가 존재한다. 양쪽 SMT 솔버로 실수 없는 정수 상태의 실제 최초 위반을 확인했다. 구조 합성기가 풀지 못한 안전한 원본이 아니라 **정당한 SAFE 불변량이 존재하지 않는 원본**이다. 최초 상태 인증은 별도의 POSTHOC 검증으로 기록했고, 첫 SHA8 실험을 소급해 학습 모델 성공으로 포장하지 않는다.

## 과학적 판정

- **PASS 제한적:** 별도 등록된 공식 원본 8개에 대해 고전적 자동 합성 7개 SAFE 입증, 남은 1개는 독립 원본 UNSAFE 반례로 안전성 구분. (후자 최종 영수증의 CI 통과 시에만 통합 PASS로 표기.)
- **OPEN:** 학습 모델 고유 신규 연산자 발견, 대조군을 넘는 Q3/Q6 이전, 클라우드+엣지 확장, 프런티어급 정확성, 전체비용 10배 우위.

## 아키텍처 결론

**Pre ∧ ¬Post(즉시 UNSAFE 검사) → 저비용 Post-only와 정확 고전적 제한 문법 → 조건부 관계 합성 → 표현 부족이 증명될 때만 arity 증가 → 원본 독립 검증 → SAFE/UNSAFE/UNKNOWN 분리**. 안전성 없는 원본에는 SAFE 증명을 시도하지 말 것. 상한 인증 정보를 활용해 필요 이상의 k 단계를 계산하지 말 것. 파서 최대 변수 수 같은 엔지니어링 한계와 수학적 표현 불가능성은 반드시 분리할 것. 학습 모델 우위 증명은 다른 원본에서 강한 고전 알고리즘을 넘는 경우에만 유효하다.
