## Architectural boundary

Deterministic extraction identifies original query numeric literals, entity
occurrences, operator/relation lexical candidates, and source-bound spans.
A finite complete grammar constructs typed *references*, never regenerated
numeric operands. The unchanged P1.5 compiler builds exact executable IR;
unchanged P1.3 admission gates the specialist. The independent original verifier
alone can accept the answer.

Literal IDs hash the complete original view, type and half-open Unicode codepoint
span. They distinguish equal repeated values and change when the source changes.
Raw surface, canonical lexical value, query hash and view hash are retained.
The closed word-number lexicon is one quarter=1/4,two thirds=2/3,one half=1/2;
these translations retain their original spans. They are explicit lexical rules,
not universal extraction of every number in arbitrary language. Arithmetic
operands are copied from those records. Intermediate results cannot overwrite
an operand. Operator lexical evidence is retained alongside selected atoms.
Compilation reconstructs the full bundle from the original view; forged literals,
foreign IDs, types, candidate order, route, coverage or span changes fail closed.

The parser covers ONLY a registered controlled-language subset:

- Start with / Begin with / Take literal, or Multiply literal by literal.
- Ordered add/subtract/divide/multiply accumulator clauses; comma,semicolon,
  newline or explicit then separators; bounded exact signed literals/fractions.
- Choose / Assign declared entities from one shared bounded integer domain.
- equals,is less than,is at most,differs from relations in original operand order.
- At most one `It equals literal` CSP clause enumerates every declared entity
  binding. Maximum4 candidates; excess ambiguity is rejected,never truncated.
- Only declared request suffixes and four instruction forms are accepted.
  Background,hidden metadata,unconsumed prose,undeclared entities,unsupported
  relations and unsupported formulations stop without tools or a neural call.

The complete grammar's unique candidate is NOT a proof of general natural-language
semantic uniqueness. Scope is syntactic coverage under this finite grammar.
No candidate-equivalence,unseen-family,general reasoning or Q1-Q7 closure claim.
P1.6 arithmetic examples are opened regression fixtures,not new capability data.

## Lazy non-generative fallback

One candidate: deterministic reference compilation; selector factory/core loading
and neural forwards are ZERO. Unsupported input: stopped state,not guessed IR.
Multiple candidates: stop unless a bounded semantic selector is supplied.
The implemented frozen-core adapter reuses the exact Gemma identity/tokenizer,
BF16 and no-training audit. It teacher-forces original audited A/B/C/D code IDs.
All24 code-slot permutations and batch4/unbatched1/reverse_batch4 are recorded;
unused slots are explicitly unavailable and masked out of selection.
Prompt-facing references use compact e0/e1 occurrence aliases; long integrity
hashes remain in receipts,not neural semantic context. Aliases retain the same
raw source spans and typed values and cannot introduce a new literal/entity.
Candidate choice is recomputed from raw matrices; no generated JSON,atoms,
numbers,answers or command are accepted. Core/model generation hard tripwires
are installed. Prompt hashes,prefixes,mapping order,memory,cost ledgers and core
identity are checked. It never consults a reference,checker result or task family.

The prospective P0 gate reuses margin>0.5nats,numeric delta<=0.05nats,
centered LOO delta<=0.5nats and stable masked winners across all modes/LOO20.
One selector invocation,one execution,one original verification; no retry.
S4 candidate scoring is an expensive fallback,not a measured optimal controller.
Zero-neural does not mean zero computation: extraction,grammar enumeration,
bundle reconstruction,exact compiler,admission,solver and verification all cost.
Factory/model startup lies inside item/selection timing. Existing180s item and
120s scoring caps remain; prefix token/forward caps are checked before inference.
Known partial forwards/tokens are retained; unknown work is None,not zero.
Accounting failures cannot enter execution even if a cached winner looks good.

The semantic-only replay helper reconstructs bundle,raw-matrix choice,compiler
proposal and original checker acceptance without any model/solver call. It is
deliberately NOT an archive/hash audit or a cost replay, and labels that limitation.
Only complete gated execution records are supported at P0; no incomplete attempt
is transformed into PASS by this helper.
