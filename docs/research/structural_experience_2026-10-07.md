# 구조 경험 데이터와 재사용 가능한 native 비교군

2026-10-07. 기존 원본을 재실험하지 않고, [전날 실제 관측](structural_mechanism_screen_2026-10-06.md)을
다음 LPS 연구에 연결하는 데이터·비교군을 구현했다. 이번 산출물은 **학습된 NEUMANN의
성능 결과가 아니다.** 새 모델 학습, GPU 실행, G1 진입, G2 또는 Decision 3 접근은 없다.

42개 개발 검사는 구조와 자원 모델 검사다. 31개는 원래 출력 목표를 보존하는 기존
경로를 찾았고 11개는 사전 지정 연산량·중간 상태 예산으로 거절했다. 이 숫자는 수치
문제를 푼 새 정확도나 미관측 구조 일반화 성능이 아니다. 작은 독립 fixture에서는
새 행렬 값·변경한 출력 순서의 정확 정수 결과를 직접 행렬곱과 비교했다.

## 모델이 배울 수 있는 기록을 만들되, 학습은 활성화하지 않는다

각 경험은 원본 문제 hash와 원본 관측 파일·위치, 제안 표현의 hash, 유효성 권한,
실제 기록된 비용을 연결한다. 한 경로의 비용을 다른 제안에 잘못 붙이지 않도록
각 비용 sample에 candidate hash를 부여했다. 변환 단계의 인과적 보상을 추정하거나
특정 단계가 절감을 만들었다고 자동으로 결론 내리지 않는다.

335개 중 정확 프로그램 관측 216개, 경로 모델 검증 95개, CPU query 관측 12개,
사전 예산 제외 12개를 모두 유지한다. CPU 관측 12개 안에는 실제 query 36개가 있다.
전체 원본은 서로 다른 측정 계약에 속하며, 비용 sample을 계약 간에 합산하지 않았다.
에너지·금전·실제 FLOPs·peak RSS는 UNKNOWN이다. 경로 탐색 시간만 있는 사례를
전체 문제 비용으로 바꾸지 않았고, 없는 비용을 0으로 채우지 않았다.

181개는 반복 관측을 문제·경로별로 연결한 그룹 수다. 독립된 새 학습 문제 181개나
학습 성공 횟수가 아니다. 전부 이미 열린 개발 자료이며 fresh eligible=0,
training activated=false다. 학습 권한은 새로운 G0/G1 계약을 대신하지 않는다.

`neumann1/structural_experience.py`는 기존 D0 권한 검사기를 재사용한다. train,
fresh_eval, S/H/O의 추론 접근은 payload를 읽기 전에 거절한다. 정답·경로·비용을
읽는 API는 runtime=false인 O/offline 접근만 허용한다. 원래 파일의 hash와 workspace
경계도 확인한다. 이 제한은 해당 Python API의 접근 통제이며 임의의 파일 접근을
막는 운영체제 보안 장치로 주장하지 않는다.

## 기존 알고리즘에도 더 강한 재사용 권한을 준다

`neumann1/native_perspective_catalog.py`는 새 이름이나 새 차원 크기에서도 기존
native 경로를 재평가할 수 있는 C 비교군이다. 공개 인덱스의 연결·중복·출력 목표를
기준으로 같은 topology를 찾고, 새 차원에서 원래 목표 보존과 연산량·중간 상태
모델을 다시 계산한다. 예산 안의 후보 중 모델 비용이 작은 것을 선택한다.

이 카탈로그에 제공된 Oracle 경로는 넣지 않았다. 출처는 기존 opt_einsum/cotengra
공개 탐색 결과이며, 메모리 재사용을 학습된 관점 생성으로 부르지 않는다. 완전한
그래프 동형성 인식, 새로운 topology 발견, 실행시간 최적성이나 전역 최적성도 없다.
실제로 더 빠른지는 동일 executor의 다음 사전 등록 측정이 있어야 알 수 있다.

같은 topology의 입력 차원은 바뀔 수 있으므로 같은 경로가 항상 유리하지 않다.
검사 fixture에서는 차원을 뒤집자 다른 경로를 선택했고, 출력 조건 변경에는 cache
miss, 작은 예산에는 거절을 반환했다. 새 표현 생성 모델 D는 이와 같은 강한 C보다
추가 가치를 보여야 한다. 단순한 답 캐시보다 강한 절차 재사용도 비교 대상이다.

## 오래된 승인을 새로운 학습 승인으로 오해하지 않는다

v0.0.104 Basis Pursuit의 긍정적 ceiling은 무료 support뿐 아니라 최적 dual도 받은
제한된 LP 결과였다. 기존 문서도 특화 L1 알고리즘과 실제 dual 생성 비용을 미해결로
남겼다. 이후 critical path는 또 다른 BP transfer rescue를 중단했다. 이 기록을
새로운 학습 진입이나 10배 우위의 근거로 재사용하지 않았다. 과거 판정은 유지한다.

현재 남은 핵심은 **미관측 구조에서 학습된 표현 생성이 강한 B/C보다 전체 비용을
줄이는가**다. 다음 G1은 A Neural Direct / B 기호 탐색 / C 학습된 고정 표현 선택 /
D 새로운 표현 생성과 제거 실험을 포함해야 한다. 여기서 구현한 native catalog는
C를 대체하는 신경 모델이 아니라, C에도 동일하게 제공할 재사용 기반이자 추가 비교군이다.
독립적으로 의미 있는 영역의 새 headroom과 원래 목표 검증이 먼저 필요하다.
