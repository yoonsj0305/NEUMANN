The collision classes sizes are **85 pairs, 15 triples, 8 quadruples, 2 quintets**. This does not mean a prior cannot guess a likely function, but guessing is not a sound certificate. Exact original source semantic correctness in this finite domain requires leaving the collision class through valid additional **target-output oracle** queries. That target-output oracle is a deliberately modeled extra observation right; it may NOT exist in an arbitrary original SyGuS/physics task and cannot be assumed without justification.

The experiment evaluates seven fixed query policies on **every one of 3,639 semantics**. A target counts solved **only if its version space shrinks to exactly one full256 semantic function**; at most eight extra queries permitted. Since each class has at most 5 distinct full256 functions, exhaustive Bellman DP explores each possible remaining subset and all permissible 240 new x inputs. For set S of remaining distinct semantic functions, optimal **sum of target-wise expected additional oracle queries**, with every function in S equally likely:

[
V(S)=|S|+min_{x:,mathrm{split}(S,x)>1} sum_{b}V(S_{x,b}),qquad V({f})=0.
]

Here (S_{x,b}) consists of functions in S with f(x)=b. The formula is exact because every target in S consumes one oracle query for each selected x, and all future observation partitions are disjoint independent subproblems.
