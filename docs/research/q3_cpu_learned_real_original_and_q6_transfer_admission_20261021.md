## What is proven and what is NOT

**Proven:** a real, cheap sklearn CPU model can learn limited *numeric phase offsets* from authentic original source transition-generated training traces, propose a mathematically typed inductive invariant, and independently pass all three native source VCs on that already opened program for all symbolic integer k. This is more than a verbal-model hypothesis and a useful legitimate bounded implementation result.

**Also proven:** exact zero-training table built from the identical four-case source data yields byte-identical typed invariant AST and hence the same original proofs at lower candidate-build cost. On the frozen input grammar there is no evidence that statistical learning is *needed* at all.

**Not proven:** native program→semantic role inference independent of variable names and state count; automatic selection of different invariant grammars; learned hidden structure that a same-authority expert classical Direct cannot discover; first-blind cross-program learned original task success; **any global Q3/Q4/Q5/Q6/Q7**; 10× wall-cost / joules / tokens frontier advantage.
