## First-principles mechanism
For arbitrary original exact typed (Int/Bool) Pre(x), Trans(x,x') (can be nondeterministic, guarded, disjunctive, nonlinear) and Post(x), discover the **smallest affine-equality inductive hull** enclosing the actual reachable initial states using counterexample-guided span enlargement. Encode each Bool as exact 0/1 expression `If(b,1,0)`; augment original state y=[Int(s), Bool(s) as 0/1, 1].

Start with one SAT model of original Pre; set V=span(y0) over rational numbers, I(x) as all integer-normalized annihilators of V. Iteratively ask:
1. Pre(x) & not I(x). If SAT, add its original source state y(x) to V.
2. Otherwise ask I(x) & ORIGINAL Trans(x,x') & not I(x'). If SAT, add y(x') to V.
3. Two UNSAT outcomes => I is an original-source inductive affine equality invariant and the exact least affine invariant hull. Every SAT witness strictly increases the rational rank <= state dimension +1. Timeout/unknown/errors/large coefficients => ABSTAIN, never a proof.
Exact row-space closure is certified algebraically and original solver checks all 3 original verification conditions for **I AND original Post**, with Pre SAT and not-Post SAT to reject vacuity. This is a classical mathematical algorithm related to affine abstract interpretation / SMT CEGIS, **not neural invention, not a new academic technique**.
