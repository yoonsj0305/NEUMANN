## No favorable reinterpretation

- The new learned table has **only three lexical source-op signatures** (COPY/ADD1/SUB1). It learns which **human-enumerated candidate** (H1 offset from -2..2, or old H0) receives formal proof reward. It does **NOT** invent quantification, offsets, source/dest references, an arbitrary new primitive, a general parser, a new theorem or a model-predicted program outside the prewritten H1 grammar. It is NOT a neural network.
- Synthetic heldout source/destination index shifts are *not* an independently authored external CHC original and are *not* a new formalism. The 12/12 result is a **scoped proof-feedback structural-selection interface** only.
- The strongest same-rights baseline already chooses 12/12 with no learned training. This experiment establishes **no capability advantage and no full-cost 10x advantage**. Student has strictly positive training/proof-discovery overhead compared with the classical direct source grammar interpreter.
- Learning changes a candidate policy, unlike the previous passive Stitch static compression and human G3 distillation, but still fails final Q3 autonomous novel operator requirement.
