## Architecture / research decision
**REMOVE** feature-equality slot-ranking neural controller from the critical path (do not remove archived receipts).
The observed meta-reward effect is real only inside a task with human-supplied sufficient statistics. It cannot establish B (invention of representation outside supplied grammar), C (learned discovery-policy adaptation to genuinely novel independently authored semantic tasks), whole-system 10x, or Q7 frontier parity. All global Q1–Q7 stay OPEN.

New admission criterion: a novel own-weight proposer must produce SEMANTIC transformations not directly computed by input features, beat both reward-shuffled/no-learn model and equal-rights strong classical search on independently authored heldout original tasks, after program/macro memories are reset. All code/weights, failed proposals and first predictions frozen before labels. Correctness and completed cost (train, planning, retries, verify, storage, latency, energy, RAM, $) separately accounted. If strong classical gets same original capability cheaper, NO neural adoption.
