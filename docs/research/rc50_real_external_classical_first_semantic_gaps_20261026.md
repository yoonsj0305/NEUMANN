### Central architecture decision

**DO NOT add more fixed-SLOT synthetic tasks.** Existing reliable classical
methods should execute without any model call. A limited grammar miss only
licenses stronger classical baselines, not automatically neural inference.
A new learned semantic proposer is worth studying *only* if the identical-rights
strong classical budget leaves an independently verified capability gap.
Candidate generation → independent source consistency/proof → first freeze →
new external domain evaluation → complete cost, including failures and
verification → reusable deterministic program or fail-closed UNKNOWN.

These findings provide a candidate mechanism for representation discovery
using the CURRENT GPT-6 helper, not evidence that NEUMANN's independent
trained system has itself invented general-purpose computation. Q1–Q7 remain
OPEN. On the actual unused second cohort, **the discovered operators did not
source-transfer**, a real C-gate negative result.
