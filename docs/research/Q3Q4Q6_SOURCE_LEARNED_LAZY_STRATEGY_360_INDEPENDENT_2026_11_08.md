## NEW live meta-algorithm
File neumann1/source_learned_grid_router.py. Three human-provided but executable search strategies:
- classical_only: classical macro original grammar, skips relation-invention entirely.
- relational_only: source-inferred object/role predicate program, skips classical grammar entirely.
- hybrid: source-driven semantic invention PLUS source-fitted exact/composed classical programs (two final attempts maximum).

The SOURCE learner evaluates the three strategies on the ALREADY OPENED third 180 original tasks, picks the highest original-task correctness for each of 18 source-publisher-supplied concept families, then chooses cheapest wall-time if source correctness is tied. The FAMILY names are public dataset metadata (not inferred latent categories). It selects relational_only on 16 families, classical_only on 2. This selection mechanism is human-designed, so NO global autonomous meta-algorithm invention is claimed.

Source policy SHA-256 42d79f3d69c332599c6aea6ecdb3c34126a6fb03d372f2c572269d28245aed21, source discovery wall time 24.76895 seconds. Source mode results from prior exposed 180: classical_only 30/180 in 5.11751 s, relational_only 87/180 in 7.45511 s, hybrid 87/180 in 12.12051 s. Only SOURCE evidence chose the policy.

## Why this matters
The actual algorithm used by NEUMANN changes its discovery PLAN, not merely the objective program. Source examples provide evidence about which executable method family is useful, and that learned plan is reused without invoking non-selected search engines. The method is connected into real NeumannEngine and RegistryEngine via synthesize_arc_grid_cost_aware. Existing core tests include source policy validation, exact example semantics, two-attempt constraint, classical fallback, and unknown-family refusal.

## What was NOT proven
1. Q3 universal metalanguage invention: three strategies, family metadata, semantic primitives, choice criterion and verification harness are human-created. The model selects a program-discovery plan from a finite set, rather than inventing an arbitrary new meta-algorithm from nothing.
2. Q4 10x total cost, 10x frontier capability/FLOPs or 10x source amortization: NOT achieved. Source discovery and fallback costs negate target-only gains at this horizon.
3. Q6 truly universal transfer into unrelated mathematics or an entirely new author without any domain adaptation: not established. This is new task transfer after earlier 1D-specific input repairs.
4. Frontier equivalence: original ARC-AGI-2 public evaluation remained 0/120 from immutable FIRST run 42440957648; creator-administered semi-private frontier 95% is a DIFFERENT cohort, without matched compute telemetry.
