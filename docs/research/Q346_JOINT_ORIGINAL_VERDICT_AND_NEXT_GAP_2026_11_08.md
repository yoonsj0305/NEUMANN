# NEUMANN 1 | Q3/Q4/Q6 Joint Original-Evidence Verdict
2026-11-08 | research decision, NOT global PASS | PR #732

## What has to be simultaneously true

- Q3: source-frozen NEW executable mechanism solves independently original-verified tasks that the **strongest matched classical / specialist comparison** could not solve, while preserving sufficient existing utility. A pre-coded new operator used on handcrafted toy tests alone is insufficient.
- Q4: for equal-or-greater correct originals, **measured full** source preparation + learning + discovery + verification + failed attempts + fallback + target inference and independent final verification is at least 10× lower than the strongest matched counterpart. Target search time alone is insufficient.
- Q6: a single source-frozen generated mechanism obtains new independently verified residual wins on independently authored originals from **unrelated mathematical semantics**; converting a graph to an adjacency matrix, or a 2D grid to a 1D grid, does not by itself establish cross-semantic transfer.
- Model/code/source freeze, target task IDs, old baseline coverage and independent proof of new execution semantics must predate first test evaluation. The evaluator cannot authenticate self-declared provenance labels or semantic equality; external source identity verification is required.

These are **partial-stage** timing ratios from historical published original evaluations. They do **not** account for all data acquisition, CPU memory, verification, model loading or provider cloud costs, so should never be labeled a full hardware performance comparison. In particular the learned 1D router uses *fewer candidate seconds* on the target but **10 fewer correct originals** than the strongest matched full-hybrid baseline.

The 1D meta-policy was frozen before fourth and fifth original cohorts, but after original-source 1D adaptation. Its Q6 is scoped to spatial grid semantics, NOT an independent transfer into e.g. formal proof, theorem proving, constraint solving or numeric scientific discovery.

## Implemented gate and controls

\`neumann1/q346_joint_evidence.py\` and \`tests/test_q346_joint_original_gate.py\` implement evidence-level anti-inflation for both published frozen results. Negative controls require:
- no Q3 success without exact original new-mechanism residual witnesses;
- no cross-domain Q6 success from the same mathematical semantics or source-domain adaptation alone;
- no Q4 10× success if any full target measurement is absent, the strongest matched comparator has higher accuracy, or source learning/failed-attempt costs have not been metered;
- source attribution, independent original verifier, frozen bytes, matched attempts and task disjointness.

The positive unit fixture is **synthetic test of gate logic**, not evidence of a true Q3/Q4/Q6 breakthrough.

## Research action: stop optimizing closed classes

The source-only official ARC-AGI-2 study found just **9/256** discovery training tasks expressible under the entire old 626-program grammar; **247/256 were outside that hypothesis language**. Merely re-ranking the same program candidates cannot create a missing program. The subsequent independently original official public evaluation was 0/120 in both learned and cold execution.

Therefore the primary R&D resource should target **new object-centered executable operators and learned representation languages** that are absent from the frozen 626 grammar, then measure new original capability versus specialist and identical-program-language baselines. Do not treat the finite-algebra, Boolean-loop, rank factorization, program-grammar or classical graph benchmarks as proof of this missing frontier capability. Preserve their scoped successes as tooling.

The domain-independent mathematical fact remains: arbitrary black-box laws indistinguishable on all source observations cannot be universally identified at unseen inputs. Relative completeness within a specified decidable language does not prove frontier capability or 10× compute economics.
