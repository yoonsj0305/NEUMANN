## Execution contract

The unchanged complete bounded P1.7 grammar extracts source occurrences and
enumerates every allowed interpretation. Unique interpretations retain their
zero-neural path. Ambiguous CSP candidates are compiled using unchanged P1.5
and admitted using unchanged P1.3, then checked by a bounded deterministic DFS
over their **public** finite domains and relations. The original checker and
private reference are never used to prune or construct a selector prompt.

| Feasibility outcome | Authority |
| --- | --- |
| All candidates exhaustively UNSAT | Reject; no model/executor/verifier |
| Exactly one SAT, every other candidate proven UNSAT | Select original index; zero model construction/forwards |
| Two or more SAT, no UNKNOWN | Lazy non-generative full-S4 selector; only SAT original indexes eligible |
| Any UNKNOWN | Stop; never treat timeout/work cap/solver failure as UNSAT |

SAT requires a complete satisfying assignment; UNSAT requires exhaustive
search. Resource cutoff returns UNKNOWN with completed work retained.
The node/constraint-check/wall budget is shared across all candidates:
20,000 attempted assignments, 100,000 evaluated relations and 2,000ms.
The full-item cap is 180,000ms. These are prospective P0 implementation limits,
**not a registered actual-study gate**. Cooperative CPU deadlines are not
preemptive operating-system execution limits; actual complete time is retained.

A found CSP witness is reused only for its exact source-bound project SHA.
It still passes P1.3 execution admission and the independent original-obligation
verifier. This prevents a second identical solver search, not the first search.
SAT by itself neither proves faithful interpretation nor implies final success.
Verifier rejection stops; there is no retry or silent expansion of candidates.
