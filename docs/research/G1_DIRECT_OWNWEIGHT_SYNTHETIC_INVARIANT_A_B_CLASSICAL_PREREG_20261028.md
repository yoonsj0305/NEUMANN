## Research question and severe limits

Train a real gradient-updated neural network **to directly WRITE a typed executable symbolic invariant** `I(x,y)` for a loop, rather than re-rank externally provided candidate programs or recycle previously opened official SyGuS answers. Program head emits an AST structural family token L or Q, integer coefficient a, integer constant c. A correct output must be independently fully formally verified over unbounded integers against the source transition, initialization, and the full safety property, **all three inductive verification conditions**, not just match five samples. Compare the identical model trained A against a B network trained on randomized-shuffled correct training triples with identical architecture, data dimensions, epochs, seeds and train budget, and an explicit standard finite-differences classical C given exactly the same observed trace inputs. For OOD cubic, a stronger symbolic classical C derives cubic coefficient while neural grammar contains L and Q only. No external cvc5 production benchmark is available in this synthetic test, **so never conflate synthetic C with official CVC5 performance**.

**CRITICAL LIMITS**: All tasks are generated by OUR OWN fixed program-family generator, NOT independent author benchmark, and answer grammar is fixed in advance to L or Q. The source labels are closed-form expressions, so even a high A accuracy only proves local direct weight-based synthesis in a narrow algebraic controlled toy. It does NOT establish discovery of a new operator outside the grammar, frontier intelligence, causal change in general discovery policy, cross-author OOD or compute dominance vs classical. G1 and Q1–Q7 remain OPEN/HOLD regardless of local accuracy, unless independently satisfied in genuinely new external setup (not this prereg). ## Frozen generating semantics and split BEFORE model training

Define a synthesis task by integer **source** `x'=x+1, y'=y + a * (f_d(x+1)-f_d(x))`, initial `x=x0, y=a*x0^d+c`, safety `y=a*x^d+c`, integer nonzero a in `{-8,...,-1,1,...,8}` and c in `{-8,...,8}`. For L `d=1`, for Q `d=2`; exact native executable model output source `(define-fun inv ((x Int)(y Int)) Bool (= y (+ (* a (x if d=1 else (* x x))) c)))`. Observe only five trace points (x_i,y_i) i=0..4, including exactly integer values, no source parameter a,c or f_d AST labels handed to the model at inference. **Because the problem itself has simple closed-form safe equality, this is intentionally a sanity test of learning not proof of innovative problem solving**.

All 2×16×17 = **544 distinct task semantics** at x0=0. Deterministic SHA256 hash partition by `NEUMANN1_DIRECT_AST_V1|degree|a|c`, training iff first four SHA hex digits interpreted as integer modulo 4 != 0 (near 75%, rest prospective ID test). Never let held-out tuples into training data or normalization. OOD family 1: the held-out ID test tuples with x0=2 in both d=1/2, same learned model, **source-coordinate shift** absent from all training. OOD family 2: exactly 16×5 = **80 cubic** instances d=3 and x0=0, `a∈{-8,..,-1,1,..,8}`, `c∈{-8,-4,0,4,8}` (different degree outside neural output grammar). Classic C computes finite differences of five samples and can output L/Q/cubic; learned A/B may only emit L/Q. Track cardinalities and SHA of ID tasks, seed, training dataset, weights and outcome receipts.
