## 2. General source-identifiability theorem, exact conditional scope

**Theorem:** Fix unsigned width `w` and a finite set of source inputs `S ⊂ {0,1}^w`. For any unseen target input `t ∉ S` and any source-fitting executable function `F`, assume the admitted DSL supports
  1. extraction/Boolean AND of individual input bits and their negations,
  2. conjunction of the resulting Boolean tests,
  3. branch between the output of F and a provably different output transform such as full bitvector complement.

Then an executable *source-fitting function* `G` exists such that `G(s)=F(s)` for every `s∈S`, yet `G(t)≠F(t)`.

**Proof:** For every `s∈S`, because `s≠t`, there exists at least one input bit where they differ. Select any set `B` containing a separating bit for every `s`. Define `M_B(x) = ∧_{b∈B} [bit_b(x)=bit_b(t)]`. Then `M_B(t)=1` and `M_B(s)=0` for all source `s`. Let `G(x)=if M_B(x) then bitwise-NOT(F(x)) else F(x)`. Because bitwise NOT on fixed-width 64-bit words differs from every word, `G(t)≠F(t)`; every `G(s)=F(s)`. QED.

In the actual original benchmark grammar, bit extraction is expressible using `ehad` (logical right1), `arba` (right4), `shesh` (right16), `bvand`, `bvnot`, constant 1. The author's `im` function implements selection on a word equal to 1. The original solver's `let` abbreviations are local SMT sharing syntax rather than novel operators; their bodies can be inlined to yield expressions in the existing grammar. Greedy bit selection minimizes *heuristically*, not proven globally optimal. Independent Z3 confirms concrete full source obligations for 12 cases.

**IMPORTANT LIMIT:** This is a theorem about nonunique extrapolation under a **rich enough known grammar and finite observations**. It neither means every model's inductive prior has equal quality nor that no generalization is possible. Low-description-length hypotheses, neural learned priors and symbolic inductive bias can select plausible functions, but none is *logically forced by the finite IO alone*. This is not a proof of all arbitrary AI function behavior nor a way to learn hidden gold. It is mathematically invalid to report `the version space has only one next output` based only on three agreeing programs from such a grammar.
