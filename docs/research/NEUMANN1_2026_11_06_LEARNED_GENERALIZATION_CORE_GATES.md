## Generalization and representation separation

Let `H_cached` be the 7 frozen teacher programs, `H_old` the frozen classical candidate set, and `G_θ(x)` a **learned executable semantic proposal generator**.

- **Caching** picks `p ∈ H_cached`. P43 restricts this directly and its strict gate failed.
- **Reranking** picks `p ∈ H_cached ∪ H_old`. An exact finite search of the same class can decide all reachable candidates; a ranker cannot *invent* a program outside it.
- **Structure discovery** must permit `p ∉ H_cached ∪ H_old` with a genuinely new executable operator AST/relation, induced from source-only observations and verified on original independent targets. Novelty is relative to the **frozen candidate sets**, not a claim that no human has discovered that operator before.
- To attribute an improvement to **learning**, use a matched no-learning proposer `G_0` with **identical grammar, execution, original source data, prover rights and search budget**. Compare a strong GP/CEGIS/full native solver portfolio granted the SAME expanded representation, not a weak previous DSL.

## Immediate research change, ordered by minimum necessary compute

1. **Delete non-discriminative research loops:** more fixed-state protocols, source-authored finite-source W optimizations, simple OR-split on already-known VeryMax, cache-only teacher functions, extra public ARC-EVAL use, chasing model hardware before a proved discriminator.
2. **One fixed problem + proof contract:** select complete original tests with source license and creator independence. Freeze original file identities, holdout family, source hashes, negative controls, and strongest recognized solver baselines **before reading any new test bodies**.
3. **One learned structure-generation hypothesis:** model proposes typed executable ASTs or semantic inference rules, never task-ID outputs, teacher-source code fragments copied by reference, or pre-fixed opcode IDs. Every proposal includes runnable source representation with verification contract.
4. **Four equal-rights arms:** (A) strong classical full search including GP/CEGIS/specialist; (B) learned model direct; (C) same full NEUMANN route minus learning; (D) trained learned proposal + independent original checker. Require D valid original successes beyond both A and C, zero unverifiable accepts, and a truly new author/source family result. If not, mark a research FAIL; do not rewrite the test to pass.
5. **Meter total cost and automate only last:** training, inference, proposal decoding, original solver verification, source calls, retry and failover. Degraded `UNKNOWN` routes to A's classical-first solver, not an optimistic certificate. For the goal `C_discovery < η C_saved`, measure both sides in same units; if no advantage, retain classic only.

## Scientific hypotheses and early stopping

- **H1**: the learned proposer outputs an executable semantics not in frozen `H_cached∪H_old`. **Criterion:** at least one independently original verified candidate outside the frozen set, source-documented program and no task-ID leakage. If not, STOP G1 and fix generator, not selector.
- **H2**: the **learning itself** adds verified solves beyond the strongest same-rights classical and nonlearning controls on source-independent holdout. **Criterion:** ≥1 learning-exclusive independently original proof, with precommitted denominator and zero unsafe admits. If not, STOP G1 model training.
- **H3**: end-to-end total-cost advantage after training amortization. **Criterion:** exact measurement on common hardware, not source-query-only ratio. Target 10x only when equal capability and complete costs justify it; otherwise no 10x.
- **H4**: independent formalism generalization. **Criterion:** exactly the same *proposal learning mechanism*, with frozen weights/heuristics and allowed simple source adapter, works on a genuinely different semantic formalism; finite-state MQTT+TLS alone cannot satisfy it.

## Risks / degraded mode

- `Task origin` and `original producer` are not interchangeable: distinct filenames from the same publisher do not prove independent authorship.
- A public original may have been used in model pretraining. Clearly label original-public tests, nonblind external-authored tests and true unseen external task families separately.
- A learned policy that proposes expressions only inside the supplied finite DSL cannot claim a Q3 structure expansion, however well it ranks.
- Too many automated score runs contaminate the remaining original public ARC-EVAL: **389/400 already used, only 11 untouched** per [PR #650](https://github.com/yoonsj0305/NEUMANN/pull/650). Preserve those 11.
- All original verifier `UNKNOWN` / timeout / untrusted state bound / malformed AST must output **ABSTAIN**. Never infer a proof from a green workflow or a model generated plausible text.
- No dates, power, model training cost, tokens, electricity, CPU throughput or financial Idiot Index may be fabricated. Different runtime machines are not matched cost controls.
