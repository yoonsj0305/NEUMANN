# 새 작업: 관찰 조건부 프로그램 생성 — 첫 실행 결과

**클로드가 구현하지 않은 학습형 트리 생성기를 새로 구현하고 실행했다.
자기 생성 검증 집합에서는 학습에 의한 프로그램 생성이 확인됐지만,
원저자 SOURCE 24문제에서 추가 능력은 0건이었다. 원래 능력 가설은 FAIL이다.**

기준 `0d1baec723f249a62a901d100af6e941234a43ac`.
사전 계획: `SEMANTIC_PROGRAM_GENERATOR_PREREG_2026_11_12.md`.
원시 결과·모델 가중치·학습 경험: `../experiments/results/semantic_program_generator_20261112/`.
이전 검증기의 실행 함수는 재사용했지만, 이전 역분해 효과를 다시 성과로 세지 않았다.

## 1. 문제 재정의

이전 코드의 핵심 학습 대상은 ‘어떤 탐색 가설에 예산을 배분할까’ 또는
‘어떤 잠재 특징을 먼저 재사용할까’였다. 이번 질문은 다르다.
**TRAIN 입출력을 관찰한 학습기가 실행 프로그램의 재귀적 트리를 직접 만들며,
그 결과가 비학습 생성기·프로그램 재생·동일 문법 탐색·기존 솔버보다 나은가?**

새 코드는 `neumann1/semantic_program_generator.py`다. 54,442개 파라미터를
가진 MLP가 관찰과 부분 트리를 받아 기본 연산·변수·상수 토큰을 순차 생성한다.
Transformer나 사전 학습 모델, 프로그램 ID 선택, 고정 얕은 readout 목록을
사용하지 않는다. 문법 마스크는 타입만 검사한다. 출력은 실제 실행할 AST다.

## 2. 가정 파쇄

| 가정 | 판정 |
|---|---|
| 정책은 기존 후보의 순위만 배워야 한다 | 삭제: 프로그램 트리 토큰을 직접 생성했다 |
| 큰 사전 학습 코드 모델이 있어야 한다 | 삭제: 54,442개 가중치로 실제 학습·생성을 실행했다 |
| 유효 문법·학습 손실 감소가 발명 성공이다 | 삭제: 원래 TRAIN·TEST 정확성과 제거 대조를 요구했다 |
| 자기 생성 문제 30개 성공이면 원저자 일반화다 | 삭제: 두 결과를 별도로 기록했다 |
| 고정된 관찰 특징은 필요한 정보를 보존한다 | 반증: 서로 다른 20개 함수가 같은 벡터로 붕괴했다 |
| 원래 정답성·동일 권리 통제군·전체 비용 | 필수 제약으로 유지했다 |

## 3. 제1원칙 요소와 실제 학습

사람이 준 것은 실행 기초 연산, 타입 문법, 관찰 특징, 무작위 문법 샘플러와
학습 규칙이다. 시스템은 AST를 생성해 실제 실행하고, 그 입출력을 교사 경험으로
사용했다. 사람이 원래 과제의 완성 답 프로그램을 제공하지 않았다.

150,000회 문법 샘플에서 서로 다른 유한 관찰 행동 1,356개가 남았다.
그중 1,292개로 학습하고 마지막 64개를 사전 고정 검증 집합으로 남겼다.
16개 고정 입력에 대한 행동 해시와 정확한 교사 AST의 학습/검증 중복은 0이다.
이는 그 유한 입력에서의 분리이며 보편적인 의미 독립 증명은 아니다.

가중치 L2 변화는 46.7615, 학습 손실은 2.2964→1.5314 nats/token이었다.
실제 가중치 업데이트가 있었음을 확인했다. 손실 수치는 능력 판정에 쓰지 않았다.

최초 준비 실행은 불리언 출력에 `서로 다른 값 ≥3`을 요구하는 오류를 발견했다.
원래 문제나 검증 결과를 채점하기 전에 B는 ≥2, I/L은 ≥3으로 수정했다.
초기 8-epoch 실행과 가중치는 `readiness_v1/`에 보존했다. 최종 64-epoch 조건은
최초 채점 전에 고정했으며, 채점 후 데이터·학습량·모델을 바꾸지 않았다.

## 4. 새 시스템과 통제군

공통 인터페이스는 `invent(TRAIN, input types, output type)`다. TEST 인자를
받지 않는다. 별도 프로세스에 TRAIN과 빈 TEST만 전달했고, 제출 프로그램 파일을
고정한 다음 별도 구현의 해석기로 원래 TEST를 채점했다. 모델을 생산 엔진에
통합하거나 클로드의 작업 브랜치를 수정하지 않았다.

| 군 | 실제 구현 |
|---|---|
| C | 관찰 조건부 학습형 AST 생성 |
| U | 같은 생성기의 초기 가중치 |
| P | 학습 가중치를 유지하고 관찰 특징을 제거 |
| M | 학습 교사 프로그램 전체 재생, 편집 없음 |
| E | 같은 기초 문법·상수·변수 권리의 비학습 열거 탐색 |
| S | 기존 명세 공간 솔버 |
| V | 클로드의 최신 고정 역분해 솔버 |

군별 과제당 명목 process CPU 3초, 생성기 최대 2,048회 시도다.
시도 제한과 CPU 제한 중 먼저 도달한 곳에서 끝냈다. 후보 수를 실제 계산량으로
환산하지 않았다. 원저자 168개 작업과 자기 생성 448개 작업, 합계 **616개 작업이
전부 완료**됐으며 worker failure/timeout은 0이다.

## 5. 삭제·단순화·가속·자동화의 실제 결과

자기 생성 검증에서는 다음 결과가 나왔다. 원래 16개 관찰의 뒤 8개가 TEST다.

| 군 | TRAIN 일치 | TEST까지 정확 | process CPU 합계 |
|---|---:|---:|---:|
| C | 35/64 | **30/64** | 16.007초 |
| U | 3/64 | 0/64 | 41.711초 |
| P | 3/64 | 0/64 | 7.306초 |
| M | 4/64 | 0/64 | 11.171초 |
| E | 45/64 | 38/64 | 75.137초 |
| S | 57/64 | 49/64 | 36.929초 |
| V | 57/64 | 48/64 | 37.562초 |

C가 맞힌 **30개 AST 모두 정확한 형태로는 학습 집합에 없었다.**
세 제거 대조 U/P/M 각각에 대한 차이는 30:0, 양측 exact McNemar p는
1.8626×10⁻⁹다. 따라서 이 유한 자기 생성 영역에서 **실제 학습이 관찰에
조건화된 새 프로그램 생성을 만들었다**는 제한된 메커니즘 증거는 있다.
M의 완전 의미 재생 실패는 유한 행동 분리 설계상 예상되는 결과이며,
독자적으로 인상적인 일반화 증거로 삼지 않는다.

그러나 C는 E보다 총 8개, S보다 19개 덜 풀었다. 모든 강한 통제군을 합친
집합보다 C만 추가로 해결한 과제는 **0개**다. 이 결과를 압도적 지능이나
새로운 해결 원리의 발견으로 부르지 않는다. 새로운 문법적 AST와 새로운
보편적 원리의 발명은 다르다.

## 6. 원저자 과제와 전체 비용

기존 S가 실패한 rule SOURCE 중 ID 해시로 정한 24개를 변경 없이 실행했다.
자기 생성 검증 결과를 보고 고른 과제가 아니다. 기존에 열린 개발 집합이므로
새 독립 평가나 전이 성공으로 인정하지 않는다.

| 군 | 원래 TEST 정확 | process CPU 합계 |
|---|---:|---:|
| C | **0/24** | 13.416초 |
| U | 0/24 | 19.784초 |
| P | 0/24 | 2.984초 |
| M | 0/24 | 4.417초 |
| E | 0/24 | 69.230초 |
| S | 0/24 | 69.217초 |
| V | 1/24 | 63.947초 |

C의 원래 TRAIN 일치는 1/24였고 그 한 과제도 TEST에 실패했다.
대부분에서 새 프로그램이 원래 관찰조차 재현하지 못했다. C의 빠른 종료는
더 적게 계산해 같은 능력을 얻었다는 뜻이 아니라, 2,048회 시도 제한에 먼저
도달한 것이다. **원래 능력의 학습 독점 해결 0건, 사전 가설 FAIL**이다.

최종 자기 경험 생성·학습은 13.135 CPU초(생성 8.596, 학습 3.847 포함),
모델 파일은 204,036 bytes다. 최초 오류 준비 실행 10.471 CPU초도 별도 보존했다.
616개 비교 작업의 CPU 합계는 468.819초다. 이후 가중치 재구성 검사는
`reproducibility.json`에 별도 계상한다. 가중치 학습·추론·실패를 무료로 세지 않았다.

Idiot Index는 원재료와 제품 가격이 정의되지 않은 이 실험에 적용할 수 없다.
에너지·금전·전체 시스템 메모리·프런티어 상대 비용은 미측정이다.

## 7. 구조적 손실의 별도 증명

원래 과제의 0/24를 단순히 ‘작은 모델이어서’라고 판단하지 않았다.
새 생성기의 고정 관찰 함수를 별도로 검사해 다음 반례를 구성했다.

동일한 8개 큰 정수 입력에 대해 `f_j(x)=x+160·2^j`, j=0..19를 관찰한다.
20개 함수는 기초 문법과 48토큰 제한 안에서 모두 실행 가능하고, 같은 입력에
서로 다른 정답을 요구한다. 그런데 이 생성기의 수치 포화·통계 특징 때문에
20개의 관찰 벡터가 **바이트 단위로 동일**하다. 최대 차이 0.0, 모델의 초기
logits도 동일했다. 측정된 20개 AST·입력·해시는 `capacity_certificate.json`에 있다.

이 표현과 부분 트리만 읽는 생성기는 20개 과제에 같은 조건부 프로그램 분포를
가질 수밖에 없다. 하나의 프로그램은 동일 입력에서 두 가지 정답을 낼 수 없다.
따라서 과제 선택이 균등하고 난수와 독립이면 **첫 제안의 평균 정확도 상한은
1/20=5%**, 식별 정보 손실은 log₂20≈4.322 bits다. 가중치 수를 늘려도 이미
버린 정보는 되돌릴 수 없다.

이것은 **이 새 관찰 함수의 용량 제한 증명**이다. 원래 24문제 실패가 모두
이 충돌 때문이라는 인과 증명은 아니다. 또 raw TRAIN을 읽는 검증·전체 탐색은
틀린 제안을 거부할 수 있으므로 NEUMANN 전체나 무제한 탐색의 불가능성 증명이 아니다.

## 8. 큰 목표에 대한 의미와 리스크

| Q | 이번에 얻은 것 | 판정 경계 |
|---|---|---|
| Q1 | 생성·검증 CPU를 실제 계측 | 동일 능력에서 계산 절감 입증 없음 |
| Q2 | 별도 해석기로 모든 제출 답 검사 | C의 원저자 정답 0 |
| Q3 | 학습 제거·관찰 제거 대조와 새 AST 30개 | 자기 생성 범위만; 원저자 독점 해결 0 |
| Q4 | 실제 경험·학습·추론 비용 | 발견 능력이 부족하므로 유용한 비용 우위 없음 |

| Q7 | 프런티어 실행 없음 | OPEN |

고정 문법·손실성 인간 특징·무작위 문법 교사가 주는 의미 편향이 크다.
프로그램 문자열의 모방 손실은 실행 의미의 정확성과 일치하지 않았다.
유한 행동 중복 제거는 전체 의미 중복 제거가 아니다. 과제당 최대 관찰 길이·값
분포도 자기 생성 경험과 원저자 과제에서 다르다. 이 한 가지 실험으로
어느 원인이 지배적인지까지는 분리하지 못했다.

10배를 겨냥한 다음 선택지는 검증된 성과가 아닌 설계 후보다.

- 손실성 수치 통계로 관찰을 대체하는 요구를 삭제하고, 정확한 관찰·차이·관계를
  유지한 채 필요한 증거를 선택하도록 학습한다.
- 임의 교사 AST의 다음 토큰 모방 대신, 제안이 실패한 실행 위치·조건의 반례로
  프로그램 구성 방법을 학습한다.
- 강한 고전이 이미 푸는 부분을 제거하고, 학습이 실제 추가 능력을 만든 부분에만
  자원을 배분한다. 각 후보는 새 가설과 사전 조건 없이는 실행하지 않는다.

## 9. 최종 결정

**기존 클로드 실험의 재검증이 아니라 새 생성 메커니즘의 구현·학습·제거 대조를
완료했다. 제한된 학습형 프로그램 생성은 확인했지만, 원래 문제의 추가 능력은
얻지 못했다. 이 경로를 확대하거나 생산 엔진에 넣지 않는다.**

모델·경험·첫 결과·초기 구현 오류·실패·정확한 한계 증명을 함께 보존한다.
같은 원저자 TEST를 보고 가중치·교사 수·학습량을 늘려 재채점하지 않았다.
고정 손실성 관찰 함수를 ‘충분한 발명 표현’으로 쓰는 설계는 폐기한다.
새 아키텍처는 더 큰 모델을 선택하기 전에 이 정보 손실과 실행 의미 피드백의
단절부터 제거해야 한다. 전역 Q1–Q7은 모두 OPEN이다.

재현 명령은 `research/q3/semantic_generator_train.py`와
`research/q3/semantic_generator_study.py`에 있다. 후자는 첫 결과가 존재하면
덮어쓰기와 재실행을 거부한다. 별도 디렉터리의 가중치 재구성과 저장 모델 비교는
원래 과제 재채점과 분리했다. 검증: 새 생성기 인터페이스·실제 경사 업데이트·
체크포인트 테스트 4 PASS, 원래 비교 168/168 및 자기 생성 비교 448/448 완료.
