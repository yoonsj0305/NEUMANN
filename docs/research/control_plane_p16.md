## Architecture and scope

The unchanged frozen Gemma makes one bounded semantic-hypothesis call.
A deterministic surface normalizer consumes generated text alone, translates
predeclared notation classes to typed atoms, and invokes the unchanged P1.5
canonical compiler. Unchanged P1.3 admission gates the specialist. Only the
independent original-obligation verifier can accept the produced answer.

The normalizer never reads the original query, hidden reference, task family
or expected route. It cannot add a relation, restore a variable, widen a domain,
reverse operands, solve a missing constraint, guess ambiguous notation or retry
the model. It owns surface notation, not semantic repair.

Accepted CSP surfaces:
- explicit or bare integer domains: DOMAIN X 0 1; X 0 1
- explicit or bare comma-separated brace domains: DOMAIN X {0,1}; X {0,1}
- prefix or infix LT/LE/EQ/NE, including case-insensitive operator spelling
- equivalent symbols <, <=, =, ==, !=, and the registered Unicode LE/NE symbols
- finite known channel/plain/text/csp/arithmetic wrappers and whitespace

Variable names/case, integer values and order, relation order and left/right
operands remain fixed. Reserved variable names, chained or unsupported operators,
prose/comments, undeclared names, duplicate declarations, invalid bounds and
domain declarations after a relation are rejected. The already successful
arithmetic grammar, ordered accumulator and exact Fraction compiler are retained.

## Candidate semantics

A CSP hypothesis may narrow domains, even to a singleton complete assignment.
It is not required to preserve the full original solution set, and no subset or
equivalence certificate is claimed. Semantic narrowing is the model's charged
hypothesis, not work invented by the normalizer.

This diagnostic covers an existential task: return one complete assignment
satisfying all original domains and constraints. It does not cover enumerating
all solutions, proving uniqueness or accepting an intermediate hypothesis as a
proof. Missing variables, wrong fixed values and missing/reversed relations can
produce a rejected answer. The original verifier checks the complete original
obligation and never uses the hypothesis to manufacture its reference.
One candidate, one specialist attempt, one original verification; no repair,
resampling, search after rejection or architecture tuning on observed results.
