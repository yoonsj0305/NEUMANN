# NEUMANN 1 | ROOT-CAUSE POSTMORTEM AND CYCLE BREAK
**2026-11-06 | Authority: frozen North Star | Classification: diagnostic + engineering corrective action, NOT Q3/Q6 capability PASS**

## 1. Reframe the failed problem in measurable terms

NEUMANN 1 must produce *new executable problem-solving structure*, induced by **its own learned policy**, verified on independently authored original problems that a powerful equal-rights classical portfolio cannot solve, and with end-to-end resource savings. This is not equivalent to (i) choosing among already stored programs, (ii) generating palette/axis variants of one fixed operation, (iii) discovering a classical finite-state model when its representation and state ceiling are supplied, or (iv) scoring more existing public benchmarks.

The observed repeated failure is NOT principally lack of search iterations. It is **lack of semantic coverage plus insufficient learned acquisition of new semantics**. The public ARC evaluation denominator has additionally been contaminated across branches, and valid synthetic/local proofs have sometimes appeared more impressive than their actual scope.

## 2. Explicit diagnosis: what was the loop?

```
Limited manually specified hypothesis class H
     ↓
Increase search depth / ranking / caching / D4 palette or shape transform
     ↓
PASS synthetic checks, local query or candidate-count optimization
     ↓
Evaluate on actual original tasks; almost all H_D=∅
     ↓
Generate more transforms of nearly the same causal operator
     ↖ REPEAT
```

P1.0, P1.5, P2.5, P2.6, P43, P44 and P45 gave evidence for the SAME failure mode. **After P2.6 the research should have prohibited further variants of the same closed hypothesis universe unless a source-verified new semantic generator had been introduced.** Pursuing P44/P45 after P43, despite earlier STOP decisions, was an avoidable research-management error. The experimental data were recorded honestly, but they were not the highest-value next experiments.

### The logical blockage

For input/output examples D and frozen candidate space H, define
`H_D={h ∈ H | ∀(x,y)∈D, h(x)=y}`.

If `H_D = ∅`, optimizing the ranker, caching, W-method verifier, search beam, number of CPU threads or model size **without expanding H** cannot construct a valid program from H. The recent complete first-backed audit found `|H_D|=0` for 399/400 original public train tasks in the specific 1800 one-seed P45 grammar.

Symmetry/palette/color-mask closure of one primitive preserves its defining **causal topology**, namely one row/column first-last-marker interval plus one fill-color effect. Even a large orbit may have a tiny quotient of independent mechanisms. This is a fundamental representation bottleneck, not a throughput bottleneck.

## 3. What must be deleted NOW

- **HARD STOP:** single-seed P44/P45 family expansion, more color/rotation/marker variants, post-hoc retuning on their 400 opened tasks.
- **HARD STOP:** attempting to rescue P2.5 by deeper same feature tree, P1.5 via reranking the same candidates, or P1.4/P43 by copying more prewritten programs and calling that self-learning.
- **HARD STOP:** considering synthetic Mealy proof, L* W-method query compression, old 12/12 easy-classical surface or code-compiler success an unclosed Q3 neural discovery gate.
- **HARD STOP:** spending any of the remaining 11 original public ARC evaluation tasks on a candidate architecture whose structural proposal language is not genuinely new.
- **DELETE prestige metric:** 1→180→1800 program count, 1→720000 evaluated candidate/task pairs, green CI count or improved local CPU should not appear as primary capability evidence.

Retain immutable FIRST receipts, scoped positive classical methods, cheap proof verification and failures as historical evidence. **Do not delete contradictory first outcomes.**

## 4. Rebuild the actual minimum system

The new minimum innovation is **a *learned generator of candidate executable semantics*, not a selector of existing candidates**.

Input `X`: original TRAIN observations, prior failure certificates and original source/task constraints.

Output `p`: a typed, executable **operator AST** / program-schema not present in the frozen previous candidate family. The generator must be able to grow or recombine operation structure and introduce new candidate program shapes. A static prewritten finite instruction set may be used as an execution substrate, but success must not come merely from picking one of its previously exhaustively enumerated fixed source programs.

```
TRAIN I/O + task metadata
       ↓
Cheapest classical capability portfolio (including SAME expanded grammar)
       ├─ Independently solved at admissible cost → RETURN VERIFIED (skip NN)
       └─ genuine original unresolved residual → learned semantic proposal
                                          ↓
                              canonical typed executable AST
                                          ↓
             independent original-source runtime/proof + negative controls
                   ├─ valid, original task outcome → record first frozen witness
                   └─ invalid/UNKNOWN → ABSTAIN; classical fallback
                                          ↓
                            residual discovery feedback for learning
                                          ↓
                  frozen policy, different external-author task family
```

**Key scientific attribution:** the learned proposal must beat (1) stronger full search/GP/CEGIS with identical language and full source rights, (2) an otherwise identical untrained or learning-ablated generator, and (3) the classical-first portfolio on original verified outcomes and true combined cost. If any baseline can solve all the same cases more cheaply, delete the neural component.

### The only meaningful next experimental unit

One **unopened independently authored family** with pinned license/source, frozen actual strong solver baseline and independently verifiable original outputs. Candidate generator and its weights must be frozen before opening target tasks. Registered original test denominator, mutation controls, equal representation rights, total cost and STOP rule must be fixed first. Do not conflate *different file* with *different task author/semantics*.

Success ladder:

- **Mechanism PASS:** independently executable program outside the former fixed H and provably correct on its original task.
- **Learned discovery PASS:** the NEUMANN *own learned* proposer creates this program and an equal-rights classical/untrained proposer cannot match its original source success at registered compute.
- **Generalization PASS:** learned proposal mechanism transfers with frozen weights to a different source-author/formalism without retuning, original independent proof PASS.
- **10× category-change candidate:** matching original capability and actual measured all-in 10× advantage including amortized training, inference, search failures, verification, fallback, memory and energy where measured. Do not claim unmeasured resource axes.

Until those separate stages succeed, Q3/Q4/Q6/Q7 remain OPEN.

## 5. Musk-style execution sequence (not another generic roadmap)

1. **Question**: why must source problem solutions belong to H? They do not. Stop assuming every new problem is a variation of an existing source operator.
2. **Delete**: no more finite seed orbits/selector variants on opened ARC400, no more tiny synthetic self-approval tests as capability proof, no more fresh ARC evaluation burn without novelty.
3. **Simplify**: one typed proposal interface, one full same-rights classical baseline, one independent original verifier, one cost recorder; no new orchestration platform.
4. **Accelerate**: use symbolic representability checks to reject impossible H *before spending proposal/search compute*, and only spend learned compute on verified residual headroom.
5. **Automate LAST**: once one independent learned-exclusive witness exists, automate multiple cross-author holdouts and regression tests.

## 6. Economics and stopping criteria

`C_all = C_data + C_training/amortization + C_proposal + C_search + C_source_calls + C_verification + C_retry + C_fallback + C_operations`.

Never divide raw classical candidate evaluations by neural-only inference time, or pretend unmetered frontier-teacher generation is free. RC47 complete CPU 1.405× on synthetic tasks and RC48 trained mechanism 134.4× slower are warning signals, not global cost estimates. "Idiot Index" finished product/raw material price **does not apply** to a pure inference algorithm without product raw-material/accounting definition.

Stop at *one* failed gate without retuning its original holdout. Reopen on a new author-family only after a **material change in learned proposal structure** is frozen and independently reviewable. Deduplicate all cross-branch test manifests first. Use classical-first fail-safe/UNKNOWN default.

## 7. Risks, uncertainty and anti-overfit

- All ARC400 P43–P45 originals were already opened; no unbiased holdout inference. Public evaluation 389/400 are used; 11 untouched must be reserved.
- Any LLM teacher may have seen ARC public tasks in pretraining. Treat teacher results as external feasibility only, not NEUMANN own learning.
- A supposedly "new AST" relative to a frozen H may be ordinary under an equally powerful classical program-search baseline. Compare SAME language and rights.
- Finite examples do not uniquely identify a universal latent program. A sound original-task checker and honest ABSTAIN are required for high-confidence claims.
- Human-authored schema expansion is an engineer's design contribution, not a learned neural invention.
- Third-party original benchmark source does not guarantee independence from model training or author selection.
- Avoid conflating first-vs-posthoc labels, scoped proofs and global generalization claims.

## 8. Four real 10× innovation OPTIONS (not proven)

1. **Learn semantic *edits*, not program IDs.** Train a conditional generator of compositional AST rewrites from verified original counterexamples; compare against equally expressive GP/CEGIS.
2. **Learn reusable proof-carrying *schemas*.** Generate parameterized source programs with invariant proofs, amortize only after cross-author repeated applicability; classical proof stays.
3. **Minimal sufficient executable IR.** Search for quotienting and invariant discovery *before* program enumeration, with a source-proof that discarded variants are redundant. Counts alone are not capability.
4. **Classical-first with certified learned escalation.** If no independently verified learned-only headroom exists, NEUMANN should run as a lean classical solver without redundant NN calls.

**Preferred first path: Option 1, but only with the full original-source equal-rights comparison.** As soon as training or external independent holdout cannot be materialized, enter degraded `G1_HOLD_NO_NEW_CAPABILITY_CLAIM`, not more proxy research.
