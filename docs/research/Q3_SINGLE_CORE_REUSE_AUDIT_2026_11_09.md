## What was changed in this branch

- `neumann1/q3_single_discovery_core.py`: a single **task-agnostic** discovery policy sees SOURCE input-output and a bounded set of older SOURCE-certified executable methods; generated candidate program goes through the existing real isolated Docker source verifier. There is **no ARC/string/graph dispatcher, named author family, injected target operator or privileged TARGET label**.
- `SourceMethodMemory.admit` requires **re-execution** of all training and disjoint SOURCE verifier pairs. A source record SHA, program SHA and original identity are retained. Frozen memories never adapt on heldout observations. `import_source_teachers` revalidates prior #744 model-authored original-source programs. Caller may exclude source IDs to prevent known overlap.
- `NeumannEngine` and `RegistryEngine` now delegate their previously open-program invention entrypoint to the SAME core, optional persisted memory, same model object and explicit `source_identity`. Existing specialized components remain intact as measured comparators.
- One canonical `source_discovery_prompt` accepts the same memory input for B/C; no hidden task-family field. `q3_trainable_code_policy.py` already uses that function during neural training.
- Old generic generators and library extractors are **not deleted** pending proven equal-or-better new core capability. Avoid turning an unproved deletion into a regression.

## 3-arm falsifiable ORIGINAL Q3 experiment

Freeze source identities, model revision/adapter weights, verified method memory SHA, interpretable proposal interface, independent-original task IDs, candidate count, total runtime budget **before** independent original gold is opened.

- **A:** same pretrained model + strongest trusted classical specialist where available; no method memory.
- **B:** A + frozen proof-certified SOURCE method memory; **same pretrained model**, no learning.
- **C:** B + actual gradient-updated SAME model from earlier SOURCE-certified methods; no hand-added task or domain branches.

Use **two genuinely unrelated original-author semantic families** (e.g. algorithmic program synthesis and geometric object transformations, only if dataset/contamination audit permits). Score full untouched original tasks and sound verifier certificates; count positive C-exclusive wins over B AND strongest applicable classical baseline in **each** family, paired regressions, failures, abstentions, SOURCE verifier false positives and real cost. No capability pass from synthetic fixtures, same-family holdouts, training loss or source fit. Pre-register numeric thresholds before bytes. All earlier CodeARC study slices are POSTFIRST project-wide.

**Global Q3 stays OPEN** until the cross-semantic causal residual gate succeeds. A single core API, retrievable method memory, or a successful CI test is implementation evidence only. Q4/Q5/Edge/cloud work must NOT divert resources while Q3 remains blocked.

## Technical caveats and next bottleneck

1. In-context memory (B) is NOT policy learning. Actual weight update (C) must beat B, not just pretrained A.
2. Prior method memory must contain **sufficiently varied ORIGINAL SOURCE-certified algorithms**. Historical CodeARC model positives are sparse, mostly trivial. A small same-corpus LoRA pilot cannot establish general invention.
3. A trained full-program proposer may still prefer memorized common routines. Require new executable structure and original heldout correctness; independent authorship and semantic families matter.
4. SOURCE finite observations cannot uniquely identify arbitrary functions. The independent SOURCE verifier is a falsification gate, not a mathematical proof of unrestricted function equivalence.
5. Fall back to original-verified classical methods if known; otherwise abstain, never execute generated robotics/actuator control.

This branch intentionally does not introduce new domain-specific algorithm classes, reranking heuristics, reward shaping, or a new benchmark grading wrapper.
