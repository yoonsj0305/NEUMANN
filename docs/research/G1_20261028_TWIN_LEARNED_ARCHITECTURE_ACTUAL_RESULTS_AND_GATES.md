### What makes these findings a better target for NEUMANN

There is a strong **necessary but not sufficient architecture boundary**:
1. Represent coordinate symmetries and input roles explicitly; do not expect arbitrary opaque vectors to learn a physically irrelevant reference origin. The co-moving source mathematical equivariance is enforced by design.
2. A compiler/runtime must ensure well-typed finite executable AST and `EOS` termination; 231/3136 offered neural candidates were malformed. Proposed model changes cannot count malformed AST as a correctly verified output.
3. Incremental verified search / counterexamples and learned policy improvements need to discover **new semantics not enumerated in a token class**. Merely exposing variable-length multiplication did not discover degree4 after training1–3.
4. Respect minimum necessary computation. On these algebraic generated tasks a transparent complete classical finite-difference algorithm solves all sources **more accurately, with less measured CPU and no model training**, so spending more compute on another MLP/GRU is scientifically unjustified here.
5. Research G1 must reserve independent author-written unseen original tasks plus trained A vs shuffled B vs full same-right specialist strong CVC5/SMT/PDR, include source grammar, full semantic formal correctness and whole computation/human setup attribution. A new fancy neural generator alone cannot promote Q1–Q7.
