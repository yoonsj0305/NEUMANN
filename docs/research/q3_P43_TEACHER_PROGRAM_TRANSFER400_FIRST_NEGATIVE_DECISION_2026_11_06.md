## 4. Generalization decision

- **Real, narrow, cross-task source program transfer:** PASS in 1 of the 400 previously opened source tasks, **source-supplied program was not rewritten**.
- **Teacher function cache-as-policy hypothesis:** FAIL under fixed >=2 novel correct tasks and >=2 transferred functions threshold. A library of frozen functions that works on 7/8 teacher-origin evaluation tasks was almost entirely unhelpful to other public task input/output requirements.
- **No source semantic discovery learned by NEUMANN:** GPT-6 produced the original program 7 externally, and P43 only selects among them by exact train-fit.
- **No first-blind distribution claim:** Original public ARC-AGI training tasks and teacher public evaluation tasks may appear in pretrained model data, and 400 train tasks were already previously opened by the project. No source-author independent problem formalism was tested.
- **No calibrated capability gain from the `55` oracle union:** an actual safe disagreement/competence router is still absent; offline gold cannot be used as the selection oracle at inference.
