## Causal intervention: real Torch weights improve selection of a previously available executable AST edit class

Unlike the many preceding external-PROSE negative results, this new experiment **actually trains a CPU PyTorch model in two chronological stages** and compares (A) correct supervised structural-program labels against (B) labels shuffled across task inputs, with matched architecture and SGD update count, and (C) a stronger same-source-privileges **classical exhaustive program synthesizer**.

The 4 AST semantic families `affine(a*x+b), square(a*x*x+b), abs(a*x+b), max(0,a*x+b)` are **all predefined in the human-authored interpreter BEFORE training**. The network **does not invent any new primitive or full program syntax**. It classifies a structurally relevant *edit root* from four input/output examples and stores the learned bias **in model weights**. An independent classical parameter fitter freshly recovers unseen integer coefficients from the new task's four source examples. No task-ID lookup, no exact solved code storage at inference.

This is an **assistant-authored synthetic dataset**, not independently authored/heldout Microsoft PROSE and not a new semantic modality. The source coordinates are fixed `(-4,-1,1,4)` and five different input positions are used for score. Parent generator has a bounded coefficient grid. The 60 old and 60 new test task/parameter combinations are excluded from training. Models learn from **110 distinct Stage 1 old-family programs**, then **104 distinct Stage 2 new-family programs plus 30 old-family rehearsal programs**, 400 Adam update steps per stage, equal updates for A and sham B. Teachers and outputs are procedurally generated and verified; they are NOT authentic external verifier failures. There are only 60 distinct new TEST problems even after running five seeds.

## Decision

**Scope-specific verified result:** truthful later verified program examples change *actual model weights*, and learning to choose among already-defined structural edits improves future task solveability relative to a genuinely shuffled teacher. Rehearsal prevents some forgetting. This is one small necessary component of a model that gets more useful through experience.

**Not achieved:** autonomously inventing a new semantic operator unknown at training, transferring discovered representation across independently authored real domains, beating a classical solver, frontier-level solving with minimum computation, or proving a useful full-cost 10× margin. The cubic operation is intentionally absent and unsupported. Synthetic heldout parameter tuples are not equivalent to independent external benchmark authoring.

**Research spending gate:** DO NOT deploy this four-way network as a standalone NEUMANN discovery model. Next admissible study must train an actual *open-expression typed rewrite emitter* from diverse independently verified failures and compare A/target-shuffled B/matched strong C under new external benchmark authorship and unshared semantic operator families. Until then GLOBAL Q1–Q7 OPEN. Keep classical-first, source/feedback integrity, fail-closed predictions, and exact-solution-memory removal.
