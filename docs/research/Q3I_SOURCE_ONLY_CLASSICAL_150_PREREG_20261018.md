# NEUMANN Q3I: first 150-source label-free classical headroom survey, frozen before run

Date 2026-10-18 KST. This is one finite, already-opened development-corpus benchmark of a **classical** algorithm. It does NOT solve global Q3/Q4/Q7.

**Source selection frozen:** same 150 license-body-verified Apache-2.0/BSD-3-Clause original C programs in the prior Q3H official receipt (GitHub Actions #39083471496). Original Microsoft Loopy archive revision `91fe89245a0894ec8ad3741d85ae91ce3b552b2e`. The 150 source path+SHA identities must match the preceding 150 source-identity records; no best-case replacement or editing. The source-selection process may read Loopy's workbook **for file matching only**; the candidate generator, source parser and proof solver are passed **only original C program text + original C postcondition**, never published invariant strings or goal answer labels. The final outputs may compare source group names, not invariant ground truth. This is not a truly hidden benchmark; all Loopy examples already existed in Q3G data.

**Algorithm frozen:** exact code `source_only_houdini.py` at PR #194 HEAD, using fixed source literal/binary comparison, source branch guard-conditional atom grammar. No added proof rules, full program modification, training or heuristic adjustments. For each of the 150 originals, original-source SHA checked, run unmodified candidate_proof; bounded source grammar <=500 candidates, Z3 1300ms per candidate solver check, fail closed for unsupported/unknown/errors. Record all original safety, induction, signed overflow and two counterchecks. Explicitly group by original source family. Run at most one full first evaluation.

**Comparable dev-heldout group subset fixed:** source groups `dataset/loop_invariants/LinearArbitrary-SeaHorn/VeriMAP` and `dataset/loop_invariants/sv-benchmarks/loop-lit` (the 32 in prior Q3G neural heldout after target-length cap). These cases are **not** independent validation of this classic algorithm, whose underlying graph and three examples were already developed with Loopy source groups. Group counts and proof wins are recorded without claiming neural comparison at identical information/outputs.

**Success definition:** proof success requires returned `SOURCE_ONLY_AUTO_INVARIANT_CERTIFIED` with independent original init/consecution/exit/signed overflow `UNSAT` and falsified goal and empty invariant `SAT`; zero missing obligations. Count every unsupported/error/rejected as no proof, never as UNSAFE. The study accepts observed results regardless of wins, including zero. CI PASS only certifies test completed and audit integrity, NOT any scientific positive count.

**Stop loss:** The 150-source headroom result will decide whether classical-first covers many truly licensed original cases. Do not build a neural surrogate to reproduce trivially solved source-only cases. If at most the three old wins prove, label generalization as limited. Global Q1–Q7 OPEN. Q3F benchmark source bytes remain unopened in this project.
