# 구조 생성 기반·외부 문제 후보·실제 CPU 실행 확인

2026-10-06. North Star와 Q1–Q7, 과거 결과, Decision 3 봉인은 그대로 유지한다.
이번 작업에서 학습 모델이나 GPU를 실행하지 않았다. **압도적인 우위나 새로운 지능
메커니즘을 달성했다는 증거는 아직 없다.** 알려진 구조 변환을 위한 검사·실행 기반을
구현하고, 동일한 기반을 강한 기존 알고리즘에도 제공해 남는 연구 여지를 확인했다.

## 실행과 결론

| 확인 범위 | 실제 관측 | 판단 범위 |
|---|---|---|
| 정수 표현 변환의 증명 검사 | 18개 프로그램, 216/216 원래 목표 통과, 잘못된 공통 인수 증명 72개 거절 | 알려진 정수 규칙 조합을 안전하게 검사하는 기반 |
| 새 검사기와 기존 다항식 검사기 | 유효 변환 12개에서 검사 비용 기하평균 8.4037배 개선 | 동결한 구성요소 10배 조건 미달; 전체 추론 우위와 구분 |
| 표현 변환 전체 첫 query | 강한 native / 무료 표현 비용 기하평균 0.3957 | 이 범위에서는 기존 경로가 약 2.53배 빠름 |

각 단계는 성능을 보기 전에 별도 계약을 저장했다. 이전 계약의 판정 기준이나 원본
보고서를 바꾸지 않았다. 이 작업들은 한 후보군의 구성요소 및 실행 확인이며, 새 G1
성능 평가나 여러 독립 분야의 지능 증거가 아니다.

## 구현한 재사용 기반

`public_rewrite_search.py`는 원래 프로그램만 받아 ADD_ZERO, MUL_ONE, MUL_ZERO,
FACTOR_COMMON을 제한된 횟수 안에서 적용하고 원래 목표의 변환 증명을 반환한다.
인수 공유가 성립하지 않으면 해당 변환을 만들지 않는다. 알려진 규칙의 결정론적
기호 탐색이며 NEUMANN의 학습된 관점 생성으로 부르지 않는다.

`contraction_structure.py`는 equation/shapes만 native에 허용한다. 각 경로에서 아직
필요한 인덱스와 원래 출력 인덱스가 보존되는지 확인하고, opt_einsum과 연산량 모델을
대조한다. 이는 수학적 sum-product 계산 순서의 검사다. IEEE 결과의 비트 동등성이나
원본 데이터의 정답을 증명하는 것은 아니다.

`cotengra_baseline.py`는 cotengra 0.8.2의 공개 탐색과 subtree reconfiguration을
직접 재사용한다. 여섯 seed/설정 모두 공개 구조만 사용했다. 학습·oracle 접근·전역
최적성 주장은 없다. opt_einsum 3.4.0과 autoray 0.11.0도 고정했다. 정확한 wheel,
라이선스를 보존했고 각각 설치 파일 28/60/12개가 wheel 바이트와 일치했다.

텐서 경로 최적화는 이미 연구된 분야다. 비교의 출발점은 [Einsum Benchmark 논문](https://proceedings.neurips.cc/paper_files/paper/2024/hash/b1bbfdb9197bfc819a52c34dce493f85-Abstract-Datasets_and_Benchmarks_Track.html),
[opt_einsum 경로 탐색 문서](https://dgasmith.github.io/opt_einsum/paths/introduction/),
[cotengra 원 연구](https://arxiv.org/abs/2002.01935)다. 기존 성과를 재사용해 낮은 비교군으로
생기는 잘못된 우위를 제거했다.

## 외부 자료의 정확한 범위

원본 Einsum Benchmark의 168개 데이터 전체를 다운로드하거나 실행한 것이 아니다.
`tensor4all/strided-rs-benchmark-suite`의 고정 commit
`05506112eb40f7cff7ac102689614c180a7d6120`에 있는 14개 파생 JSON을 사용했다.
MIT 라이선스와 원본 archive를 보존했고 JSON 14개를 archive와 대조했다.
원본 텐서 값과 원본 정답은 확보하지 못했다. pickle은 다운로드·실행하지 않았다.
제공된 opt_size/opt_flops 경로도 전역 최적 경로라고 가정하지 않는다.

## CPU 측정 계약과 한계

이미 열린 `lm_batch_likelihood_brackets_4_4d`의 84개 tensor 구조에 float64 양수
uniform [0.5,1.5] 입력을 seed 세 개로 생성했다. NumPy/BLAS thread 1, 같은 executor,
같은 구조 검사·컴파일 권한, 같은 세 입력 간 경로 재사용 권한으로 비교했다.
원본 벤치마크 수치 평가나 새로운 구조 일반화 평가가 아니다.

| 경로 | 첫 작업 중앙값(초) | 실제 세 작업 합계 중앙값(초) |
|---|---:|---:|
| 기존 탐색 결과를 가진 native 절차 캐시 | 0.315638 | 0.938503 |
| 공개 auto-hq 탐색 후 실행 | 1.161017 | 2.430404 |
| 공개 cotengra RECONF32 탐색 후 실행 | 4.178424 | 4.789038 |
| 제공된 경로를 무료로 받은 낙관적 경우 | 0.186964 | 0.552515 |

public greedy는 예측 중간 상태 약 68.7 GB, 연산량 모델 약 1.0094e12로 실행 전
동결한 자원 예산을 넘었다. 세 관측의 탐색·제외 비용을 보존했다. 원본 보고서의
`complete=false`, 빈 종합 ratio는 그대로 둔다. 위 비율은 모든 반복이 통과한 eligible
경로만을 대상으로 별도 저장한 **사후 기술 통계**이며 합격 판정으로 사용하지 않는다.

첫 작업 비용에는 경로 발견 또는 기존 캐시 파일 읽기·해시, 구조 검사, 컴파일, 입력
검사, kernel 실행, 전체 출력 비교가 포함된다. 모든 경로가 실제 다른 값의 세 입력에
절차를 재사용한다. 수치 허용 오차는 실행 전 rtol=1e-10/atol=0으로 고정했다.
두 제공 경로의 전체 출력이 일치했고 영 출력·잘못된 형태를 거절했다. 별도 replay에서
입력 seed를 재생성하고 36개 witness를 다시 수치 실행해 확인했다. 같은 NumPy 계열
계산을 쓰므로 독립적인 원본 정답이나 모든 입력의 수치 안정성 증명이 아니다.

native cache의 이전 여섯 경로 탐색 투자 23.397583초는 별도 기록한다. 제공 경로의
연구 투자 비용은 UNKNOWN이다. 무료 경로 비용만으로 총자원 경제성을 주장하지
않는다. 데이터 생성·참조 실행·I/O·전체 연구 시간도 보존했고, 원본 측정 27.211305초다.
에너지, 실제 peak RSS/VRAM, 금전 비용은 측정하지 않았다. 이 제한된 seen 구조의
cache 비교로 미관측 구조에서 학습된 발견의 비용 이점까지 기각하지 않는다.

## 증거 보존과 다음 판단

`Continuation/STRUCTURAL_SCREEN_FIRST`, `CONTRACTION_CHALLENGE_FIRST`,
`CONTRACTION_KERNEL_FIRST`와 각 PREPARATION을 유지한다. 첫 screen replay는 원래
216개 관측·1,152개 입력 행·89개 경로와 외부 출처를 재검사했다. 첫 replay의 보고서
합산 순서 오류도 실패 기록으로 보존하고 replay만 수정했다. 추가 audit는 challenge
8개 파일·6개 경로, calibration 45개 파일·36개 수치 결과·3개 제외를 재검사해 PASS다.
코드와 기존 표현·증명·기호 탐색을 함께 검사한 pytest 47개가 3.04초에 통과했다.

32개 원본 case를 출처·hash·D/O 투영으로 등록했다. 전부 opened 개발 자료이며
training activation=false, fresh eligible=0이다. 모든 원본 H 결과는 유지하고,
실험 의사결정 ledger와 이어가기 문서에 실제 관측을 반영했다. 원격 GitHub push,
Notion 수정, GPU 학습, 봉인 평가 접근은 이번 작업에 없다.

현재 중단할 투자는 이 단순한 알려진 인수 변환이나 이미 열린 텐서 한 구조를
신경망으로 선택하게 만드는 학습이다. 보존할 기반은 목표 보존 증명, 공개 구조 상태,
강한 선행연구 비교군과 절차 재사용이다. 다음 핵심 질문은 **미관측 구조에서 새 표현을
학습·생성하는 것이 동등한 재사용 권한을 가진 기존 탐색보다 전체 비용을 줄이는가**다.
후속 학습 전에 그 여지를 독립적으로 의미 있는 문제 영역과 강한 비교군에서 사전 등록해
확인해야 한다. 알려진 최적화나 검사기 단독 개선으로 North Star를 낮추지 않는다.
