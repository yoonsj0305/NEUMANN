# v0.0.96 — Q34 reset and early-compression representation ceiling

## Purpose

v0.0.96 is the first version after the local-tuning phase. It does not train a
new model. It asks a high-information binary question using only the retained
v0.0.94 opened-input archive:

**Is early 2m support compression itself the dominant information bottleneck,
or does the frozen discoverer still fail when early compression is removed?**

This is a representation-ceiling diagnostic before any architecture tournament.

## Frozen evidence

Use only:

- `docs/experiments/results/v094_first_probe.manifest.json`,
- the exact v0.0.88 parent opened training sources already referenced by that
  archive,
- the frozen v0.0.94 point/full/compact proposals and original-LP certificate
  outcomes.

No new fitting, inference, optimizer/solver call, timing, dataset generation,
checkpoint selection, holdout, or parameter sweep is permitted.

Hidden label bases are offline diagnostic information only. Original-LP
certificate acceptance remains the stronger authority.

## Compared contracts

For each seed and each of 48 opened inputs:

- **early compression ON representation**:
  the point selector's 2m `selected` support before graph refinement;
- **early compression OFF representation**:
  all n input columns available to the same frozen full graph route;
- **full graph shortlist**:
  the frozen full route's top2m output after processing all n columns;
- **compact graph shortlist**:
  the frozen compact route's top2m support;
- **exact-m proposals**:
  point, full and compact candidate certificates already retained.

The representation ceiling measures whether the hidden reference basis is
contained in / recoverable from the support. It is not a deployment metric.

## Frozen diagnostic thresholds

The Q34 utility floor is 0.80. Therefore a seed has an adequate early-support
ceiling only when at least 80% of the 48 cases contain the complete hidden
reference basis in the 2m selected support.

A **full-information rescue** of the current discoverer requires the early-OFF
full route to produce at least 4 additional original-LP-certified exact-m
proposals out of 48 relative to the same seed's compact route.

Decision table:

1. if either seed's early-support full-basis containment is <80%:
   `EARLY_REPRESENTATION_CEILING_BELOW_Q34_FLOOR`;
2. else if both seeds gain >=4 exact-m certificates with early compression OFF:
   `FULL_INFORMATION_RESCUES_CURRENT_DISCOVERER`;
3. otherwise:
   `DISCOVERER_BOTTLENECK_DOMINATES_EARLY_SUPPORT_LOSS`.

These are diagnostic routing decisions, not a Q34 pass and not a Q3/Q4
scientific closure.

## Consequence

- Case 1: tournament must include an uncompressed/full-information family and
  the compact representation is not entitled to training.
- Case 2: early compression timing is the primary suspect; tournament tests
  full-information versus compact under the Q34 cost gate.
- Case 3: do not spend more versions shifting the pruning point. The existing
  representation already preserves enough oracle structure; tournament effort
  moves to genuinely different discoverers/authorities.

Q3 and Q4 remain OPEN. Q34 remains unpassed until a separately preregistered
complete-cost architecture evaluation clears the joint gate.
