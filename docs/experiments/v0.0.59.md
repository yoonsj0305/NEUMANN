# v0.0.59 — Bounded affine elimination against native LP presolve

Status: **exploratory instance, frozen test protocol before first paired full
timing**. `binkar10_1` was selected after inspecting MIPLIB's metadata,
its MPS, HiGHS native presolve shapes, and its degree-one equality structure.
This is not a blind holdout. The original MIP took longer than a 20-second
exploratory HiGHS limit; therefore this experiment explicitly tests its
**continuous LP relaxation**, not MIP optimum or fixed MIP capability.

## Instance, transformation, and comparator

The only source is the original MIPLIB 2017 `binkar10_1.mps.gz`, pinned to
SHA-256 `94282c38edd6c83bb6c2d788d823fd82f218218e8e07c98d1d1ab42c1e91039e`.
Use HiGHS 1.15.1, one thread, disable output. Relax all integrality in both
paths before measurement; parsing/relaxation is a shared, excluded input
cost. The fixed native baseline passes the unmodified relaxation to HiGHS
with presolve enabled, solves it and independently checks original bounds,
equations and objective.

Candidate: for each original equality in row order, choose the lowest-index
continuous variable that occurs in exactly that row, at most one per row.
Substitute it into the objective, remove its equality and column, translate
its original variable bounds into a bound on the remaining row expression,
then reconstruct that variable from the retained answer. No integer claim is
made. The candidate checks row uniqueness and all source coefficients/bounds,
uses HiGHS with its native presolve **enabled** on the reduced LP, and
independently verifies the answer and objective on the full original LP.
Failed transformation or verification fails closed to a native original-LP
solve; all failed candidate work is charged. No ground-truth objective or
timing data enters the selection rule.

Run one warmup per path, then seven paired alternating repetitions. Time
from the shared original `HighsLp` through copy/passModel, candidate
discovery/construction/certificate check, native presolve and LP solve,
reconstruction, independent original checks. Common MPS I/O and integrality
relaxation are excluded for both. Report objective agreement <=1e-6
relative to max(1,|baseline objective|), original primal bound/row violation
<=1e-7 relative to each row's max(1, absolute coefficients and bound), all
solver statuses optimal, and matched seven trials. Any failure invalidates
the performance decision. Report original/reduced dimensions, nonzeros and
transformed rows, as well as full-path median candidate/baseline ratio.

Decision: **ONLY** if the validity contract holds and candidate full-path
median is at least 20% faster than native baseline, label this one LP
`LOCAL_COMPRESSION_ADVANTAGE`; otherwise `NO_LOCAL_ADVANTAGE`. A local pass
would still require an independently selected workload and stronger solver
comparison before a general runtime route. No energy, learned discovery,
MIP speedup or cross-domain scaling claim follows from this experiment.
