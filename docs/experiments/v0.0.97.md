# v0.0.97 — First Q34 support-system tournament

## Question

After v0.0.96 showed that the 2m representation already preserves almost all
reference-basis information, can a complete support-discovery system recover
most oracle structural savings cheaply enough to beat Direct under equal
original-problem verification?

The preregistered gate is in
`v0.0.97-preregistration.md`. No new model fitting, checkpoint selection,
final data, or hyperparameter sweep is used.

## Scope and accounting

- first 16 already-opened v0.0.88 training inputs;
- Direct, nondeployable Oracle, deterministic support, point support,
  full-information support, and adaptive support;
- 1 warmup + 3 retained timed repetitions per case/route;
- 576 observations total;
- every accepted answer requires the same original-LP certificate;
- learned routes pay `(training_setup + own fit) / 10000` per query;
- failed restricted attempts and fallback are charged;
- no clean memory, energy, natural-workload, or domain-general claim.

The reference Direct total over per-case medians is **541.979956 ms**.
Supplying the exact oracle basis for free leaves **49.706681 ms** of post-
discovery execution/verification, so the available oracle savings are
**492.273275 ms** and the oracle post/Direct ratio is **0.0917131**.

This is the first clean evidence in the current LP line that a small learned
support proposer can be cheap enough relative to the structural savings it
unlocks **when the solver is asked to finish the problem rather than the model
being forced to predict the exact basis**.

## Boundary

This is development data from a constructed LP family. It is **not** a global
Q34 pass, not a Q3/Q4 closure, and not evidence of frontier-model equivalence.
Q3/Q4 remain analytically OPEN.

No tuning on these 16 inputs is permitted. Carry only the frozen B_POINT
contract and both frozen seeds into a separately preregistered fresh Q34
holdout. If that passes, advance this LP mechanism to Q5 scaling/cross-domain
tests rather than polishing Q3/Q4 locally.
