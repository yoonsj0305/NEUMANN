# v0.0.60 — Original MIP capability at a fixed total-compute gate

Status: **nonblind single-instance protocol**, freeze before the first full
paired audit. The source, incumbent objective, 20-second native timeout,
LP-relaxation transformation and its negative timing are already known from
v0.0.58–59. The chosen target is calibrated to that exploratory native run;
it is not an independently chosen holdout or evidence of a general speedup.

## Scope and baseline

Use exactly the hash-pinned original `binkar10_1.mps.gz` from v0.0.59,
HiGHS 1.15.1, one thread and native presolve enabled. **Do not relax the
integer variables.** Original MPS parsing is a shared excluded input; the
complete timed path begins with the original `HighsLp`, creates/passes each
model, runs HiGHS, reconstructs any removed variables, and checks original
linear rows, column bounds, integrality and objective. Both paths must retain
identical objective sense, numerical tolerances and solver options.

The candidate adapts the exact v0.0.59 affine rule: only continuous columns
with degree one in an equality can be eliminated, with original bounds
translated into row bounds and original objective coefficients substituted.
All retained binary/integer declarations must be passed to HiGHS unchanged.
For every accepted result, the reconstructed answer must pass an independent
original-model primal check (scaled bound/row violation <=1e-7), original
integrality violation <=1e-6 and objective reconstruction versus the solver
reported incumbent <=1e-6 relative. A failed proposal falls back to the
original MIP and retains its discovery cost; an unsafe reconstructed answer
raises an audit error without accepting it. Preserve the error rather than
inferring advantage or silently skipping the case.

## Fixed capability and cost

Set HiGHS relative MIP gap threshold to **0.003** and solution objective
ceiling to **6742.21** for this minimization problem. These targets are
chosen after the earlier native 20-second exploratory run returned objective
6742.200024 and gap 0.002572. The explicit condition is a feasible original
solution no worse than the ceiling plus a native solver dual-bound gap no
greater than 0.003. No local objective-only success is allowed. Each path
gets a **20-second total budget including preprocessing and verification**;
reserve one second for model transfer, reconstruction and verification, and
pass at most `19 seconds minus elapsed candidate construction` to HiGHS.
Recheck the actual measured
complete-path time against that budget. Stop at the gap threshold if HiGHS
reaches it earlier. The comparison is time-to-fixed-capability, not optimal
MIP solve or a mere fixed-time quality comparison.

Run one discarded warmup for each path, then **three alternating pairs**,
native-first/candidate-first/native-first. Record complete time, candidate
construction time, achieved original objective, primal/integrality errors,
native dual bound, relative gap, status, nodes and whether the target was
reached. Abort a run after the budget; keep invalid/censored trials. The
candidate wins only if all six trials reach the same capability, all three
candidate trials verify original constraints and integrality, and its median
complete time is at least **20% lower** than native. Otherwise report
`NO_LOCAL_MIP_ADVANTAGE` or `INVALID_MIP_TRANSFORMATION` for an unsafe result.

No trained model, external data subset, retry-tuned threshold, optimized
post-result rerun, energy or cross-domain scaling claim follows from this
single already inspected instance. In particular, a ratio observed near a
short timeout is sensitive to branching variability and one-machine noise.

## First complete paired audit (after local freeze `15540e4`)

`results/v060_first_audit.json` preserves all three alternating pairs.
All six returned original-MIP feasible incumbents with scaled primal and
integrality violations at most `1.11e-15`; the candidate removed 763
continuous variables while retaining all 170 original integer variables.
No candidate fallback occurred. **But none of the six met the frozen
capability target.** Native HiGHS stopped at its requested 0.003 gap with
original objective `6747.310015` (three times); the candidate stopped at
the same gap threshold with original objective `6746.760023` (three times).
Both exceed the required 6742.21 ceiling.

The native/candidate complete-path medians were 7.893/10.028 seconds, a
candidate/native ratio of 1.271. This is a recorded diagnostic, **not a
valid fixed-capability cost ratio**, since the conjunction of objective
ceiling and dual-bound gap was never reached by either path. The evaluator's
frozen label `NO_LOCAL_MIP_ADVANTAGE` means the pass condition failed; it
must not be read as evidence that the candidate loses at the intended
capability. The earlier 20-second native exploratory objective was obtained
without the new 0.003 early-stop rule, making the chosen conjunction
internally mismatched. Do not silently edit this result or cherry-pick one
of the six runs.

Decision: **CAPABILITY_GATE_UNREACHED** (interpretation of the frozen
fail-to-pass label). A separately versioned and openly corrective protocol
is needed to assess iso-capability cost. Any threshold selected after these
observations must be identified as post-result calibration.
