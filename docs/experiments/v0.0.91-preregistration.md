# v091 — remove least-squares input construction, then retrain once

Publish before fitting/timing. Only the 48 opened v088 train sources are used;
the first 16 are an explicitly in-sample development screen. No old final
inputs, new generated inputs, holdout access, tuning, best-epoch selection or
favorable reruns. Pin the old JSON SHA256 and the v087 runtime/HASWELL BLAS.

Replace both least-squares input fits with column-normalized observable moments,
cost, centered cost, and b correlation. Eight row/column features, all finite,
computed from A,b,c only. This changes information as well as cost; retrain from
the original initialization rather than silently reuse incompatible weights.
Same four architectures and seeds 87001/87002; 48 examples, 12 epochs, Adam .001,
same basis/primal/dual supervision, shuffled fit order, 240-second/model cap,
last epoch only. Compact16 genuinely removes states/edges after the first update;
full16 retains them and is the no-compression/Direct control. Point16 and full128
remain equally executable Direct alternatives. Every weight/checkpoint is retained.

Screen all 12 old classical routes plus cheap cost/correlation top2m controls,
and all eight newly trained models. Every model uses its full forward followed
by refined top2m selection and the shared restricted native executor, full
original numerical certificate, and paid full rescue. No predicted answer
shortcut for any new model. Classical methods retain their allowed features
and tools. Training setup/fit, proposal and execution costs are paid.
22 routes x 16 cases x (1 warmup + 3 timed repeats) = 1408 calls; deterministic
shuffle 91991+repeat; one thread, five-second deadline. No concurrent tests.

Both compact seeds must have all observations certified, geometric mean ratio
<=.8 against per-case best classical, best noncompact learner across both seeds,
own full16, and classical with training amortized at 10000 queries. Require
>=12/16 individual 20% wins for each of the first three comparisons and
>=12/16 cases without full rescue on every repeat. A pass only admits a NEW
separately preregistered holdout; it cannot close Q3/Q4. Failure stops this
specific cheap-feature/architecture/fit candidate. It does not prove all cheap
features unlearnable. Native remains default and previous negative finals stay.
