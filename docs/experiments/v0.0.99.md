# v0.0.99 — Equivalence-quotient point representation passes the pre-fit gate

## Purpose

v0.0.98 failed its fresh Q34 conjunction on the larger size + surface-shift
cell because structural utility recovery fell below the frozen 0.80 floor while
discovery remained cheap. That holdout is sealed and is not used here.

v0.0.99 asks a cheaper, higher-information question before any new fit:

> can known solution-preserving surface degrees of freedom be removed from the
> point representation itself?

The audit uses only the already-opened 48 v0.0.88 training inputs and analytic
metamorphic transformations. No v0.0.88 final data and no v0.0.98 source or
evaluation archive is loaded.

## Frozen equivalence audit

For each opened input, three label-free equivalent views are generated:

- signed row permutation,
- positive column scaling with matched objective scaling,
- their composition.

The current CG5 representation is compared with a preregistered quotient
representation. No label, oracle basis, solver, fitting, optimizer, timing,
fallback or Q34 performance metric is used.

The quotient representation keeps the first four CG5 column observables and
replaces two surface-sensitive slots with:

- `|D_j|^T |b| / max(1, ||b||_2)`;
- `||D_j||_1 / sqrt(m)`.

## Frozen admission gate

The representation is admitted to a later opened-development refit only if:

1. maximum quotient-feature drift over 48×3 equivalent views <= 1e-8;
2. every one of the first six channels has global standard deviation > 1e-8;
3. the dimension-normalized slot-6 median ratio for m=32 versus m=64 <= 1.20;
4. all values are finite.

### Current CG5 diagnosis

The current representation is almost invariant in seven channels, but the
signed `D.mean(0)` slot moves by as much as:

`0.1723346053014952`

under the equivalence views.

The two frozen point16 selectors preserve their exact top2m support on only
48/144 transformed views each, an exact-support rate of 1/3. Mean Jaccard
similarity remains high, 0.99219 / 0.99689, so the issue is not wholesale
randomization; it is a small but systematic surface sensitivity in a support
decision where a few columns can matter.

All candidate values are finite.

## Decision

`ADMIT_QUOTIENT_POINT_REFIT_ON_OPENED_DEV`

The representation gate passes before training.

This does **not** show that a model trained on the quotient representation will
recover more structural utility, does not pass Q34, and does not advance to Q5.
It authorizes exactly one next step: a separately preregistered refit/evaluation
using opened development + metamorphic data only.

The sealed v0.0.98 24-case holdout remains unavailable for tuning or re-test.
Any future confirmation after development must use a newly registered holdout
with new seeds.
