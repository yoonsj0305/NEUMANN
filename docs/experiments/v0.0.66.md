# v0.0.66 — DC power-grid N−1 structural reuse protocol

Status: **protocol frozen before timing**. The external case is MATPOWER's
IEEE 118-bus `case118.m` from `MATPOWER/matpower`, source blob
`7c60c62743e570fbc142968874b14692338e26b6`, local SHA-256
`bc2e6f22b4b9e776572885ee4b50e4f4ab2ee0c5577e9126e86d906f14c4b5f7`.
The file is read locally and never redistributed: MATPOWER's BSD license for
code does **not** automatically cover its case files. This is a standard
test network, not measured field operation. It has 118 buses and 186 active
branches. The DC approximation ignores reactive power, losses and thermal
limits; it is not an AC contingency safety assessment.

## Single hypothesis and gate

With injections and slack fixed, removing one active branch changes the
reduced DC bus matrix by one rank-one term. Reusing one factorization across
all connected single-branch outages should lower the total verified solve
time compared with rebuilding and factoring each outage independently.
Require the candidate median complete-path time to be at least **20% lower**
than the repeated SciPy SuperLU baseline over seven alternating trials,
with all connected outages satisfying the same original-outage relative
residual <=1e-10 and angle difference <=1e-8 radians. Otherwise record
`NO_LOCAL_REUSE_ADVANTAGE`. This is a mechanism gate only; the stronger
MATPOWER PTDF/LODF specialized method is established prior art and is not
timed in this study. Passing cannot establish NEUMANN novelty or supremacy
over that specialized comparator.

## Interfaces and accounting

Parse bus/branch/generator numeric tables from the hash-pinned case file,
reject unsupported status, nonpositive reactance, phase shifts, nonconsecutive
bus IDs or multiple slack buses. Set injection at each bus from recorded
generator Pg minus Pd, divided by baseMVA; drop the slack equation. Form the
DC matrix from branch incidence `c`, susceptance `1/(x*tap)` with zero tap
treated as one. The same original matrix and RHS serve both paths. Neither
arm runs AC power flow or optimizes generation.

Every trial includes reduced-matrix construction, topology screening,
factorization(s), all connected-outage solves, full angle reconstruction,
and independent residual checking against each original outage matrix.
External file fetch and MATLAB syntax parsing are common excluded I/O.
Use one discarded complete warmup and seven paired trials in alternating
order under one process with BLAS threads pinned to one. Compare full-batch
medians, report every raw time, numerical error, counts and SciPy version.
The candidate pays for base factorization, base solution, one triangular
solve per outage, denominator check and all verification. A small or
nonfinite denominator triggers degraded mode: fall back to direct outage
factorization and charge it. Disconnected outages are classified and excluded
from the defined connected-outage capability for **both** paths, with count
reported; an accidental singular solve must fail the audit.

The quotient here is not a new mathematical discovery: the preexisting
network interface states which one branch changed. The measurable question
is whether representing that change, constructing a valid reuse witness and
verifying all outputs costs less than repeating generic sparse solves. A
positive result would need a separate comparison with MATPOWER's LODF and
larger, untouched networks before a runtime or scaling claim. A negative
result terminates this candidate on case118 without retuning the threshold.
