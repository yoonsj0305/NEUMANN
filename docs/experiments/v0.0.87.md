## Preregistered before the first observation

Q3/Q4 remain OPEN. v085 ruled out attributing the same executable basis head
to compression. v086 made native warm starts available to both sides. This
version implements a different computation: a 16-wide three-update bipartite
graph model keeps all columns for the first update, then pays a learned top-2m
selection and actually removes column states/edges for the final two updates.
Its full16 ablation has identical initial parameters and retains all columns.
Pointwise16 and full128 executable candidates are implemented but NOT trained.
This is a runnable candidate roster, not a completed matched-model experiment.

The message-passing family is informed by Fan et al., ICML 2023,
<https://proceedings.mlr.press/v202/fan23d.html>. It is NOT a faithful reproduction
of that paper's features, training or learned repair. Lu et al., ICML 2025,
<https://proceedings.mlr.press/v267/lu25q.html>, is another applicable basis
baseline still required before any global learned-LP superiority claim.
