# v0.0.10 — Learned proposal, deterministic acceptance

## Question

Can a learned high-level structure recognizer select a deterministic family compiler without allowing the learned prediction itself to become solver-ready authority?

## Architecture

raw problem
→ learned competence / family proposal
→ selected deterministic family compiler
→ compiler accept or UNKNOWN
→ deterministic solver

The learned model is advisory. It does not create the final IR.

## Safety contract

A learned proposal is accepted only if:
1. the proposed family has an authorized compiler,
2. that compiler fully accepts the raw input,
3. the compiler emits the same IR family as proposed.

Any failure becomes UNKNOWN.

## Why this matters

A scalable NEUMANN cannot try every future domain compiler forever. But letting a learned router directly authorize solver execution would turn classifier errors into semantic errors.

v0.0.10 tests a middle path:

> learned proposal + deterministic acceptance

## Evaluation

Compare:
- false routes at the proposal layer,
- false routes after compiler acceptance,
- known-task coverage,
- structurally-near unsupported tasks,
- cases where the compiler rescues a bad learned proposal.

## Boundary

The dataset is tiny and controlled. This version does not demonstrate broad natural-language understanding, calibrated production OOD detection, or general-purpose learned IR generation.
