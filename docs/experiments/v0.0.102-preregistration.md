# v0.0.102 — Fresh Q34 holdout for frozen EXPAND4

## Purpose

v0.0.101 admitted exactly one frozen support-system authority to a new
confirmation holdout:

`EXPAND4`

The learned representation, model architecture, two quotient checkpoints,
ranking rule, support factors (2m then 4m), verifier trigger, fallback rule,
Q34 thresholds and cost accounting are all frozen.

v0.0.102 tests that unchanged system on a newly registered holdout. It is the
last Q34 confirmation before Q5 for this constructed LP mechanism.

No refit, threshold calibration, support-factor search, checkpoint selection,
architecture change or v0.0.98 holdout reuse is permitted.

## Two-phase authority

The holdout is irreversible and split into two phases.

### Phase 1 — source registration

Generate and byte-freeze the fresh inputs and independently certified oracle
labels.

During registration:

- no model or checkpoint is loaded;
- no learned inference is executed;
- no Direct/Oracle route timing is executed;
- no EXPAND4 route is evaluated;
- no Q34 metric is computed.

The source gzip and SHA256 manifest are committed before evaluation code is
allowed to access them.

### Phase 2 — first evaluation

Evaluation starts only from the committed source archive.

Restore only the two frozen v0.0.100 QUOTIENT checkpoints carried through the
v0.0.101 EXPAND4 decision:

- seed 100001;
- seed 100002.

Run only:

- DIRECT;
- free-structure ORACLE reference;
- EXPAND4_s100001;
- EXPAND4_s100002.

The first valid result is retained byte-for-byte. No rerun may rescue an
observed failure.

An infrastructure failure before any observation may be corrected only at the
invocation/runtime boundary and must be retained explicitly.

## Fresh source set

Use 24 completely new base seeds:

`102200..102223`

- first 12: m=64, n=1024;
- next 12: m=128, n=2048;
- alternating condition number 1 / 1000;
- width factor 16.

For every base problem create exactly one mathematically equivalent surface
view with:

- signed row permutation;
- positive column scaling with matched objective scaling;
- deterministic surface seed `base_seed + 300000`.

This yields 48 views and four cells of 12 each:

- `m64_base`
- `m64_surface`
- `m128_base`
- `m128_surface`

These seeds are disjoint from v0.0.88, v0.0.98, v0.0.100 and v0.0.101.

The generator family remains the same planted width-factor-16 LP lineage.
Therefore even a pass is a mechanism-level Q34 confirmation, not natural-domain
generalization.

## Frozen EXPAND4 contract

For each input:

1. compute quotient point features;
2. run the frozen support MLP once;
3. form the complete ranking;
4. try top2m with the restricted native solver;
5. verify on the original LP;
6. only if rejected, try top4m;
7. verify on the original LP;
8. only if rejected again, use charged full Direct fallback.

Hidden basis labels never enter proposal or expansion decisions. Only the
original-problem verifier controls expansion.

## Fresh Q34 gate

For each seed independently, require the conjunction on:

- m64_base;
- m64_surface;
- m128_base;
- m128_surface;
- all 48 views combined.

Each required cell passes only if:

1. every retained timed answer is original-problem verified;
2. oracle savings are positive;
3. candidate pre-discovery savings are positive;
4. utility recovery >= 0.80;
5. discovery burden <= 0.20;
6. amortized complete / Direct < 1.00.

Additionally, for each seed the frozen top2m proposal must be exactly invariant
between all 24 base/surface pairs.

Fallback-free rate and expansion frequency are reported but are not new hard
gates. Fallback has always been part of NEUMANN and remains fully charged.

## Decision

If both seeds pass every cell + combined gate and preserve 24/24 paired top2m
invariance:

`Q34_EXPAND4_FRESH_HOLDOUT_PASS_ADVANCE_Q5`

Then freeze this constructed-LP mechanism and stop local Q3/Q4 architecture
tuning. Advance to Q5 scaling/open-set/cross-domain evaluation.

If reference capability is not reached:

`Q34_EXPAND4_FRESH_REFERENCE_CAPABILITY_UNREACHED`

Otherwise:

`Q34_EXPAND4_FRESH_HOLDOUT_FAIL_NO_Q5`

A failure cannot be tuned against this holdout. Return to a higher-level
structural authority / task formulation.

Even on PASS, global/general Q3 and Q4 remain analytically OPEN. The claim is
only that this constructed LP mechanism has enough verified Q34 evidence to
justify Q5.
