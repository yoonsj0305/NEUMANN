# v0.0.52 — Real numerical matrix ordering audit

Status: **preregistered protocol; freeze before first full audit**. No learned
model or Structural Compression claim. This experiment checks whether a cheap
external structural ordering can beat mature solver-internal presolve/ordering
on an actual solve after paying its own discovery and verification costs.

## Source and fixed sample

Use the original compressed Matrix Market files from NIST's Harwell–Boeing
BCSSTRUC1 structural engineering set: `bcsstk05` (153), `bcsstk06` (420),
`bcsstk09` (1083), `bcsstk10` (1086). These are four predetermined symmetric
positive definite stiffness matrices across three sizes; the scope is this
small related family, not random samples of all sparse systems. Their gzip
SHA-256 values, source URLs and expected sizes are pinned in
`neumann1/numeric_order_v052.py`. Reject a mismatching original file. Do not
redistribute the data in this repository. NIST describes the source and the
original collection; no external code or weights are copied.

## Fixed policies and accounting

Use SciPy SuperLU `splu` with its default `COLAMD`, `MMD_AT_PLUS_A`,
`MMD_ATA`, and `NATURAL` column ordering. The primary strong diagnostic
reference is the **per-instance best median** of the first three native
policies. This best-of-three is not a free deployable selector; report default
COLAMD separately. NATURAL is a weak negative control. Compare a single cheap
external `reverse_cuthill_mckee(A, symmetric_mode=True)` permutation followed
by `splu` with `NATURAL` on the symmetrically permuted matrix. SuperLU may
pivot rows internally. RCM is a different numerical pipeline, not an
identical implementation of a native column-order policy.

For each policy and matrix, set `x_true[i]=sin(i+1)`, `b=A@x_true`. Time the
conversion to CSC, policy order and permutation where applicable, numerical
factorization, one solve, unpermutation, and *original-equation verification*.
Exclude common external file fetch, parsing and shared RHS formation; these
are charged equally to every path. Record L+U nonzeros as an independent
memory proxy, not a FLOP or byte count. Use one discarded complete warmup and
seven repetitions per policy, with predetermined shuffled trial order.
Report every raw trial and median wall time; microsecond-scale local timings
are diagnostic and hardware-dependent. Use one process, pinned BLAS threads
(`OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1`). No search or per-instance
policy selection is deployed or assigned zero cost.

Original-equation backward error is
`||A x-b||inf/(||A||inf ||x||inf+||b||inf) <= 1e-10`; relative infinity-norm
error to the planted solution must be `<=1e-7`. Abort the audit on any
nonfinite/invalid solution. The checker uses the original unpermuted matrix
and known solution, independently of SuperLU's factorization result.

## Fixed decision

`DETERMINISTIC_OPPORTUNITY_VISIBLE` requires RCM's *complete-path median*
to beat the per-instance strongest native median by at least **20% on at
least two of four matrices**. Otherwise report `NO_RCM_OPPORTUNITY` and stop
this candidate; do not train an orderer on four cases. Even a pass is only a
reason to test more matrices and deployable routing with its selection cost,
not evidence that a learner, Structural Compression or favorable scaling won.
No threshold, matrix or candidate change may be made after seeing rows from
the first full audit. Different workload questions need separate protocols.

## Reproduction

Download `https://math.nist.gov/pub/MatrixMarket2/Harwell-Boeing/bcsstruc1/
{name}.mtx.gz` for the four names to an external directory. Run:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python benchmark_v052.py \
  --data-root /path/to/bcsstruc1 --output docs/experiments/results/v052_first_audit.json
```

CI runs a small original-equation contract smoke without fetching data.
