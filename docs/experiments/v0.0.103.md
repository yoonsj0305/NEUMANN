## Replay, publication and stopping rule

`experiments.q5_first_archive` hard-pins the first source/report bytes,
execution heads and terminal chains before independent witness/cost replay.
Fresh generation, checkpoint restoration/forward and native solver calls are
forbidden by replay guards. Dedicated exact-runtime CI must actually run that
replay; a skip or internally valid replacement hash chain is not sufficient.

Stop rescue work on this opened slice. Do not increase its5s deadline, remove
small/null/failed/surface cases, widen support or retrain to turn it green.
The next scientific decision must use a separately frozen task/capability and
source contract. Cross-domain transfer remains untested; a constructed-LP
result cannot close global Q5.
