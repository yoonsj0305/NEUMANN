# v0.0.99 — Equivalence-quotient point representation preregistration

## Why this version exists

v0.0.98 failed the fresh Q34 conjunction because the frozen B_POINT support
system lost structural utility on the larger size + surface-shift cell while
remaining cheap. The v0.0.98 holdout is now sealed: its labels, misses, route
outcomes and per-case behavior are not development data.

v0.0.99 therefore does **not** fit a new model and does **not** touch the
v0.0.98 source/evaluation archives. It uses only the already-opened v0.0.88
training inputs plus analytic metamorphic transformations.

The question is narrower:

> Can we define a point representation that quotients out known
> solution-preserving surface degrees of freedom before spending another
> training budget?

## Equivalence group

For standard-form LP

`min c^T x  s.t.  A x = b, x >= 0`,

this audit uses the following index-preserving surface transformations:

1. signed row permutation:
   `A' = R A, b' = R b`, where R is a signed permutation matrix;
2. positive column scaling:
   `A' = A diag(s), c' = c ⊙ s`, where every `s_j > 0`;
3. their composition.

These transformations preserve the represented feasible/optimization problem
up to the obvious variable rescaling and preserve column identities. A support
selector should therefore not depend on these surface coordinates.

The audit deliberately does **not** call m=64 and m=128 equivalent problems.
Problem size is a separate generalization axis. It only removes a known
dimension-dependent nuisance statistic from the point representation.

## Candidate quotient representation

Keep the first four frozen CG5 column observables:

1. normalized cost;
2. five-step CG affine dual residual;
3. five-step CG primal projection;
4. normalized `D^T b`.

Replace the two surface-sensitive slots:

5. old `mean(D_j)`
   -> `|D_j|^T |b| / max(1, ||b||_2)`;
6. old `mean(|D_j|)`
   -> `||D_j||_1 / sqrt(m)`.

Keep:

7. `m/n`;
8. constant 1.

Column normalization `D=A/||A_j||`, `q=c/||A_j||` already removes positive
column scaling. The new slots are exactly invariant to signed row permutation.
Slot 6 is additionally dimensionless under the dense normalized-column scaling
law that makes the old mean-absolute statistic shrink approximately as
`1/sqrt(m)`.

This is a point-support representation only. No graph representation claim is
made.

## Frozen audit set

Use all 48 already-opened v0.0.88 training sources. Do not access v0.0.88 final
sources and do not open any v0.0.98 holdout archive.

For each source, generate exactly three deterministic, label-free metamorphic
views:

- signed-row only;
- positive-column-scale only;
- signed-row + positive-column-scale.

Metamorphic seed base: `99900`, deterministically offset by case index and
view index.

The audit may restore the two frozen v0.0.88 point16 checkpoints only to measure
how much the **current** CG5 representation changes its top2m support under
equivalent views. Those scores are diagnosis only. Candidate quotient features
are not passed through those old weights because their semantics differ.

No label, oracle basis, solver, fitting, optimizer, timing, fallback, or Q34
performance metric is permitted.

## Frozen admission gate

A candidate quotient representation is admitted to a later opened-development
refit only if all are true:

1. maximum absolute quotient-feature drift over all 48×3 equivalent views is
   <= `1e-8`;
2. each of the first six quotient channels has global standard deviation
   > `1e-8` across the opened training columns;
3. the median slot-6 value across m=32 versus m=64 differs by at most 20%:
   `max(median32, median64) / min(...) <= 1.20`;
4. all candidate values are finite.

The old CG5 drift and frozen-score/top2m instability are reported but are not
used to tune this gate.

PASS:
`ADMIT_QUOTIENT_POINT_REFIT_ON_OPENED_DEV`.

FAIL:
`REJECT_QUOTIENT_REPRESENTATION_BEFORE_TRAINING`.

Passing this audit authorizes only a separately frozen refit/evaluation on
opened development/metamorphic data. It does not authorize touching the
v0.0.98 holdout, does not pass Q34, and does not advance to Q5.
