# v0.0.37 — Smallest Adequate State-Aware Residual Predictor

Status: pre-registered research specification

## Motivation

v0.0.36 established that the strongest current architecture on the exact affine-linear family is hierarchical:

    cheap target-leaf prior
        -> certified compression
        -> state-aware residual search
        -> exact verification

The cheap-first residual teacher:

- reduced final retained-system solver work below both target-leaf alone and empty-start dynamic greedy,
- recovered residual value on 55.47% of final examples,
- reduced exact teacher trial materializations by 89.58% relative to empty-start dynamic greedy.

The next question is therefore not whether residual value exists.

It is:

> What is the cheapest policy that can rank residual candidates well enough to recover most of the exact residual teacher's verified solver-work savings?

## Non-goal

v0.0.37 does not attempt to imitate the teacher's exact chosen candidate identity.

The optimization target is downstream verified solver work.

## Frozen cheap first stage

The first stage remains unchanged:

    target-leaf
    threshold = 0.10
        -> deterministic checker

This threshold is transferred unchanged from v0.0.35 and v0.0.36.

No v0.0.37 data may recalibrate the first stage.

## Residual execution authority

A residual policy is advisory only.

At each residual state:

1. cheaply score all feasible candidates,
2. rank them,
3. exact-materialize at most the top **4** candidates,
4. accept the first candidate whose measured marginal solver-work gain is strictly positive,
5. update state and repeat,
6. if none of the top 4 candidates yields positive gain, stop.

Thus:

    predictor / heuristic ranking
        -> bounded exact utility gate
        -> deterministic validity authority
        -> positive-gain admission only

A learned prediction can never directly authorize a solver-work-increasing reduction.

The exact residual teacher remains:

    evaluate every feasible candidate exactly
        -> choose maximum positive marginal gain

and is used only as an expensive reference / label generator.

## Trial budget

Frozen per-state proposal trial budget:

    B = 4

This value is not tuned on v0.0.37 data.

The purpose is to impose a fixed bounded utility-checking cost and turn the experiment into a ranking problem rather than an exhaustive-search approximation.

## Data contract

Use the same leakage-hardened exact affine-linear generator family.

Scale grid:

    k in {2, 4}
    n in {4, 8, 16, 32}
    n >= k

New splits:

    train      = 12 examples / cell = 96 systems
    validation =  6 examples / cell = 48 systems
    final      = 16 examples / cell = 128 systems

Every v0.0.37 full-system signature must be disjoint from:

- v0.0.33 train / validation / final
- v0.0.34 calibration / final
- v0.0.35 calibration / final
- v0.0.36 final

and all v0.0.37 splits must be mutually disjoint.

## Teacher trajectory labels

For every train / validation system:

1. run frozen target-leaf first stage,
2. start from its actually certified accepted set,
3. follow the exact residual dynamic-greedy teacher trajectory,
4. at every teacher state, enumerate every non-conflicting candidate,
5. exact-materialize the tentative set,
6. assign candidate target:

       y = max(0, current_solver_ops - tentative_solver_ops)
           / max(1, current_solver_ops)

   invalid / non-materializable candidates receive y = 0.

The label is therefore normalized positive marginal solver-work gain.

It is not generator-reference identity.

## State-aware feature contract

The predictor may use only information available from:

- the original exact system,
- the currently accepted certified reduction set,
- the current certified retained-system state,
- the current residual candidate universe.

It may not use:

- core_dimension metadata,
- n-k,
- oracle dependency labels,
- ground-truth solution values,
- future teacher choices,
- final-split labels.

Feature vector:

### Static candidate block

Reuse the frozen 16 v0.0.33 candidate features.

### Residual-state block

Add 12 cheap structural state features:

1. retained dimension / apparent dimension
2. accepted reduction count / apparent dimension
3. current solver ops / apparent_dimension^3
4. active row nnz / retained dimension
5. active target incidence / retained row count
6. mean active dependency incidence / retained row count
7. max active dependency incidence / retained row count
8. fraction of candidate dependencies already eliminated
9. candidate target-as-dependency frequency in residual universe
10. mean dependency-as-target frequency in residual universe
11. residual candidates sharing the candidate row / residual candidate count
12. residual candidates sharing the candidate target / residual candidate count

Total input dimension:

    28

No full baseline solve and no exact trial materialization is required to compute these features. The current solver-operation count is already available from the currently certified materialized state; it is normalized only by apparent_dimension^3.

## Pre-registered policy ladder

Every policy uses the same bounded exact utility gate with B=4.

### P0 — state-target-leaf

Recompute target-leaf score from the current active residual structure.

Fitted parameters:

    0

### P1 — state-Markowitz

Recompute Markowitz-style local fill score from the current active residual structure.

Fitted parameters:

    0

### P2 — Ridge residual utility

Pipeline:

    StandardScaler
        -> Ridge(alpha = 1e-3)

Target:

    normalized positive marginal gain y

Learned coefficient/intercept count:

    29

### P3 — MLP-8 residual utility

Pipeline:

    StandardScaler
        -> MLPRegressor(
               hidden_layer_sizes=(8,),
               activation="tanh",
               solver="lbfgs",
               alpha=1e-3,
               max_iter=1200,
               random_state=37
           )

Input dimension:

    28

Fitted weight + bias scalars:

    28*8 + 8 + 8*1 + 1 = 241

No larger learned model is allowed in v0.0.37.

## Smallest-adequate selection rule

Policy selection uses only the validation split.

For each policy measure, relative to the exact residual teacher from the same target-leaf state:

    residual_savings_recovery
        = mean(policy residual additional savings)
          / mean(teacher residual additional savings)

    exact_trial_reduction
        = 1 - mean(policy exact utility trials)
              / mean(teacher exact trials)

A policy is validation-adequate only if:

1. verified retention = 1.0
2. unsafe accepted reductions = 0
3. residual_savings_recovery >= 0.80
4. exact_trial_reduction >= 0.75
5. policy never accepts a non-positive measured marginal gain

Selection order is deliberately biased toward deletion of learned complexity:

1. if either zero-parameter deterministic policy is adequate, choose the adequate deterministic policy with:
   - fewer mean exact trials,
   - then lower mean final solver ops,
   - then fixed name order.
2. otherwise, if Ridge is adequate, choose Ridge.
3. otherwise, if MLP-8 is adequate, choose MLP-8.
4. otherwise select no deployable residual policy and return HOLD.

The final split does not alter this selection.

## Final confirmation rule

The validation-selected policy is frozen before final evaluation.

Final confirmation requires:

1. verified retention = 1.0
2. unsafe accepted reductions = 0
3. residual_savings_recovery >= 0.80
4. exact_trial_reduction >= 0.75

Interpretation:

### Selected deterministic policy + final PASS

    DELETE learned residual complexity.
    Keep deterministic residual ranking.

### Selected Ridge or MLP-8 + final PASS

    KEEP smallest learned residual policy.

### No validation-adequate policy, or selected policy final FAIL

    HOLD.
    Do not claim deployable residual compression.

All pre-registered policies may be reported on final for descriptive comparison, but only the validation-selected policy is confirmatory.

## Metrics

Report for each policy:

- final retained-system solver ops
- residual additional solver savings
- residual savings recovery vs exact teacher
- exact utility trial count
- exact utility trial reduction vs teacher
- accepted residual reductions
- rejected / non-positive trials
- verified retention
- unsafe accepted reductions
- fitted parameter count
- scaler state count
- weighted-sum proxy where applicable

For the exact teacher separately report:

- exact trial materializations
- successful trial solver work

Do not combine unlike operation classes into one synthetic compute metric.

## Degraded mode

If a learned scorer emits non-finite values or its fitted state is unavailable:

    residual stage = disabled
    target-leaf certified result is returned

No fallback may silently invoke exhaustive teacher search.

## KEEP contract

KEEP means the experiment is methodologically valid.

Required:

1. all v0.0.37 splits are disjoint from all prior v0.0.33-v0.0.36 data,
2. train / validation / final are mutually disjoint,
3. target-leaf threshold remains exactly 0.10,
4. B remains exactly 4,
5. no final labels affect fitting, policy selection, or thresholds,
6. core_dimension and n-k do not affect features or inference,
7. all learned models are fit only on teacher labels from train,
8. selection uses validation only,
9. final selected policy is frozen before final evaluation,
10. exact utility gate rejects invalid or non-positive proposals,
11. every returned solution verifies against the original full problem,
12. unsafe accepted reductions = 0.

KEEP does not require a learned model to win.

A deterministic selection or HOLD result is a valid scientific outcome.

## Claim boundary

A positive learned result would support only:

> on this generated exact affine-linear family, a tiny state-aware residual ranking model can recover a large fraction of the exact residual teacher's additional verified solver-work savings while testing far fewer candidates exactly.

It would not establish:

- total-compute superiority,
- natural-language Structural Compression,
- domain generality,
- globally minimal structure,
- asymptotic complexity improvement,
- superiority to all possible deterministic residual heuristics.
