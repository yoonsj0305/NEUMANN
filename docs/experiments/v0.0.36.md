# v0.0.36 — Cheap-First Residual Utility

Status: pre-registered research specification

## Motivation

v0.0.35 established two facts on the generated exact affine-linear family.

First, downstream Value-of-Reduction is strongly state-dependent:

    dynamic greedy solver savings
        = 1798.59765625

    static isolated solver savings
        = 1180.078125

Second, the cheap deterministic target-leaf heuristic already captured most of the dynamic teacher's downstream value:

    target-leaf solver savings
        = 1749.7265625

    target-leaf / dynamic savings
        ≈ 97.28%

The remaining question is therefore not:

> can a learned policy replace target-leaf?

It is:

> after cheap certified compression has already removed most avoidable work, is there enough residual state-dependent utility left to justify any learned component at all?

v0.0.36 measures that residual before training another model.

No new learned model is introduced in this experiment.

## First-principles architecture

The experiment applies the project sequence:

    delete unnecessary learned work
        ↓
    use the cheapest deterministic mechanism that already works
        ↓
    measure only the residual capability gap
        ↓
    learn that residual only if the gap is material

Canonical v0.0.36 path:

    full exact problem
        ↓
    frozen target-leaf scorer
        ↓
    deterministic checker
        ↓
    cheap certified state R0
        ↓
    residual marginal-utility teacher
        ↓
    deterministic checker / exact materialization
        ↓
    retained solve
        ↓
    reconstruction
        ↓
    verify ORIGINAL full problem

The residual teacher remains an expensive measurement instrument.

It is not a deployable inference policy.

## Frozen cheap stage

The cheap first-stage policy is frozen from the first v0.0.35 full result:

    method    = target_leaf
    threshold = 0.10

The threshold is not recalibrated on v0.0.36.

For each example:

1. score the frozen candidate universe using target-leaf,
2. propose candidates with score >= 0.10,
3. process proposals in the frozen deterministic order,
4. accept only reductions that pass the existing deterministic checker,
5. materialize the certified cheap state R0.

No generator k or n-k is supplied.

## Residual utility teacher

Let R0 be the certified target-leaf accepted set.

Let:

    C(R)
        = exact Gauss-Jordan arithmetic-operation count
          of the retained system after reductions R

For a feasible residual candidate c:

    residual_VoR(c | R)
        = C(R) - C(R union {c})

Starting from R = R0:

1. enumerate all remaining candidates that do not directly conflict with accepted row/target identities,
2. materialize every tentative R union {c},
3. reject invalid tentative sets,
4. measure exact marginal solver-work change,
5. choose the candidate with largest strictly positive residual_VoR,
6. tie-break deterministically by row index then target index,
7. accept the winner,
8. repeat until no valid positive marginal gain remains.

Candidates rejected by the cheap stage may be reconsidered if they remain non-conflicting, because validity and marginal utility are state-dependent.

## Full dynamic comparison

The v0.0.35 dynamic greedy teacher is rerun from the empty state on the same v0.0.36 final examples.

This creates three directly comparable paths:

    A. target-leaf only
    B. target-leaf + residual dynamic teacher
    C. full dynamic teacher from empty state

Path C is a comparison teacher, not a claimed global optimum.

Because greedy paths may choose different early reductions, path B is allowed to beat path C.

No recovery ratio is clipped at 1.

## Data contract

Use the same leakage-hardened affine-linear generator family.

Scale grid:

    k in {2, 4}
    n in {4, 8, 16, 32}
    n >= k

New deterministic seeds:

    development = v0.0.36-only seed family
    final       = separate v0.0.36-only seed family

Per cell:

    development = 24
    final       = 32

The development split exists for implementation tests and bounded smoke checks only.

It must not be used to change:

- target-leaf threshold,
- residual selection rule,
- full dynamic rule,
- GO / NO-GO thresholds.

The final split must remain untouched until the contract implementation is complete.

Every v0.0.36 example must be signature-disjoint from all v0.0.33, v0.0.34, and v0.0.35 train/calibration/final data.

Development and final signatures must also be mutually disjoint.

## Primary quantities

For each example define:

    C_full
        = full-system solver ops

    C_cheap
        = solver ops after target-leaf only

    C_residual
        = solver ops after target-leaf + residual teacher

    C_dynamic
        = solver ops after full dynamic teacher

Cheap-stage savings:

    S_cheap = C_full - C_cheap

Residual additional savings:

    G_residual = C_cheap - C_residual

Full-dynamic advantage over cheap stage:

    A_dynamic = C_cheap - C_dynamic

If A_dynamic > 0:

    residual_advantage_recovery
        = G_residual / A_dynamic

The ratio may exceed 1.

If A_dynamic <= 0, the example provides no positive full-dynamic advantage to recover and must be reported separately.

Remaining-work reduction:

    residual_remaining_work_reduction
        = G_residual / C_cheap

when C_cheap > 0.

## Teacher-search cost

Report separately for both residual and full dynamic teachers:

- trial materializations
- successful trial materializations
- invalid trial materializations
- successful trial solver arithmetic ops
- selected positive marginal-gain count
- selected marginal-gain sum

Define descriptive search ratios:

    trial_materialization_ratio
        = residual trials / full-dynamic trials

    successful_trial_solver_ops_ratio
        = residual successful-trial solver ops
          / full-dynamic successful-trial solver ops

These are teacher-generation diagnostics.

Partial solver work inside invalid materializations remains uninstrumented and must be stated as a lower-bound limitation.

No teacher-search cost may be folded into downstream solver savings as if the units represented end-to-end deployment compute.

## Primary comparisons

Report aggregate and per-cell:

1. target-leaf only vs residual path,
2. residual path vs full dynamic teacher,
3. residual additional savings,

5. residual advantage recovery where defined,
6. residual remaining-work reduction,

## KEEP contract

KEEP means the experiment was executed according to this specification.

Required:

1. v0.0.36 development/final data are disjoint from all v0.0.33-v0.0.35 data,
2. development and final are mutually disjoint,
3. target-leaf threshold is exactly 0.10,
4. no v0.0.36 data tune the cheap-stage threshold,
5. residual teacher starts only from the certified target-leaf accepted state,
6. full dynamic teacher starts from the empty state,
7. neither teacher receives k or n-k,
8. tie-breaking is deterministic,
9. deterministic reduction validation remains authoritative,
10. every path verifies the original full problem,
11. unsafe accepted reduction count is zero,
12. all scale cells are complete,
13. teacher-search costs remain separately reported,
14. final data are not used to alter the GO / NO-GO rule.

Not required:

- residual path beats full dynamic,
- residual path materially beats target-leaf,
- search cost falls enough to justify learning,
- a learned residual model is warranted.

A NO-GO result is a valid outcome.

## Pre-registered GO / NO-GO rule for a learned residual model

A subsequent learned residual-utility model is justified only if **all** of the following aggregate conditions hold on the untouched v0.0.36 final set.

### Gate 1 — material residual value

Residual teacher must reduce target-leaf's remaining solver work by at least:

    10%

Formally:

    mean(C_cheap - C_residual)
        / mean(C_cheap)
        >= 0.10

### Gate 2 — recover meaningful dynamic advantage

If the aggregate full-dynamic advantage is positive:

    mean(C_cheap - C_dynamic) > 0

then the residual path must recover at least:

    50%

of that advantage:

    mean(C_cheap - C_residual)
        / mean(C_cheap - C_dynamic)
        >= 0.50

If aggregate full-dynamic advantage is non-positive, this gate fails and there is no demonstrated residual learned gap to pursue.

### Gate 3 — shrink teacher search

Residual teacher must use no more than:

    50%

of full dynamic teacher trial materializations:

    mean(residual_trials)
        / mean(full_dynamic_trials)
        <= 0.50

### Gate 4 — safety

Both target-leaf and residual paths must retain:

    verified retention = 1.0
    unsafe accepted reductions = 0

Only if all four gates pass:

    GO -> v0.0.37 learned residual Value-of-Reduction

Otherwise:

    NO-GO -> keep deterministic target-leaf architecture
             and do not add a learned residual component yet

The thresholds above are frozen before v0.0.36 final execution.

## Additional descriptive cost gate

Because trial count can hide very expensive successful solves, also report:

    residual successful-trial solver ops
    / full-dynamic successful-trial solver ops

This ratio is descriptive in v0.0.36 and is not part of the formal GO gate.

If it is unexpectedly high despite Gate 3 passing, that is a reason to delay learned-teacher data generation and redesign the teacher.

## Interpretation branches

### Case A — GO

If all four gates pass:

- the cheap deterministic stage remains mandatory,
- the next learned model predicts only residual state-aware utility,
- the learned model must be compared against target-leaf-only and exact residual teacher,
- it must not relearn the cheap stage.

### Case B — useful residual, expensive teacher

If Gates 1-2 pass but Gate 3 fails:

- do not train yet,
- first reduce teacher generation cost,
- investigate candidate pruning or structural bounds.

### Case C — weak residual value

If Gate 1 or Gate 2 fails:

- delete the learned residual plan,
- keep target-leaf as the current compression policy,
- move research effort to harder structural families where deterministic heuristics may stop saturating.

## Claim boundary

A positive v0.0.36 result would support only:

> on this generated exact affine-linear family, a cheap deterministic compression stage can be followed by a smaller residual state-dependent utility search that recovers measurable additional verified solver-work savings.

It would not establish:

- a useful learned residual model,
- globally optimal compression,
- domain-general Structural Compression,
- natural-language Structural Compression,
- end-to-end total-compute superiority,
- energy or latency superiority,
- asymptotic scaling improvement.
