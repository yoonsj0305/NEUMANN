# v0.0.36 — Cheap-First Residual Headroom Contract

Status: pre-registered research specification

## Motivation

v0.0.35 established two facts on the generated exact affine-linear family:

1. state-aware dynamic marginal utility materially outperformed static isolated utility,
2. the cheap target-leaf heuristic nevertheless recovered about 97.28% of the dynamic teacher's aggregate solver savings.

Therefore the next question is not whether to train a larger utility model.

The next question is:

> After the cheapest strong deterministic compression has already run, is enough verified residual value left to justify any learned residual policy at all?

## Architecture under test

The cheap-first path is frozen as:

    target-leaf scorer
        ↓
    fixed threshold tau = 0.10
        ↓
    deterministic checker
        ↓
    accepted cheap compression R0
        ↓
    residual dynamic marginal-utility teacher
        ↓
    deterministic exact materialization
        ↓
    reconstruction
        ↓
    verify ORIGINAL full problem

The target-leaf threshold is transferred unchanged from the v0.0.35 final architecture.

v0.0.36 does not recalibrate it.

No learned residual model is trained in this experiment.

## Residual utility definition

Let R0 be the certified target-leaf reduction set.

For a residual candidate c and current residual state R:

    residual_VoR(c | R)
        = C_solver(R) - C_solver(R union {c})

where R initially equals R0.

The residual teacher repeatedly selects the valid candidate with largest positive residual_VoR, with deterministic row/target tie-breaking, and stops when no positive marginal gain remains.

## Comparators

Every final example is evaluated with three paths:

### A. Frozen cheap target-leaf

    target-leaf @ tau=0.10
        -> deterministic checker

### B. Full dynamic greedy utility

The v0.0.35 teacher starts from the empty reduction set.

This estimates the dynamic greedy reference path on the same new examples.

### C. Cheap-first residual dynamic utility

Start from the accepted target-leaf set and search only for additional positive marginal reductions.

The residual teacher may not undo target-leaf decisions.

Therefore it is a hybrid architecture measurement, not a claim of global optimality.

## New data

Use the same leakage-hardened affine-linear generator family.

Scale grid:

    k in {2, 4}
    n in {4, 8, 16, 32}
    n >= k

Final-only audit set:

    32 examples per cell
    256 systems total

No calibration set is needed because v0.0.36 introduces no fitted parameter or threshold.

Seeds are new and every v0.0.36 signature must be disjoint from:

- v0.0.33 train / validation / final
- v0.0.34 calibration / final
- v0.0.35 calibration / final

## Primary measurements

For every example report:

- full-system solver ops
- target-leaf solver ops
- full-dynamic solver ops
- cheap-first residual solver ops
- target-leaf accepted reductions
- residual added reductions
- target-leaf solver savings
- full-dynamic solver savings
- residual additional solver savings
- full-dynamic headroom over target-leaf
- residual recovery of that headroom
- residual positive-gain indicator
- full-dynamic trial materializations
- residual trial materializations
- full-dynamic successful-trial solver ops
- residual successful-trial solver ops
- final original-problem verification

Do not collapse teacher-search work and final retained-system solver work into one synthetic total.

## Core ratios

Aggregate residual headroom recovery:

    H_full
        = mean(target_leaf_ops - full_dynamic_ops)

    H_residual
        = mean(target_leaf_ops - residual_ops)

    residual_headroom_recovery
        = H_residual / H_full

if H_full > 0.

This ratio may exceed 1 if the cheap-first residual path beats the empty-start greedy path.

Teacher materialization reduction:

    1 - mean(residual_trials) / mean(full_dynamic_trials)

Positive residual rate:

    examples with residual additional savings > 0
        / all examples

## Pre-registered decision rule

Proceed to a learned residual policy only if **all three** conditions hold on the untouched final set:

1. residual_headroom_recovery >= 0.50
2. positive_residual_rate >= 0.25
3. teacher_materialization_reduction >= 0.50

Interpretation:

- all three PASS -> proceed to a state-aware learned residual model,
- one or two PASS -> HOLD; inspect scale-conditioned routing before adding learned complexity,
- zero PASS -> DELETE the learned residual branch and retain deterministic target-leaf only.

These thresholds are research continuation gates, not claims of economic break-even or total-compute superiority.

## Scale-conditioned diagnostic

Report all primary measurements by (k, n) cell.

If aggregate continuation is HOLD but residual value concentrates strongly at large apparent dimension, the next experiment may pre-register a size/router gate rather than a universal learned policy.

No router threshold may be selected from v0.0.36 final results and then evaluated on the same data as a confirmatory result.

## Safety / authority

Every target-leaf and residual proposal remains advisory.

The deterministic reduction checker and exact full-problem verifier retain authority.

Required:

    verified retention = 1.0
    unsafe accepted reductions = 0

## KEEP contract

KEEP means the experiment is methodologically valid.

Required:

1. v0.0.36 signatures are disjoint from all v0.0.33-v0.0.35 signatures,
2. target-leaf threshold is exactly 0.10 and is not recalibrated,
3. final inference receives neither k nor n-k,
4. full dynamic and residual dynamic use identical exact marginal-utility semantics,
5. residual dynamic begins from the actually certified target-leaf accepted set,
6. residual dynamic cannot undo the cheap-first accepted set,
7. deterministic tie-breaking is frozen,
8. every path verifies the original full problem,
9. unsafe accepted reduction count is zero,
10. all eight scale cells contain exactly 32 examples,
11. teacher-search work is reported separately from final solver work.

KEEP does not require the continuation gate to pass.

A DELETE outcome is a scientifically valid result.

## Claim boundary

A positive continuation result would support only:

> on this generated exact affine-linear family, a cheap deterministic structural heuristic leaves repeatable state-dependent residual solver-work value that can be exposed by an expensive exact marginal-utility teacher.

It would not establish:

- that a learned residual model can recover that value,
- total-compute superiority,
- natural-language Structural Compression,
- domain generality,
- globally minimal structure,
- asymptotic complexity improvement.

## Next milestone

Only after a PASS continuation result:

    v0.0.37 = smallest adequate state-aware residual predictor

If the gate returns HOLD:

    v0.0.37 = pre-registered scale/router residual test

If DELETE:

    freeze target-leaf as the current cheap compression component
    and move to a harder structural family.

## Central result

The important result is stronger than "residual value exists."

The cheap-first residual path outperformed both components alone.

Relative to frozen target-leaf, residual search reduced the remaining retained-system solver work by approximately:

    76.65%

Relative to empty-start dynamic greedy, the cheap-first residual path reduced retained-system solver work by approximately:

    67.34%

Teacher trial materializations fell by approximately:

    89.58%

Successful trial solver work fell by approximately:

    98.96%

The hybrid therefore reached a lower final solver-work state while exploring far fewer expensive teacher states.

## Path-dependence result

The aggregate residual headroom recovery exceeded 1 because:

    cheap-first residual solver ops
        < empty-start dynamic greedy solver ops

This does not imply that the residual path exceeded a global optimum.

The empty-start dynamic teacher is only greedy with respect to immediate marginal solver-work gain.

The result instead shows that the greedy trajectory is path-dependent.

A cheap structural prior can place the system in a state from which subsequent marginal-utility search reaches a better solution than empty-start greedy search.

This changes the architectural interpretation.

The current candidate architecture is no longer:

    expensive utility search from raw structure

It is:

    cheap deterministic structural prior
        ↓
    certified compression
        ↓
    state-aware residual policy
        ↓
    deterministic checker
        ↓
    exact execution
        ↓
    original-problem verification

## Scale diagnostic

Residual value is heterogeneous.

At apparent dimension n=32:

- k=2: positive residual rate **96.875%**
- k=4: positive residual rate **100%**

and the residual path strongly outperformed empty-start greedy.

At small cells, residual value was often sparse.

This suggests that a future deployable residual policy may benefit from a cheap activation/router gate rather than running universally.

However v0.0.36 final data must not be reused to fit and confirm such a router.

## Research consequence

The pre-registered continuation rule authorizes a learned residual experiment.

But v0.0.37 must not skip deterministic residual baselines.

The next experiment should compare:

1. no residual policy,
2. simple residual structural heuristics,
3. a smallest-adequate state-aware residual predictor,
4. the exact residual dynamic teacher as an upper diagnostic reference.

The learned component is justified only if it recovers residual value not already captured by a cheaper residual heuristic.

The optimization target remains downstream verified solver work, not imitation of the teacher's exact chosen candidate identity.
