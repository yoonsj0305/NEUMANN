# v0.0.30 - Direct capacity/data break-even frontier

## Research question

v0.0.29 observed a large matched-learned-capacity quality gap:

- Structural path: 64/64 strict verified answers
- Direct 8-unit regression: 0/64 strict verified answers

v0.0.30 is designed to attack that result.

The question is no longer:

> Does the matched tiny Direct model lose?

It is:

> How much learned capacity and training data must Direct receive before it reaches the fixed Structural reference, if it reaches it at all?

The desired output is a break-even frontier, not a winner label.

## Stronger Direct challengers

Strict equation verification can make continuous regression look artificially weak because a numerically close prediction still fails an exact residual tolerance.

v0.0.30 therefore evaluates three Direct outputs.

### 1. Raw regression

    token encoder -> MLPRegressor -> (x0, x1)

This preserves the v0.0.29 Direct baseline.

### 2. Rounded regression

The same regressor output is rounded to the nearest integer and clipped to the known support [-4, 4].

This gives Direct the true benchmark prior that every hidden solution is an integer pair in that range.

It has no additional learned inference cost over raw regression.

### 3. 81-class discrete Direct classifier

    token encoder -> MLPClassifier -> one of 81 ordered solution pairs

Every pair in:

    [-4, 4] x [-4, 4]

has a dedicated output class.

This is a stronger Direct challenger because it cannot fail merely by predicting 1.999 instead of 2.0.

## Pre-registered sweep

Training sizes:

    128
    512
    2048

Hidden widths:

    8
    16
    32
    64

This produces 12 configuration cells.

Every cell trains:

- one two-output Direct regressor
- one 81-class Direct classifier

The token encoder remains the v0.0.29 fixed-position encoder.

No final result is used to change the grid.

## Solution-covered corpus

The v0.0.30 training pool is deterministic and nested.

The first 81 examples cover all 81 ordered integer solution pairs exactly once in shuffled order. Larger prefixes continue cycling through reshuffled solution pairs.

Therefore the 128-example classifier is not handicapped by never seeing some output classes.

Corpora:

- training pool: 2048
- validation: 243
- final: 243

Training, validation, and final use different fixed seeds and are text-disjoint.

They are also checked to be text-disjoint from the v0.0.29 corpora.

## Fixed Structural reference

The Structural path is not enlarged in v0.0.30.

It remains the exact v0.0.29 reference:

- fixed-position token encoder
- 8 hidden units
- two output scores
- 128 positive training systems
- 128 paired near-negatives
- validation threshold learned from the v0.0.29 validation split
- deterministic compiler
- Gaussian elimination
- deterministic verifier

This keeps the target stationary while Direct receives more resources.

## Validation-before-final protocol

All 12 Direct cells are trained first.

The validation split is evaluated across all pre-registered cells and all three Direct output methods.

The benchmark records:

- best validation Direct candidate
- first validation break-even candidate, if any

Only after validation selection is computed does the benchmark evaluate the final split.

Because every final grid cell was pre-registered, the benchmark may also report the observed best final cell descriptively. It must not use that observation to retune the model or grid.

## Break-even definition

The target verified coverage is the fixed Structural reference coverage on the same split.

A Direct candidate reaches break-even when:

    Direct strict verified coverage
      >=
    fixed Structural strict verified coverage

When multiple Direct candidates satisfy the target, choose the one with the smallest:

1. dense weighted-sum inference proxy
2. fitted parameter count
3. training size
4. hidden width

Training size is recorded separately and is not treated as inference cost.

## Cost reporting

For every grid cell report:

Regression:
- fitted parameters
- layer shapes
- dense weighted-sum proxy
- training wall-clock diagnostic
- convergence-warning status
- inference wall-clock diagnostic

Discrete classifier:
- same fields

Quality:
- strict verified coverage
- solution RMSE
- mean maximum equation residual

The Structural reference additionally reports deterministic solver steps.

Do not combine learned weighted-sum terms and deterministic solver steps into one number. Their units are different.

## Convergence status

A classifier or regressor reaching its iteration limit is not hidden.

ConvergenceWarning is captured and stored as an explicit boolean for each cell.

This avoids both noisy CI logs and silent optimizer failure.

## KEEP contract

KEEP means the frontier measurement is valid.

Required:

1. exactly 12 pre-registered grid cells
2. all three corpus splits are text-disjoint
3. all training prefixes contain all 81 solution classes
4. all reported Direct predictions are finite
5. all learned parameter and arithmetic-proxy counts are positive
6. fixed Structural compiler-gated near-negative false-route rate remains zero

Not required:

- Direct reaching break-even
- Structural outperforming Direct
- zero convergence warnings
- any particular RMSE
- any wall-clock winner

## Claim boundary

v0.0.30 remains a narrow generated 2x2 linear-system experiment with a hand-designed token encoder and hand-written deterministic compiler.

Even if the Structural path retains a large frontier advantage, that is not yet evidence about frontier LLMs, GPU FLOPs, memory traffic, energy, or open-domain reasoning.

The useful result is the measured shape of the controlled break-even frontier.

### Stronger discrete Direct challenger

The 81-class head did not close the gap either.

Its best observed final coverage was:

- training size: **2048**
- hidden width: **16**
- strict verified coverage: **0.098765**

Because this head emits exact integer solution pairs, this result rules out a narrow alternative explanation that Direct failed only because strict verification rejected numerically close floating-point regression outputs.

### Raw regression

Raw continuous regression remained at **0.0 strict verified coverage in every one of the 12 cells**.

However, its RMSE improved substantially with more data and capacity. This means the model was learning some numeric relationship even though it did not learn a sufficiently exact general algorithm for the verifier.

For example, at 2048 training examples:

- 8 hidden units: raw final RMSE **1.912**
- 16 hidden units: raw final RMSE **1.777**
- 32 hidden units: raw final RMSE **1.710**
- 64 hidden units: raw final RMSE **1.822**

The non-monotonic 32 -> 64 change is another reason not to interpret width alone as a simple capability scale.

### Convergence evidence

Regression models reported no captured ConvergenceWarning in the pre-registered grid.

The discrete classifier did report captured convergence warnings for several smaller-data cells, especially the 128-example row. These warnings are retained as evidence rather than suppressed from the result.

The strongest-data 2048-example classifier cells did not require that caveat, yet still remained far below Structural verified coverage.

## Interpretation

v0.0.30 strengthens the v0.0.29 finding, but it still does not establish a total-compute advantage.

Three alternative explanations were directly weakened:

1. **The Direct model was merely too small.**  
   Direct was expanded from 8 to 64 hidden units, reaching about 8x the Structural learned inference proxy in the validation-selected configuration.

2. **The Direct model merely lacked data.**  
   Direct was expanded from 128 to 2048 positive systems.

3. **Strict floating-point verification unfairly punished regression.**  
   Rounded regression and an exact 81-class output head were both added.

None reached Structural break-even inside the pre-registered frontier.

The narrow result is therefore:

> On this controlled 2x2 linear-system benchmark, a small learned model used to identify applicable structure plus deterministic execution preserved verified generalization far better than substantially larger Direct learned mappings from tokenized equations to answers.

The result still has major boundaries.

- The Structural path has a hand-written compiler and exact Gaussian-elimination solver.
- Direct and Structural do not have matched training objectives.
- Structural sees paired negative supervision for abstention.
- Deterministic solver work is additional computation.
- The fixed-position token encoder is not a language model.
- The Direct sweep is still finite. A larger or architecturally different Direct model may eventually close the gap.

Therefore the result should not be stated as:

    NEUMANN is 8x more compute-efficient.

What is supported is:

    No Direct break-even was observed
    within the pre-registered frontier up to
    2048 training examples and 64 hidden units.

## Next falsification target

The next experiment should stop scaling the same shallow MLP indefinitely.

The current frontier suggests that the bottleneck may be **inductive bias**, not only parameter count.

A stronger falsification target is therefore a Direct model with a more appropriate sequence architecture, for example:

- learned token embeddings
- a small recurrent or attention-based sequence model
- explicit positional encoding
- enough capacity to represent multi-step coefficient interactions

The Structural path should then be moved to the same learned backbone so the comparison remains about **what the learned system is asked to produce**, not merely model family.

That would turn the next milestone from a width sweep into an architecture-controlled test.
