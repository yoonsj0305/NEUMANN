# v0.0.101 — Frozen quotient support-expansion tournament

## Purpose

v0.0.100 fixed the known surface-equivalence defect but still missed the frozen
Q34 utility floor on m128 because each quotient seed had one top2m restricted
support miss out of eight cases.

No further fitting is authorized.

v0.0.101 asks one training-free execution-authority question:

> Is a single verifier-triggered expansion from 2m to 4m enough to recover the
> rare size-generalization miss while preserving Q34 economics?

If not, stop this fixed learned point-support family.

## Frozen learned authority

Load only the retained v0.0.100 first-result archive.

Use exactly the two frozen QUOTIENT checkpoints:

- seed 100001;
- seed 100002.

No OLD_CG5 model is carried forward.
No optimizer, fitting, checkpoint selection, score calibration, threshold tuning
or architecture change is permitted.

The quotient representation, model architecture and weights are byte-frozen.

The v0.0.98 fresh holdout remains sealed and unavailable.

## Frozen Q34 gate

For each route, each of the four cells and all 32 views combined:

1. every retained timed answer is original-problem verified;
2. positive oracle and candidate savings;
3. utility recovery >=0.80;
4. discovery burden <=0.20;
5. amortized complete / Direct <1.00.

Both seeds must pass for a family to pass.

Because the quotient representation is already frozen as an equivalence
quotient, each seed's top2m proposal must also be exactly identical between all
16 base/surface pairs.

## Pareto selection

For each family, form conservative development coordinates across both seeds
and all required cells + combined:

- minimum utility recovery;
- maximum discovery burden;
- maximum amortized complete ratio.

Among families that pass all gates, delete a family if another passing family
has no lower minimum utility, no higher maximum burden, no higher maximum
complete ratio, and is strictly better in at least one coordinate.

## Pre-measurement authority clarification

FIXED2 is a **matched control only**. It already failed the strict m128 cell
gate in v0.0.100, so a favorable new development sample must not erase that
STOP boundary. FIXED2 can never independently authorize another holdout.

EXPAND4 earns new authority only if all of the following are true:

1. the EXPAND4 family passes every frozen Q34 cell + combined requirement for
   both seeds and preserves 16/16 top2m equivalence invariance;
2. EXPAND4 remains on the Pareto frontier among passing controls;
3. for **each seed**, across the two m128 cells together, EXPAND4 uses full
   Direct fallback on strictly fewer views than FIXED2;
4. for each seed, EXPAND4 has strictly higher worst-cell m128 utility recovery
   than FIXED2;
5. for each seed, EXPAND4 has strictly lower worst-cell m128 amortized
   complete/Direct ratio than FIXED2.

This clarification is frozen before the first timed v0.0.101 run and prevents
resampling from reviving the already-stopped FIXED2 contract.

## Decision

If EXPAND4 satisfies the authority-earning conditions above:

`ADMIT_NEW_FRESH_Q34_HOLDOUT_FOR_FROZEN_SUPPORT_SYSTEM`

Freeze **EXPAND4 only**. Do not tune on these cases. A later version may
register a new holdout with entirely new seeds.

Otherwise:

`STOP_FIXED_POINT_SUPPORT_FAMILY`

No second development screen, no further local point-support fitting, and no
support-factor tuning. Move one level up to a different structural authority /
representation / task formulation.

This version cannot itself advance Q5.
