# v0.0.75 — Proof-DP lifetime hygiene recovery audit

Status: frozen first audit completed; correctness/lifetime fix retained, first timing no-regression gate failed. Identical-tree replication is recorded separately.

## Why this version exists

An interrupted local work session after v0.0.73 identified a Python object
lifetime problem in both exact graph-DP paths:

- `independent_optimum` used a per-call `@lru_cache` recursive closure,
- `solve_with_proof` used a per-call recursive closure over its memo table.

Clearing or returning from the call did not break the function's self-reference.
Per-call state could therefore remain alive until cyclic GC.

The interrupted work had already established:

- the issue occurred on normal and budget-exceeded paths,
- both solvers needed the same lifetime treatment,
- focused correctness/lifetime tests passed,
- a 1.20 no-regression ceiling had been fixed,
- correctness and lifetime success were to be judged separately from timing.

The exact earlier 25-case local corpus and code snapshot were not recoverable.
Therefore this document does **not** claim an exact rerun of that lost audit.
It freezes a new 25-case audit before timing.

## Code change

Do not alter the mathematical recurrence.

Move recursive evaluation to module-level helper functions and keep memo/counter
state per call.

Required invariants:

1. public answers are unchanged,
2. proof records are byte-for-byte structurally identical,
3. memoized state counts are unchanged,
4. normal exit leaves no per-call memo reachable without invoking cyclic GC,
5. budget-exceeded exit leaves no per-call memo reachable without invoking
   cyclic GC,
6. verifier behavior and failure semantics are unchanged.

This is runtime hygiene, not a new MIS algorithm.

## Correctness authority

The existing independent exact checks remain authoritative:

- `check_proof` validates the Bellman DAG,
- original graph feasibility remains checked,
- v0.0.73 classic graph optima remain unchanged,
- exhaustive/small-graph tests remain part of the suite.

The v0.0.75 tests also embed the pre-change recursive implementations as
test-only references and compare:

- optimum,
- memoized state count,
- full `DPProof.states`.

## Frozen 25-case timing corpus

Use 25 deterministic constructed graphs:

    k in {4, 5, 6, 7, 8}
    index in {0, 1, 2, 3, 4}
    multiplicity = 3
    seed_base = 755000

For each graph evaluate two targets:

- direct original graph, unit weights,
- exact false-twin quotient, certificate weights.

For each target compare two solver families:

- independent exact optimum DP,
- proof-carrying exact DP.

For each family compare:

- `legacy`: the exact pre-v0.0.75 local-recursive implementation embedded in
  the benchmark,
- `cycle_free`: the v0.0.75 module-level-recursion implementation.

No generated graph is removed after timing.

## Timing protocol

For every case / target / solver / implementation:

- one untimed warmup,
- five timed repetitions,
- rotating legacy/cycle-free order,
- cyclic GC enabled,
- explicit `gc.collect()` immediately before each timed repetition,
- the timed lifecycle includes:
  - solve,
  - result equivalence bookkeeping,
  - dropping returned proof where applicable,
  - a final `gc.collect()`.

The final collection is intentionally charged. This audit asks about complete
per-call object lifetime, not just arithmetic inside the recurrence.

For proof-DP calls, proof verification is performed outside the timed solve
lifecycle but every timed result must match the already verified reference
proof exactly. Verification cost is unchanged by this refactor and is reported
separately where available.

## Metrics

Per cell report:

- optimum,
- state count,
- legacy median lifecycle ms,
- cycle-free median lifecycle ms,
- cycle-free / legacy lifecycle ratio.

Aggregate separately for:

- independent/direct,
- independent/quotient,
- proof/direct,
- proof/quotient.

Also report the maximum per-cell ratio in each group.

## Pre-registered decision

### `LIFETIME_FIX_VALIDATED`

Required:

1. all correctness/equivalence tests pass,
2. all 25 cases complete for both direct and quotient targets,
3. all state/proof equivalence checks pass,
4. no timed call fails,
5. every aggregate geometric-mean ratio <= 1.20,
6. every per-cell median lifecycle ratio <= 1.20.

The 1.20 ceiling is retained from the interrupted work as a no-regression cap.

Passing this gate means only:

> removing recursive self-reference preserves exact behavior without imposing
> a material complete-lifecycle regression on this frozen small constructed
> corpus.

It is not evidence of a general speedup.

### `LIFETIME_FIX_CORRECT_BUT_PERF_REGRESSION`

If correctness/lifetime checks pass but any 1.20 timing cap fails.

Keep the correctness fix only if project-wide total-cost reasoning still
justifies it; do not reinterpret the timing failure as noise without a new
pre-registered audit.

### `LIFETIME_FIX_INVALID`

If any answer, state count, proof record, verification, or lifetime contract
fails.

### Engineering disposition versus research verdict

The mathematical recurrence, optimum, state counts, full proof records,
budget failures, and verifier behavior are unchanged. Weak-reference tests
show that per-call memo state is released without cyclic GC after both normal
and budget-exceeded exits.

Therefore the cycle-removal change is retained as an **engineering lifetime
hygiene fix**, not as a performance result. The research gate remains the
first-audit failure above. No speedup, lower-compute, memory-peak, or scaling
claim follows from v0.0.75.

### Evidence limitation

The CI invocation printed the audit summaries but did not use
`--output`, so raw per-repetition rows from these two CI runs were not
persisted as repository artifacts. The workflow/job IDs and exact summary
values above are retained, but this is a provenance limitation. Future timed
gates must persist raw rows before a result is opened.

After freezing these results, routine CI should test the deterministic
lifetime/equivalence contract rather than repeatedly reclassifying this
already-opened timing gate.
