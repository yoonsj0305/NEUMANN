# ARC-AGI-1 opened development fixtures (third-party data)

The four JSON fixtures in this folder are unchanged copies of selected
`data/training` cases from François Chollet's Abstraction and Reasoning Corpus,
https://github.com/fchollet/ARC-AGI.

- Original repository: `fchollet/ARC-AGI`
- Original training task IDs: `007bbfb7`, `08ed6ac7`, `0d3d703e`, `05f2a901`
- Upstream license: Apache License, Version 2.0. A local copy appears in
  `LICENSE-APACHE-2.0.txt`.
- Changes to fixture contents: none.
- Scientific status: selected *after* the researcher examined source data;
  these are public, opened-development examples, **not a blind benchmark**.
- The associated program candidates were also selected with knowledge of
  these tasks. Successful outputs do **not** demonstrate novel opcode
  invention, JEPA transfer, open-set generalization, or frontier-gap recovery.

Original task data is evaluated under its own Apache-2.0 license; NEUMANN's
other source code licensing is separate.
